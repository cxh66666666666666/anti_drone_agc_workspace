# 读后记录：基于改进 TD3 算法的无人机动态环境无地图导航

> 记录日期：2026-09-07
> 重要级别：S 级（核心直接对标）——端到端 DRL 避障导航直接竞品，动态环境主题与本人避障主线重合度高。

## 1. 基本信息

- **标题**：基于改进 TD3 算法的无人机动态环境无地图导航
- **作者**：姜凌峰，李新凯，张海，李涵玮，张宏立
- **单位**：新疆大学 电气工程学院 等
- **期刊**：航空学报，2025, 46(8): 331035
- **DOI**：10.7527/S1000-6893.2024.31035

## 2. 研究问题与动机

无人机在未知动态环境中难以建图与导航，感知受限、稀疏奖励收敛难。

## 3. 方法

- 将导航建模为 **POMDP**，引入 **GRU** 让策略网络利用历史时序信息，避免局部最优；
- 改进 TD3：引入 **softmax 算子**处理值函数，采用**双策略网络**缓解策略不稳定与值函数低估；
- 设计**非稀疏奖励函数**解决收敛问题。

## 4. 结果与证据强度

- AirSim 平台仿真：相对传统 DRL 收敛更快、任务成功率更高。
- 证据强度：标准仿真验证，无真机（摘要层面未给出统计细节）。
