# 读后记录：级联 PID 四旋翼抗风的残差强化学习

> 记录日期：2026-09-07
> 用途：与本人最贴合**PX4 平台**的残差 RL 方法源（直接用 PX4 作基础飞控），是"级联 PID + 残差 RL 抗扰动"的标准引文，也佐证本人选 PX4 SITL 闭环的正确性。

## 1. 基本信息

- **标题**：Improving Wind Resistance Performance of Cascaded PID Controlled Quadcopters using Residual Reinforcement Learning
- **作者**：Yu Ishihara(索尼集团), Yuichi Hazama, Kousuke Suzuki(索尼/Aerosense), Jerry Jun Yokono, Kohtaro Sabe, Kenta Kawamoto
- **出处**：arXiv:2308.01648v1 [cs.RO]，2023-08-03
- **类型**：方法 + 仿真(Gazebo) + 真机（户外抗风 >13 m/s）

## 2. 研究问题与动机

- 级联 PID 简单易调但抗风弱：上层（位置）输入要等下层（角速率）收敛才反映，遇到阵风反应延迟、偏离目标位置。
- 现有抗风方法（MPC/H∞/L1 自适应、扰动估计）需系统辨识、逐机定制，丧失 PID 简单性，难迁移。
- 本文用残差 RL：只学补偿风扰动的残差，保留级联 PID 作基础控制器；纯仿真训练、直接迁移真机（无微调）。

## 3. 方法

**核心公式**：`a = a_PID + a_RL`（级联 PID 输出 + 残差策略输出叠加）。残差学习让策略只关注"抵消外部扰动"，不必从零学飞行。

**算法**：SAC（`r = r_target + αH(π)`）。策略网络小（4 层全连接：68→30→20→5→4 均值+4 方差），在 10 Hz 下可部署到机载。

**状态（68 维）**：相对目标位置(3×3步) + 速度(3×3步) + 相对角度(3×3步) + 角速度(3×3步) + PID输出(4×3步) + RL输出(4×5步) 的历史（1 步=0.1s）。

**动作（4 维）**：`a_RL = (F_thrust, T_roll, T_pitch, T_yaw)` 残差推力+转矩，`a_RL = tanh(a_πθ)` 后经 shift/scale 映射到 `[a_min, a_max]`（`a_max=(0.25,0.1,0.1,0.1)`），最终叠加成桨角速度。

**奖励**（三项）：位置偏差变化 `r_pos=min(-Δ_t+Δ_{t-1},0)`、横滚/俯仰变化惩罚 `r_rp=-|T_roll-T_roll,prev|-|T_pitch-...|`、偏航/推力变化惩罚。权重 w_pos=1, w_rp=2.5e-2, w_yt=5e-3。

**训练**：Gazebo + **PX4 作基础飞控**，单机模型；模拟风 15–25 m/s、26 个方向随机吹（1s 线性增、3s 持续）；对状态加均匀噪声模拟传感器噪声；γ=0.95、batch 128、lr 2e-4。约 12 小时收敛。

## 4. 实验与结果

**仿真（20 m/s 阵风 26 方向）**：位置误差标准差每轴降 45%–63%（x 轴 0.132→0.060、y 0.166→0.063、z 0.099→0.055）。**鲁棒性**：质量/升力系数在 50%–150% 变化下，残差控制器仍比手动调 PID（原机）好 40%–60%。

**户外真机**（无微调，直接迁移）：
- 低风速(<7 m/s，风机 5–10s 数轮)：平均位置偏差 0.29→0.17 m（-41%），最大偏差 0.93→0.48 m（-52%）。
- 高风速(>13 m/s 持续吹，换不同机型):平均 0.34→0.22 m（-35%），最大 1.69→0.78 m（-53%）；传统 PID 多次偏离 >1m，残差控制器最大 0.78m。

## 5. 局限

- 作者自述：系统稳定性无理论保证，特殊情形可能失稳（未来研究）。
- **未自述问题**：① 只做**定点抗风保持**，非轨迹跟踪、非避障；② 无感知模块、无安全约束；③ 动作是低层推力/转矩残差，落在**内环**而非本人外环参考层；④ 真机实验为定性演示（风机/风扇），无严格统计。

## 6. 与本人工作的关系（写作要点）

**竞争性：低（任务不同），平台与方法高度相关**。与本人同为"PX4 + 级联控制器 + 残差 RL"，但其残差落在**内环推力/角速率**、目标是抗风定点；本人残差落在**外环位置设定点偏移**、目标是避障：

| 维度 | Ishihara | 本人工作 |
|---|---|---|
| 残差补偿对象 | 风扰动（内环） | 障碍引起的局部偏移（外环） |
| 基础控制器 | 级联 PID + PX4 | 名义 LQR 轨迹外环 + PX4 内环 |
| 动作 | 连续推力+角速率(4) | 6 离散参考偏移 |
| 感知/安全 | 无/无 | LiDAR 12 扇区 + 安全过滤 |
| 任务 | 定点抗风 | 轨迹跟踪下的局部避障 |
| 迁移 | 仿真直接真机 | PX4 SITL 闭环仿真 |

**写作价值**：① 强佐证"**残差 RL 叠加在级联控制上、保留基础控制器简单性、纯仿真训练可迁移**"的范式；② 证明本人选 PX4 作平台的工程合理性；③ 其"内环残差 vs 本人外环残差"的分界，可作为相关工作清晰划界的素材。
