## 2. 研究问题与动机

针对传统 DQN 在机器人路径规划中的三个缺陷：

1. **Q 值过估计**：目标网络直接取最大 Q 值的动作。
2. **样本无区分度**：经验回放均匀采样，低价值样本被重复利用。
3. **奖励稀疏**：仅终点/碰撞给奖励，收敛慢且易陷局部最优。

## 3. 方法（A-DDQN = DDQN + APF 奖励 + PER）

三项改进叠加构成创新点：

1. **DDQN（Double DQN）**：评估网络选动作、目标网络评价值，解耦动作选择与价值评估：

   $$\hat{y}_t = r_t + \gamma\,\hat{Q}\big(s_{t+1},\,\arg\max_a Q(s_{t+1},a;\theta);\,\hat\theta\big)$$

2. **APF 奖励函数**（核心创新，人工势场思想）
   - 目标项（引力）：$R_{\text{tar}} = -\alpha_1\,d_{\text{goal}}$
   - 避障项（斥力）：$R_{\text{rep}} = -\tfrac{1}{2}\alpha_2\left(\tfrac{1}{d_{\text{obs}}}-\tfrac{1}{d_0}\right)$，当 $d_{\text{obs}}\le d_0$ 时生效
   - 方向项（趋向）：$R_{\text{away}} = \alpha_3\,(d_{\text{pre}}-d_{\text{goal}})$，当 $d_{\text{pre}}>d_{\text{goal}}$ 时生效
   - 常数比例：$\alpha_1=0.00001$（弱引力，防止压制避障项）、$\alpha_2=0.05$、$\alpha_3=0.05$

3. **PER（优先经验回放）**：按 TD 误差优先级采样，比例优先 $p_i=|\delta_i|+\varepsilon$，配重要性采样权重 $\omega_j=\left(\tfrac{1}{N}\cdot\tfrac{1}{p_j}\right)^\beta$ 以消除偏差。

## 4. 实验设置与证据强度

- **环境**：二维栅格地图（Python/PyTorch，非 Gazebo/PX4），机器人 8 方向离散移动。
- **超参数**：γ=0.9，学习率 0.1，迭代 200 轮，动作空间 8，初始/最小探索率 1/0.1，衰减 0.998。
- **场景**：3 组固定地图——15×15 小地图；20×20 稀疏障碍；20×20 密集障碍。起点/终点固定。
- **统计缺陷**：**单次运行、无随机种子、无重复试验、无置信区间**。

### 结果汇总

| 场景 | 路径长度降低 | 迭代轮次降低 | 拐点数降低 |
|---|---:|---:|---:|
| 小地图 15×15 | 24.4→21.6 m（11.5%） | 65→50（23.1%） | 13→5（61.5%） |
| 大地图稀疏 | 35.5→28.6 m（19.4%） | 60→30（50.0%） | 17→8（52.9%） |
| 大地图密集 | 40.7→28.6 m（29.7%） | 77→40（48.1%） | 28→10（64.3%） |

- 指标仅 3 个：路径长度、迭代轮次、拐点数。**无碰撞率、无成功率、无 RMSE、无统计检验**。

## 5. 局限

**作者自述：**

1. 仍依赖经验回放，非平稳环境适应能力有限。
2. APF 静态势场对动态障碍物需调整（未来方向：预测模型估计障碍物未来状态）。

**未自述但明显的问题**（写作时可暗比，勿公开贬低）：

- 二维栅格、单智能体点模型，无动力学、无控制接口（与本人 PX4 SITL 闭环仿真差异巨大）。
- 单次运行、无随机种子、无分布统计，结果仅"提升百分比"，无可信区间。
- 对比仅为 DQN vs A-DDQN，缺少 A* / RRT 等传统基线。
- "收敛轮次"在单次运行语义下不可靠。
