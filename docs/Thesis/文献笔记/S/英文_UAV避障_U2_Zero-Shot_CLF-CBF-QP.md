# 读后记录：Zero-Shot 安全无人机导航（PBRS + CLF/CBF-QP 过滤）

> 记录日期：2026-09-07
> 用途：与本人"RL 输出候选动作 + 部署期安全过滤器"**架构最接近**的直接对标，且是无人机避障场景，须重点划界差异。

## 1. 基本信息

- **标题**：Zero-Shot, Safe and Time-Efficient UAV Navigation via Potential-Based Reward Shaping, Control Lyapunov and Barrier Functions
- **作者**：Ashik Abrar Naeem, Mohammad Ariful Haque
- **出处**：arXiv:2605.01787v1 [eess.SY]，2026-05-03（预印本）
- **类型**：方法 + 仿真（PyBullet + Stable-Baselines3 + Gymnasium）

## 2. 研究问题与动机

- 现有 RL 导航重成功率、轻任务耗时与安全；奖励函数靠经验调权，脆弱、难扩展新约束。
- 多数方法**在 CLF-CBF 约束内训练** RL，使策略依赖特定环境，换场景需重训。
- 本文主张：把"任务学习"与"安全执行"**解耦**，训练在简单通用环境、部署时套 CLF-CBF-QP 过滤器实现**零样本迁移（zero-shot）**到复杂未见场景。

## 3. 方法

**三道组件**：
1. **PBRS 奖励塑形**（加速收敛且不改变最优策略）：用势函数 Φ 构造塑形项 `F = γΦ(s')-Φ(s)`，保证最优策略不变。三个势：到目标距离 `Φ_D=-k_D·d`、对准角 `Φ_Θ=-k_Θ·|α|`、障碍安全 `Φ_obs=k_obs·Σd_i`（9 条 LiDAR 射线距离和）。
2. **MPTD3 算法**（多池 TD3）：在标准 TD3 上引入三分区经验池（临时 FIFO + 成功池 + 失败池），按成功/失败比例 η 自适应采样，避免局部最优。基类为 TD3（连续动作）。
3. **部署期 CLF-CBF-QP 过滤器**（核心）：
   - **CLF**（稳定性）：`V = ½‖p_A-p_T‖²`，约束 `(p_A-p_T)ᵀ(v-v_T) ≤ -γ_clf(V)`；给出 `γ_clf = k_clf√V`，`k_clf ≤ √2(v_max-‖v_T‖_max)` 的可行性条件。
   - **障碍 CBF**：用 24 射线感知，估计障碍圆（质心 c、半径 R_obs），`h_obs = ‖p_A-c‖² - R²`，`R = R_obs + d_safe`；给出硬可行性条件 `v_max ≥ ċ_max + Ṙ_max`。
   - **边界 CBF**：四边线性屏障。
   - **QP**：最小化 `½‖v-v_des‖² + (λ_slack/2)(δ₁²+δ₂²)`，障碍 CBF 为硬约束，CLF 与边界 CBF 用松弛变量 δ 软化，`‖v‖ ≤ v_max`。

**观察空间（18 维）**：位置（归一化）+ 速度 + 航向 + 目标位置 + 9 条 LiDAR 射线距离（120° 前向弧）+ 相对目标距离/方向/对准角。**动作（2 维连续）**：`[λ_v, λ_θ]` 速度与航向的分数变化，动力学为 `v←clip(v+λ_vΔv_max)`、`θ←θ+λ_θΔθ_max`。

## 4. 实验与结果

- 训练环境 1000×1000、20 静态 + 5 动态障碍；训练 10⁶ step，每集 max 1000 步；测试同环境 1000 集。
- **随机初始化障碍位置的提升**：成功率 +19%（774→962/1000），平均步数 -32%（396→267）。
- **PBRS vs 启发式奖励**：成功率略升（95.6→96.2%），平均步数 -19%。
- **零样本迁移**（2 个 100×100 新环境、40 静态+10 动态障碍，静态/动态目标各 100 集）：

| 方法（静态目标） | 成功率 | 碰撞 | 越界 | 超时 | 步数 |
|---|---|---|---|---|---|
| RL(1Hz) | 44 | 2 | 51 | 3 | 102.84 |
| RL+Decision(10Hz) | 73 | 4 | 22 | 1 | 74.95 |
| RL+CLF-QP | 75 | 24 | 1 | 0 | 52.93 |
| **RL+CLF-CBF-QP** | **99** | **1** | **0** | **0** | 59.52 |
| +无速度约束 | 100 | 0 | 0 | 0 | 59.55 |

动态目标场景结论一致（RL+CLF-CBF-QP 成功 98、零越界零超时）。结论：CLF-CBF-QP 过滤器在复杂未见场景下提供稳定安全引导，预训练 RL 无需再训练。

## 5. 局限

- **纯仿真**，作者自述未来需真机验证、需为特定场景找合适 Lyapunov/Barrier 函数。
- 障碍感知是**估计圆**（质心 + 最远点半径），对非凸/复杂障碍失真；LiDAR 是 9 射线（训练）+ 24 射线（部署）的理想化，非真实点云扇区。
- 动作是连续速度/航向，无人机当作**恒高球体**，无底层飞控黑盒内环建模，与本人"PX4 位置设定点 + LiDAR 扇区 + 离散偏移"接口不同。
- 证据力：仿真单次统计，无随机策略种子说明、无置信区间/显著性检验。
