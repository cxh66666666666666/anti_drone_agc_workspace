## 2. 研究问题与动机

强化学习数据驱动造成行为不可预测，难以保证动态自主避让安全；需在降低净空域约束违反风险的同时提高任务成功率。

## 3. 方法

- 将无人机动态避让建模为**约束马尔可夫决策过程（CMDP）**；
- 引入**障碍函数（barrier function）**刻画无人机与入侵机之间的净空域安全边界，以转移后相对距离的**安全裕度**作为风险度量，转化为**障碍成本**嵌入**拉格朗日安全强化学习**框架；
- 拉格朗日乘子自适应调节成本权重，增强对风险转移的惩罚。

## 4. 结果与证据强度

- 与多种基线比较并进行泛化性与安全性测试：平均入侵率降低 10.9%，成功率提升 7.6%。
- 证据强度：仿真数值验证（论文摘要所述），未见真机。
