## 2. 研究问题与动机

针对传统强化学习无人机避障的两个缺陷：
1. **价值函数过度估计**：单网络同时选择与评估动作。
2. **部分可观测**：状态不完全，网络训练时间长、难收敛。

## 3. 方法

- **DRDQN = Double DQN + GRU + PER**：
  1. **双网络**：解耦最优动作选择与动作价值估计，抑制过度估计；
  2. **GRU 循环模块**：在全连接层引入 GRU 处理时间维度信息，增强部分可观测环境下的性能；
  3. **PER 优先经验回放**：加快收敛。
- 环境为仿真实验，设计专门的状态/动作空间与奖励函数。

## 4. 实验与证据强度

- 仿真环境测试（训练 + 未知场景泛化测试），与原有算法对比。
- 结论：训练时间、避障成功率、鲁棒性均更优。
- 标准仿真论文证据强度：无真机、未强调随机种子/重复试验统计。
