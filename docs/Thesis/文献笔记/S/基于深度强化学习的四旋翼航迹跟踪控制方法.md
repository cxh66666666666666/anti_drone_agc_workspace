## 2. 研究问题与动机

- 现工况：传统 PID 依赖精确模型参数，难以应对未知环境扰动（飞行阻力、传感器误差、物理属性突变）造成的控制误差；MPC 等依赖模型准确性与求解时间。
- 既有 DRL 四旋翼工作多集中在**定点悬停**，或把悬停策略直接迁移到航迹跟踪、或只针对单一航迹训练，未有效利用航迹先验信息，航迹跟踪误差较大，跨航迹泛化差。
- 本文要解决：在未知扰动下、面向单种航迹与混合航迹的鲁棒 DRL 航迹跟踪控制器。

## 3. 方法（PPO-SAG = PPO + 模拟退火自适应引导 + 注意力 + 扰动补充）

**核心思想**：利用航迹先验信息 + PID 专家知识引导，提高 PPO 收敛速度与稳定性。三级结构：

**① 模拟退火自适应引导（核心创新）**
每轮航迹训练得累计奖励 R(τ)，与近 N 条平均奖励 R̄(τ)_N 比较；若 R(τ) ≥ R̄(τ)_N 直接通过，否则按 Metropolis 准则决定是否接受：

```
P = exp((R(τ) - R̄(τ)_N) / T_k)     # 接受概率
T_k' = k·T_k,  k∈(0,1)             # 每 L 轮退温，越后期越严
```
被拒绝的训练经验整轮舍弃，改用 PID 专家控制策略重采步长 S̄_N 的引导数据入回放池，提升困难航迹的数据质量。超参 [T₀, k, L]=[1000, 0.95, 100]，灵敏度过宽/过严都坏（宽→几乎不重采、震荡；严→被 PID 主导、抑制探索）。

**② 改进的目标函数**（在 PPO 裁剪项基础上加两项）：

```
J_Ours = J_PPO + Σ_batch β·(log π_old(a_t|s_t) - log π_new(a_t|s_t))² - Σ_aₜ π_new(a_t|s_t) log π_new(a_t|s_t)
```
第一项为**平方距离惩罚**（相对 KL 对称连续，约束更新幅度）；第二项为**最大熵项**（鼓励低概率动作探索）。β=5.0。

**③ 特征处理技术**
- 状态动态标准化：`μ_new = μ_old + (x-μ_old)/n_step`；`q = q + (x-μ_old)(x-μ_new); σ = q/n_step`
- 优势函数批标准化：`Â_GAE_t/Norm ~ N(μ_batch, σ_batch)`
- 奖励缩放替代标准化：`r_t = r_total/(σ_r + ε)`（比例方差，避免绝对量纲影响）
- 学习率线性衰减：`Lr = Lr_max(1 - step_now/step_max)`

**④ 网络结构（策略）**：当前状态 + 两个附加编码拼接后过全连接，输出 Beta 分布采样出螺旋桨转速动作 `a_t = FC(x, h_att, h_his)`。

- **航迹特征选择结构 h_att**（注意力机制，面向未来航迹）：
```
q_t = W_Q⊕s^dt;  k_{t+i} = W_K⊕s_-{t+i};  v_{t+i} = s_-{t+i}
h_att = Σ_i softmax(q_t·k_{t+i}/√d_k)·v_{t+i}      # 共享查询 W_Q、多个独立键 W_K
```
前向点个数 n=6、间隔步长 s=10，前向总范围由 (n·s) 决定；注意力权重能随转向/弧形会聚到关键航迹点位。

- **扰动误差信息补充结构 h_his**：
```
s_e = R(q_t)·(p_t - p_des_{t-1})                   # 机体系下当前位与上刻期望位之差
h_his = ReLU(FC(s_e, v_t, R(q_t))) ⊕ s_e           # ⊕为哈达玛积，保留关键方向误差
```

**状态向量**：`s_t = [x, p_des_{t-1}, s^d-, s_-{t+i}, D_t], i∈{1..n·s+1}`，`D_t` 为扰动真值（训练可见，仅喂给价值网络作环境信息）。

**动作空间**：连续 4 旋翼转速指令 Ω_cmd（Beta 分布映射到转速范围，属 low-level 直控层）。

**奖励设计**（多目标加权求和）：

```
r_p = -k_p·√(x_e²+y_e²+z_e²)      # 位置误差
r_v = -k_v·√(v_xe²+v_ye²+v_ze²)   # 速度误差
r_ω = -k_ω1·(θ_e²+φ_e²+ψ_e²)      # step<K时,小转角引导
   ↳ -k_ω2·(θ_e+φ_e+ψ)²            # step≥K时改角度差
r_bound = -k_b (‖p_e‖₂ > Max_bound)  # 越界终止
r_alive = k_alive                  # 存活奖励
r_total = r_p + r_v + r_ω + r_bound + r_alive
```
系数：k_p=0.5, k_v=0.1, k_ω1=0.2, k_ω2=0.1, k_b=5, Max_bound=8, k_alive=1.5, K_step=2e5。

## 4. 实验设置

- **仿真平台**：Ubuntu20.04 + Python3.8 + **V-rep（PyRep 接口）**，非 ROS/Gazebo/PX4。四旋翼用 **Crazyflie** 参数，控制频率 100 Hz。CPU i7-10700K + RTX3070。
- **扰动**：机身质量、转动惯量、空气阻力、重力加速度均加均匀分布扰动（质量/惯量 ±15%，阻力 ±0.05 等）。
- **航迹**：6 组航迹（前 3 组高度变化小、后 3 组垂直变化大，难度递增），每组由随机航迹点经 A*/Minimum-snap 生成 50 条相似平滑航迹 → **单种 50 条，混合共 300 条**。训练显式排除避障规划航迹点。
- **超参数**：γ=0.99、学习率 ≤3e-4、裁剪 ε=0.2、批大小 64、经验池 1024、最大步长 1e7、回合步长 1800、退火轮次 L=100、T₀=1000、退火系数 0.95。动作空间连续(4)，状态维度较大（含未来航迹特征）。
- **证据强度**：每航迹测试 **5 次** 给均值±标准差；收敛奖励对比；有消融实验、超参灵敏度、大扰动泛化、新航迹迁移。**未见随机种子说明（5 次来源不明）、无统计检验、无实机。**

## 5. 局限

**作者自述**：方法可应用于两类场景（单点侦察/竞速、多点侦察混合航迹），未展开显著自述局限；训练显式排除了避障规划航迹案例（避障仅在迁移实验出现）。

**未自述但明显的问题**（暗比用）：
- **端到端 low-level 直控**整个控制栈（姿态+位置都是网络输出），与实际工程常用的"外环参考 + 内环控制器黑盒"架构不同——说明其可解释性/复用性受限。
- **无安全约束**：仅靠奖励惩罚越界（r_bound + Max_bound 终止），训练时场景内无物理障碍物/无碰撞检测，安全保证是软性的、非结构化的。
- **无感知**：纯航迹跟踪，无 LiDAR/障碍物反馈，与本人"LiDAR 点云 + 安全过滤"完全不在同一问题分支。
- **证据力**：每航迹仅 5 次测试给出 ±std，但无随机种子说明，5 次的独立性存疑；无显著性检验/置信区间；无实机（仅 V-rep 物理仿真）。
- 收敛奖励值仅以"总回报"定性比较，混合航迹下 PPO 不稳为描述性，无统计刻画。
- V-rep（开源物理引擎）仿真保真度低于 Gazebo+PX4 SITL 的飞控级闭环。

## 7. 可借鉴之处（对本人真正有用）

1. **奖励多目标分解与量纲校准**：位置/速度/角度/边界/存活五类加权，系数间量级关系（k_p=0.5 > k_v=0.1 ≈ k_ω2，k_b 最大用于硬惩罚）提示我们设计 DQN 奖励时要按量纲对齐，可参考其项拆分框架。
2. **扰动双层泛化验证方法（V&V 模型）**：训练扰动范围内测一次、再放大到范围外测一次，能直观证明鲁棒与泛化；本人可照此在 Gazebo 中做"标称扰动 vs 加大扰动"两档验证，并对新轨迹做迁移/盲测。
3. **自适应拒绝低质量样本的思想**：模拟退火拒绝低奖励航迹并回炉重采，虽算法层面我们不模仿，但"困难航迹定向提升数据质量"可启发我们对失败 case 的定向重训/数据增强策略。
4. **注意力用于未来航迹特征**：我们已有预设参考轨迹，若后续把 8 字/螺旋等先验信息引入网络，可参考其"(前向点 n, 间隔 s) 量纲开销权衡"的思路（连续密集采样收效甚微）。
