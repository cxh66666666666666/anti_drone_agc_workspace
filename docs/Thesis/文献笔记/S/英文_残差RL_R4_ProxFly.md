# 读后记录：ProxFly——级联控制器上的残差强化学习

> 记录日期：2026-09-07
> 用途：本人"名义外环参考调节器 + 残差 RL 局部修正"架构的**核心方法源 + 直接对标**，用于证明"残差 + 级联控制器"范式的有效性，须与本人避障任务区分。

## 1. 基本信息

- **标题**：ProxFly: Robust Control for Close Proximity Quadcopter Flight via Residual Reinforcement Learning
- **作者**：Ruiqi Zhang, Dingqi Zhang, Mark W. Mueller（UC Berkeley HiPeRLab）
- **出处**：arXiv:2409.13193v2 [cs.RO]，2025-04-30（开源：github.com/ruiqizhang99/ProxFly）
- **类型**：方法 + 仿真 + 真机（近距飞行、空中对接）

## 2. 研究问题与动机

- 近距多旋翼飞行中，上方旋翼的 downwash（下洗流）对下方机造成推力损失 + 复杂外力/力矩，难用传统模型精确建模（需 CFD/风洞）。模型基础的补偿需精确系统辨识、计算昂贵、难迁移到不同机型。
- 端到端 RL 采样低效、黑盒不可解释、拟合特定配置。多智能体 RL 依赖通信与精确建模。
- 本文用**残差 RL**：在级联控制器之上叠加残差模块，只补偿外部扰动，无需通信、领域随机化免精确辨识。

## 3. 方法

**核心公式**：`π(o|θ) = u_cas(s) + π_res(o|θ)`（级联控制器输出 + 残差策略输出叠加）。因 `▽_θ π = ▽_θ π_res`，可直接优化叠加策略的奖励。

**架构（图2）**：动作捕捉/状态估计(200Hz) → 高级位置/姿态控制器(50Hz) → 残差模块(50Hz) → 叠加命令 → 板载低级控制器(500Hz)。残差模块输入是**自车状态 + 期望位置/姿态 + 上一高级命令**，不依赖机间通信。

**动作空间**：`a_res = {c_res, ω_res} ∈ R⁴`（归一化推力残差 + 三轴体角速率残差），经 tanh 缩放。

**观测空间**（20 维）：`{Δs, u_cas, a_res}` = 状态误差(12) + 高级命令(4) + 残差动作(4)。

**奖励**（五项加权）：位置误差 L2、姿态误差 `e_att=2-2cos(ω)`（SO(3) 测地距离）、推力命令惩罚 `Pc=‖c‖+2‖c-c_prev‖`、体角速率惩罚 `Pω=‖ω‖+2‖ω-ω_prev‖`、存活奖励 0.1。加权系数 `α=[-1m⁻¹,-1,-0.01,-0.1s,1]` 无量纲对齐。

**域随机化（重点）**：随机化质量(±20%~±50%)、惯量、螺旋桨效率(U(0.6,1.2)每桨独立)、外力/力矩扰动（x/y/z 三角波随机周期幅值 + 高斯力矩），模拟 downwash 与载荷变化，避免策略过拟合特定配置。

**训练**：PPO，MLP 三层 128 单元（前两层 LeakyReLU，末层 tanh），Adam；每集 20s（前 15s 起飞悬停、后 5s 降落），随机初始位置，500 epoch × 10 集。i7-13700H 上 15 分钟训完。

## 4. 实验与结果

**真机对比**（近距悬停、同向绕圈、反向绕圈三任务，指标为位置/姿态 RMSE）：

| 任务指标 | Basic Controller | FB-AeroComp（CFD模型） | ProxFly |
|---|---|---|---|
| 悬停 E_pos/E_att | 0.1199/0.1710 | 0.1113/0.1818 | **0.0882/0.0794** |
| 同向绕圈 E_pos/E_att | 0.1867/0.1976 | 0.0832/0.1238 | 0.1385/0.1252 |
| 反向绕圈 E_pos/E_att | 0.1451/0.1714 | 0.0983/0.0930 | **0.0940/0.0996** |
| 平均 | 0.1506/0.1800 | 0.0976/0.1329 | **0.1069/0.1014** |

结论：残差模块使位置 RMSE 平均降 29.0%、姿态降 43.7%（相对基础控制器），并与复杂 CFD 模型补偿的 FB-AeroComp 达到可比性能，且无需精确模型/通信。

**空中对接演示**：小机从上方逼近大机（downwash 强扰动）→ 自由落体 5cm 对接（脉冲 + 永久质量改变）→ 脱离。残差模块产生滚转/俯仰反向命令抵消扰动、随下洗流增减的补偿推力，完成 docking（仅用基础模型控制器会失败）。

## 5. 局限

- 作者自述：残差模块可能引发振荡（电机过热）；仍要求系统参数在合理范围；仅验证两种常规尺寸机。
- **未自述问题**：① 训练主要是悬停，轨迹跟踪靠连续改变悬停点实现（非真正轨迹跟踪），对位置/姿态误差高度敏感导致动作偏激进；② 高频命令振荡仍存在（虽有惩罚）；③ **无感知、无避障**——只补偿 downwash 扰动，非避障任务；④ 真机证据无多随机种子统计。

## 6. 与本人工作的关系（写作要点）

**竞争性：低（任务不同）、方法范式高度相关**。ProxFly 与本人共享"**级联控制器 + 残差 RL 叠加**"的架构范式，但 ProxFly 的残差补偿对象是**气动扰动（downwash）**，本人是**局部避障参考偏移**；ProxFly 无感知/无安全过滤，本人核心正是感知 + 安全过滤：

| 维度 | ProxFly | 本人工作 |
|---|---|---|
| 残差补偿对象 | downwash/载荷外部扰动 | 障碍物引起的局部参考偏移 |
| 感知 | 无（仅自车状态+命令） | LiDAR 12 扇区距离 |
| 安全过滤 | 无 | 跟踪误差/感知误差/制动距离调制过滤器 |
| 动作 | 连续推力+角速率残差 | 6 离散参考偏移（位置设定点层） |
| 接口 | 低级控制器(500Hz)黑盒 | PX4 位置设定点黑盒内环 |
| 验证 | 真机近距飞行 | PX4 SITL 闭环仿真 |

**写作价值**：作为"**残差 RL 叠加在级联控制器上、降低黑盒占比、跳过从零探索**"这一范式的最强真机证据来引用，支撑本人采用残差 DQN 而非端到端的合理性；再强调本人差异在"避障感知 + 结构化安全过滤 + 证据严谨性"。

## 7. 可借鉴之处

1. **残差叠加公式 `π = u_cas + π_res`**：本人"名义参考 + 残差偏移"的精确数学表达。
2. **黑盒占比降低论据**：`u_cas` 占比大 → 可解释性强，是本人"残差 DQN 优于端到端"的写作文本。
3. **域随机化（质量/惯量/效率/扰动）**：供本人干扰种子（传感噪声/延迟/动力学扰动）设计参考。
4. **奖励量纲对齐**（α 系数把位置/姿态/命令统一成无量纲）：提醒本人 DQN 奖励按量纲对齐。
5. **"15 分钟训完"的轻量性**：说明残差学习采样高效，可反衬端到端 RL 的低效。
