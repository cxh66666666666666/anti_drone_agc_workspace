# 读后记录：CBF-RL——训练期安全过滤强化学习

> 记录日期：2026-09-07
> 用途：与本人"残差 DQN + 离散安全过滤器"**最同构**的方法源，审稿人最可能用来质疑新颖性，必须在相关工作中显式划界。

## 1. 基本信息

- **标题**：CBF-RL: Safety Filtering Reinforcement Learning in Training with Control Barrier Functions
- **作者**：Lizhi Yang*, Blake Werner*, Massimiliano de Sa, Aaron D. Ames（Caltech MCE）
- **出处**：arXiv:2510.14959v6 [cs.RO]，2026-06-22（预印本，引用需标注 arXiv）
- **类型**：方法 + 仿真 + 真机（宇树 G1 人形机器人）

## 2. 研究问题与动机

- RL 重性能轻安全；CBF 传统上作为**运行时安全过滤器**在线部署，能保安全，但带来的副作用是：策略不了解 CBF → 行为保守、高维智能体探索空间被过度剪枝、每步求解优化程序计算昂贵。
- 纯奖励塑形（reward shaping）不直接强制训练期安全动作，对惩罚权重敏感。
- 本文主张：**训练期过滤 + 奖励塑形是互补的**，融合二者让策略在训练中"内化"安全约束，部署时无需运行时过滤器。

## 3. 方法（CBF-RL 双方法）

**两个核心组件**：
1. **训练期安全过滤**：对策略提出的动作 `v_policy` 用 CBF-QP 最小修改为 `v_safe`（只让策略看到校正后的安全动作，学到内在安全行为）。
2. **障碍启发式安全奖励 `r_cbf`**：在过滤之外，再奖励"接近安全动作、远离违规"的行为，让策略主动避免触发过滤器。

**关键理论贡献——连续→离散安全引理**：
- Lemma 1：对单积分器 `q'=v`，若连续时间 CBF 控制器 `k_s` 满足 `∇h·k_s ≥ -αh`，则 Euler 离散化后 `h(q+Δt·k_s) ≥ (1-Δt·α)h(q) - |R|`。
- Theorem 1（Continuous to Discrete Safety）：在有界不变集 K 上，`h(q_k) ≥ (1-Δtα)^k h(q_0) - μ/(Δtα)`，μ→0 as Δt→0；当 Δt 足够小时恢复标准 DTCBF 界。
- **结论**：Δt ≤ 0.01s 时（受物理引擎稳定性与求解时间限制），连续时间 CBF 的**闭式解**可直接用于离散 RL 环境。

**闭式 CBF-QP 解**（单线性约束，避免每步数值求解，适配大规模并行 IsaacLab）：
```
a = ∇h(q_k), b = -αh(q_k)
if aᵀv_policy ≥ b: v_safe = v_policy
else: v_safe = v_policy + (b - aᵀv_policy)·a / ‖a‖²
```
**安全奖励**：
```
r_cbf = min(aᵀv_policy - b, 0) + exp(-‖v_policy - v_safe‖²/σ²) - 1   # 第二项严格下界 -1，平滑稳定
```
总奖励 `r = r_nominal + r_cbf`。算法用 PPO，声称对具体 RL 算法无关。

**约简模型（reduced-order）**：高维状态（关节位置/速度）投影到低维 `q = p(x)`（如质心/摆动脚位置），只需求约简模型的导（如 Jacobian J），保持 model-free。

## 4. 实验与结果

**单积分器导航消融**（4096 并行环境，1500 步，随机起点/障碍/目标；四变体 Dual/Reward-only/Filter-only/Nominal，12 配置交叉测试）：

| 方法（1000 随机测试成功率） | 无 DR | DR | 部署时过滤器 |
|---|---|---|---|
| Dual | 99.0% | 99.0%(-0%) | 无 |
| Dual(w/o runtime filt.) | 92.7% | 91.7%(-1%) | 无 |
| Reward Only | 91.9% | 87.6%(-4.3%) | 无 |
| Filter Only | 98.8% | 96.7%(-2.1%) | 有 |
| Filter Only(w/o runtime filt.) | 38.7% | 36.8%(-1.9%) | 无 |
| Nominal | 51.4% | 55.0%(+3.6%) | 无 |

关键结论：**只有 Dual 在去掉运行时过滤器后仍保持 ~92% 成功率**；Filter-only 一去掉过滤器就坍缩到 38.7%；Dual 在域随机化（DR）下几乎不退化。

**人形机器人真机**：IsaacLab 训练（4096 env，Δt=0.005s，MLP [512,256,128]，50Hz），零样本 sim-to-real 转移；障碍规避（把障碍近似为圆柱，CBF `h=‖p_ro‖-R_r-R_o`）与上楼梯（摆动脚到下一级台阶切平面的超平面 CBF）两任务。用 ZED2 相机点云聚类定位障碍。高台阶 0.3m 下无 CBF 的 nominal 会踢脚绊倒，CBF-RL 成功上下。

## 5. 局限

- 作者自述：未来需自动障碍函数发现、感知型障碍函数；仅 locomotion 未覆盖全躯操作。
- **未自述的明显问题**：① 障碍函数 `h` 需分析师手动给定（analytical barrier function），不学；② 依赖约简模型导（Jacobian）与单积分器假设，对无人机"离散动作 → 底层 PX4 黑盒内环"的接口是否成立未讨论；③ 人形机器人实验的主要话题是 locomotion 而非无人机/避障，场景与本人差异大；④ 单积分器导航是低维理想化，与本人"33 维状态 + PX4 闭环"复杂度不同。

## 6. 与本人工作的关系（写作要点）

**竞争性：中高，但本质不同**。同是"RL + CBF 安全过滤"，但其落点是**训练期把安全内化到策略、部署去过滤器**；本人是**保留外环部署期安全过滤器**（σ 过滤器始终在线，参数在验证集冻结）。二者方向相反：

| 维度 | CBF-RL | 本人工作 |
|---|---|---|
| 过滤时机 | 训练期过滤，部署免过滤 | 部署期过滤，训练仍用未过滤 DQN |
| 动作形式 | 连续速度 `v_policy`（PPO） | 6 个离散局部参考偏移（Double DQN） |
| 系统接口 | 约简单积分器/人形关节 | 名义轨迹外环 + PX4 位置设定点黑盒内环 |
| 安全建模 | 解析 CBF + 连续→离散闭式 | 净空 h + 跟踪误差/感知误差/制动距离裕量，一阶短时预测 |
| 部署保证 | 去过滤器（靠策略内化） | 过滤器始终在环，可记录干预 |

**差异化重点**：本人不做"训练期过滤内化"，而是强调"**外环参考调节器上、可解释可记录的部署期离散安全过滤器**"，且用 PX4 SITL 闭环而非约简模型训练。这在"训练期 vs 部署期过滤"的对比轴上是明确不同支线。

## 7. 可借鉴之处

1. **连续→离散安全引理（Theorem 1）**：是本人"有条件离散时间安全引理"的直接理论参考和写作模板（`h(q_k) ≥ (1-Δtα)^k h(q_0) - μ/(Δtα)` 结构与 publication_plan.md §4.5 的 `h(k+1) ≥ (1-α)h(k)` 高度吻合）。
2. **闭式 CBF-QP 解 + r_cbf（min + exp 平滑）**：本人安全过滤器若需"最小代价动作投影"，可参考其闭式与平滑奖励，避免每步 QP 数值求解。
3. **消融设计**：Dual/Reward-only/Filter-only/Nominal 四变体 + 部署时有无过滤器的交叉，可直接作为本人 A1(κ=0)/P(κ>0) 消融的对照范式。
4. **域随机化（DR）对安全的鲁棒验证**：用 DR 证明策略在动力学扰动下仍安全，可供本人"传感噪声/延迟扰动种子"参考。
