# B 类快读：CBF 理论综述（Ames，C3）

**Control Barrier Functions: Theory and Applications**——Ames, Coogan, Egerstedt, Notomista, Sreenath, Tabuada；arXiv:1903.11199（cs.SY）。

- **方法**：系统综述 CBF 理论——ZCBF/ECBF、与 CLF 结合的 CBF-QP 与 CLF-ECBF-QP，含相对度、输入受限等推广；并综述在多机器人、四旋翼、双足等领域应用。
- **证据强度**：纯综述，无新实验。
- **作用**：安全过滤方法论的权威综述，作论文 related work 与理论引用的总纲，尤其覆盖相对度/输入受限处理的写法可参考。
