# B 类快读：RL 求解组合优化 UAV-TOP（杨灿）

> 记录日期：2026-09-07；背景（辅助）文献。

**多约束条件下基于强化学习的无人机团队定向优化方法**——《系统仿真学报》2026, 38(2): 360-371；DOI: 10.16182/j.issn1004731x.joss.25-0595；国防科技大学 系统工程学院。

- **方法**：注意力机制 RL 端到端求解多约束无人机团队定向（UAV-TOP，NP-hard 组合优化）。MIFDAM＝静态图编码器(GAT) + 动态增量嵌入 + 角度偏置注意力 + 双视角上下文融合。核心：①action_mask 掩码式多约束建模；②可视图法避障免逐对 A* 计算；③解码顺序重排后处理。
- **证据强度**：中等。每场景 500 随机样例测试，单次整理无置信区间/统计检验。
- **作用**：
  - 与本人工作关系：问题类型不同但同用 RL。**最值得借鉴：用 action_mask 把多重约束（安全/航程/时间/角度）以掩码形式传入网络、环境自动更新合法动作集**——与本人"离散安全过滤"组件思路高度同构，可参考其写法。
  - 可引价值：作为主投刊"RL + 多约束求解"的期刊范本；其"绕障最短距离计算成本高→可视图/掩码替代"论证可反衬本人 SITL 闭环端到端生成避障策略的优势。
