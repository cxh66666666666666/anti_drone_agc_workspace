# B 类快读：SAC-RRT 路径规划（梁秀满）

> 记录日期：2026-09-07；背景（辅助）文献。

**基于深度强化学习的改进 RRT 算法路径规划**——《系统仿真学报》2025, 37(10): 2578-2593；DOI: 10.16182/j.issn1004731x.joss.24-0494；华北理工大学电气工程学院。

- **方法**：SAC 决策网络 + RRT 融合的 **SAC-RRT** 全局路径规划。动作＝{目标偏置概率, 修正距离, 动态步长}，奖励五项（避障/平滑/导航/路程/结果），后剪枝 + B 样条平滑。无人机质点匀速 3D，无闭环动力学。
- **证据强度**：弱偏中。n=8/15 各 **50 次取均值**有重复，但无置信区间/统计检验/种子细节。
- **作用**：
  - 与本人工作关系：**非直接对标（层次不同）**——SAC-RRT 属**全局（离线）路径规划**，RL 仅用于生成 RRT 采样参数；本人属**局部避障 + 外环参考偏移**的在线闭环避障，直接策略执行与飞控闭环。论文里强调刷新计划级别（局部 vs 全局）与闭环验证深度的差异。
  - 可引价值："DRL 提升传统采样规划"的方法学参考；其"50 次均值 + 收敛曲线"实验呈现方式可作本人实验撰写范本。
