# B 类快读：AGV 行人避让 LSTM-PPO（王贺）

> 记录日期：2026-09-07；背景（辅助）文献。

**基于深度强化学习的 AGV 行人避让策略研究**——《系统仿真学报》2025, 37(3): 595-606；DOI: 10.16182/j.issn1004731x.joss.24-0088；沈阳建筑大学机械工程学院 闫广宇课题组。

- **方法**：LSTM-PPO 端到端避障，Isaac Sim + ROS。核心改进＝**基于个人空间理论的奖励设计**（行人舒适度惩罚 + 碰撞惩罚 + 引导/速度/时间奖励），用椭圆指示函数判断是否闯入行人私人空间；先无行人预训练加速收敛。
- **证据强度**：弱。无随机种子/置信区间/统计检验，仅均值描述与逐回合最小距离表。
- **作用**：
  - 与本人工作关系：主题"行人/动态目标避让 + DRL 仿真"贴近但对象为 AGV，不构成直接对标。**最需区分：其"个人空间"是心理舒适度（连续梯度惩罚、可进入被罚），本人"最小净空/安全边界"是物理硬约束（进界即危险）**——写论文时须明确点出本质差异，避免混淆。
  - 可引价值：支持"DRL 配仿真的虚拟仿真验证流程"；用作介绍端到端视觉 DRL 避障、并说明本人直接以状态量输入（非视觉端到端）的差异化。
