# B 类快读：改进 DDPG 无人机路径规划（张森）

> 记录日期：2026-09-07；背景（辅助）文献。

**改进型深度确定性策略梯度的无人机路径规划**——《系统仿真学报》2025, 37(4): 875–881；DOI: 10.16182/j.issn1004731x.joss.23-1524；张森、代强强，河南科技大学信息工程学院。

- **方法**：改进 DDPG。动作＝APF 引导项与带噪随机动作按衰减 β 动态整合；改进点＝①成功/失败双经验池按比例采样；②组合奖励函数（目标吸引+障碍斥力+时间）缓解奖励稀疏。
- **证据强度**：弱。无随机种子、无重复试验、无统计检验，成功率＝"最近 50 次到终点概率"。
- **作用**：
  - 与本人工作关系：非直接对标（本人为残差 Double DQN + 离散安全过滤 + PX4 SITL 闭环；本文为静态配置内 DRL 规划、无动力学闭环）。最值得借鉴**成功/失败双经验池分流**思路，可迁移到本人离散动作奖励设计。
  - 可引价值：作为 DRL 类无人机路径规划在本刊的结构范本（"模型构建→算法→仿真验证"章节编排可模仿）。
