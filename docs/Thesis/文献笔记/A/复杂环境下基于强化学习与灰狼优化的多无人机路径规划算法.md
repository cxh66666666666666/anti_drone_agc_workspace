# A 类快读：强化学习与灰狼优化多无人机路径规划（常绪成）

> 记录日期：2026-09-07；方法源。

**复杂环境下基于强化学习与灰狼优化的多无人机路径规划算法**——常绪成，朱锋，张心慧，等（郑州航空工业管理学院）；信息与控制，2026（DOI: 10.13976/j.cnki.xk.2025.3482）。

- **方法**：DQN-GWO——改进灰狼优化（动态非线性收敛因子 + Lévy 飞行跳跃局部最优）做全局寻优，DQN 深度融合优化状态空间与奖励函数，多无人机 3D 路径规划。
- **证据强度**：多场景对比仿真：收敛路径适应度提升 4%~6%、路径长度降 2%~8%、最大转向角降 30%~60%，运行时间相近。
- **与本人关系**：同用 DQN 家族但面向离线多机规划（+ 元启发式混合），与本人"在线残差 DQN + 安全过滤"路线不同：可作"RL+元启发式混合"路线代表在相关工作引用，突显本人纯端到端策略 + 硬安全保证的定位差异。
- **作用**：DQN 系扩展文献补充；其指标结构（路径质量/转向角）可参考。
