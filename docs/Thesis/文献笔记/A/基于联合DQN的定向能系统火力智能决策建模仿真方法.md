## 2. 研究问题与动机

反无人机集群作战中，需对快速来袭的无人机集群合理分配火力。火力分配传统三类方法均有缺陷：
- **数学求解**（如弹炮混编遗传算法求解）：需严格数学逻辑、模型复杂，仅适用简单场景，难满足三维空间火力分配。
- **优化搜索**（PSO、GA 等）：粒度难把握、搜索效率低、实时决策性低、泛化能力差。
- **智能算法/强化学习**（DQN 等）：此前仅适用简单装备火力分配场景，难移植复杂场景。

**核心动机**：定向能系统多装备、多部署场景下状态空间与动作空间巨大，DQN 会发生训练发散、收敛缓慢、维数灾难。故提出联合 DQN，配合 5 种机制（联合机制、威胁评估机制、动作屏蔽机制、嵌入装备特性奖励机制、探索机制）提升收敛速度、稳定性与泛化迁移性。

## 3. 方法（联合 DQN）

**总体架构**：基于"集中式训练-执行"的多智能体 DQN 联合策略——训练期输入全局态势信息 o 与所有动作 {a1..an}，执行期同样输入全部智能体态势，输出单智能体决策动作。

### 3.1 状态空间（三部分：装备 / 无人机 / 部署区域）

```
s_e = (h_e, g_e, f_e, p_e, a_e, d_emax, d_emin)   (1) 装备
s_u = (h_u, r_u, g_u, m_u, v_u, p_u)             (2) 无人机
s_a = (t_a, w_a, l_a, c_a, t_a)                  (3) 部署区域
```
- s_e 装备：h_e 健康值；g_e 经度；f_e 纬度；p_e 姿态；a_e 可用状态；d_emax / d_emin 最大/最小攻击距离。
- s_u 无人机：h_u 生命值；r_u 路线；g_u 经纬度；m_u 材质；v_u 速度；p_u 姿态。
- s_a 区域：t_a 类型；w_a 宽度；l_a 长度；c_a 中心点；t_a 旋转角。

归一化用 **L2 范式**（式 4，`o_i = s_i / sqrt(sum_k s_k^2)`），融合成长度 m 的状态向量 `o = [o_1,...,o_m]`（式 5）。

### 3.2 联合机制
- **共享状态信息**：把全局态势 st、动作 at、新态势 st+1、奖励 rt+1 组成四元组存入同一经验回放池（全局共享）。
- **共享网络参数**：**同类型装备用同一个网络权重**；定义总状态空间时保留所有装备类型的全部状态，每类装备只在其所在维度填充、其余补 0，统一网络输入维度。→ 数据需求更少、合作性更强。

### 3.3 威胁评估机制（提升泛化、缩小搜索空间）
按位置速度评估每个 UAV 对防御区域的威胁：
```
d1 = r * 2arcsin( sqrt( sin(a/2)^2 + cos(θ1)cos(θ2) sin(β/2)^2 ) )   (7) 大圆距离
t_e = e*(d2/v) + (1-e)*(d2/v_max)              (8) UAV 到区最短时间
T   = (t_cmax - t_c) / t_cmax                  (9) 威胁程度
```
- 式 7：r 地球半径，θ1/θ2 经纬度弧度，α 经度差弧度、β 纬度差弧度。
- 式 8：d2 为 UAV 到部署区域最短距离，v 为该 UAV 速度，v_max 探测到的最大速度，e∈(0,1) 加权系数。
- 式 9：t_c 为 UAV 到达时间，t_cmax 为所有 UAV 最大时间；威胁越大 T 越高。

**动作设计（9 个）**：`A = [0,0,0,0,0,1,0,0,0]`（式 10），A0~A4 追踪、A5 攻击、A6 重置、A7 继续追踪、A8 空闲；0=不可执行，1=可执行。威胁评估选出攻击范围内威胁度最高的 5 个目标设置追踪动作。

### 3.4 动作屏蔽机制（原文定义，须准确引用）
> "引入动作屏蔽机制在一些特定情况下来屏蔽掉智能体的一部分动作，减少学习成本，加快模型的收敛速度。"

```
Ã  = A_l · M                    (11) 屏蔽后的动作 = 动作空间 × 掩码
追踪状态例：
A_l = [1,2,3,4,5,6,7]           (12) A_l0~A_l4 追踪；A_l5 攻击；A_l6 继续追踪
M   = [1,1,1,1,1,0,0]          (13) M0~M4 追踪掩码=1；M5 攻击、M6 继续追踪=0
Ã   = [1,2,3,4,5,0,0]           (14) 屏蔽结果赋回原动作空间完成屏蔽
```
**关键点（原文语义）**：`M0~M4`（追踪动作）掩码为 1、`M5`（攻击）与 `M6`（继续追踪）掩码为 0。即**当前处于"追踪状态"时，屏蔽/禁选攻击与继续追踪动作**。它是**基于装备当前状态（是否处于追踪）的静态规则掩码**，把不可执行/不应执行的动作置 0。属于"任务约束驱动的不让智能体选无效动作"，本质是**约束动作选取**，不是基于连续状态动力学的动态可达域判定。

### 3.5 嵌入装备特性奖励机制
- 输赢奖励（稀疏）：`R = r`（式 15），`r=+10` 击落全部（胜），`r=-10`（负）。
- 激光：`R1 = a*r1 + (1-a)*r2 + r3 + x*0.05`（式 16）——r1=1 自身单步命中奖励，r2 其他装备命中奖励之和，r3=0 或 -10（打击冲突惩罚），x 单步毁伤值。
- 微波：`R2 = a*r1 + (1-a)*r2 + r3 + (5-n)*0.2`（式 17）——n 上次攻击无人机的威胁排序号，越小威胁越大，鼓励先打高威胁。
- 干扰：`R3 = a*r1 + (1-a)*r2 + r3`（式 18）。

### 3.6 探索机制
`ε = ε_end + (ε_start - ε_end)*δ`（式 19），ε-greedy + 指数衰减，ε_start→ε_end。

## 4. 实验设置与结果

- **平台**：自定义对抗仿真平台（定向能系统模型服务 + 无人机集群模型服务 + 中心控制平台），Windows10，CPU i7-10700 2.4+GHz / 128G RAM，GPU A100（训练段）/ 4070（实验段），Python 构建并训练，两平台通过通信协议传数。**非 ROS/PX4/Gazebo 闭环**。
- **状态/动作维度**：融合后长度为 m 的状态向量（未给具体 m 数值）、动作空间 9。
- **超参数（表 1）**：lr 初始 0.001（动态：round<600→1；600≤round<1000→0.1；≥1000→0.01，式 21）；ε_max=0.99 / ε_min=0.01；退火系数 τ=0.001；折扣 γ=0.99；每轮学习次数 C=150；batch_size=256；经验池 30,000。
- **场景**：场景1=30 架无人机 + 1 雷达 + 2 激光 + 1 微波 + 2 干扰；场景2=110 架无人机 + 1 雷达 + 6 激光 + 3 微波 + 2 干扰。判定：无人机任一飞入要地=无人机集群胜，反之定向能胜。**单一指标=胜率**。
- **基线**：仅"基于规则"方法（`T_r=0.2t+0.1h+0.3v+0.3l+0.1f`，式 20）。
- **随机种子**：未见任何随机种子设置、重复试验或置信区间；胜率为单一数值。

## 5. 局限（作者自述 + 未自述）

**作者自述局限**：文中基本未设独立"局限"小节，仅在结论强调优点；隐性提及"状态/动作维度高、场景复杂"为难点，未承认方法局限。

**未自述但明显的问题（论文写作时可暗比）**：
- **证据强度弱**：无随机种子、无重复运行、无置信区间，胜率是单一确定性数值，统计上不可复现。
- **仿真保真度存疑**：火力决策模型（激光毁伤、微波摧毁、电子干扰）为高层抽象仿真，无物理级（大气衰减、命中几何）交叉验证，也未与任何战场真实数据对标。
- **基线不足**：仅对比"基于规则"，无其他 RL/多智能体基线（MADDPG、QMIX 等），无消融（去掉动作屏蔽/威胁评估的逐项验证）。
- **动作屏蔽是手工规则**：掩码由人工按状态设定，与策略学习强耦合，跨场景泛化（装备类型/数量变化时掩码规则需重调）未讨论。
- **状态向量补 0 的可扩展性**：装备数量上百时统一输入维度用补 0 处理，未给 m 的具体规模与计算开销。
- **泛化表缺对照**：高度/速度/规模测试仅报联合 DQN 胜率，未给规则方法对照组。

## 6. 与本人工作的关系（写作要点）

**是否直接对标/竞争**：不构成直接竞争——应用域完全不同（定向能火力分配 vs 无人机轨迹局部安全避障），算法实现上也差距很大（联合多智能体 DQN + 规则掩码 vs 我们单智能体 Dueling+Double+PER 残差 DQN + 实时安全过滤）。但同为《系统仿真学报》稿件，且其"动作屏蔽"关键词与本人"安全过滤"语义相近，**审稿人很可能引用它质疑"安全过滤"新颖性**，必须在相关工作里主动划界。

**必须写清的差异化（核心：动作屏蔽 vs 安全过滤）**：

| 对比维度 | 该文"动作屏蔽" | 本人"安全过滤" |
|---|---|---|
| 触发依据 | 装备状态（如是否处于追踪态）的静态规则掩码，人工设定 | 跟踪误差、感知误差、制动距离的动态安全集判定 |
| 作用对象 | 动作选取层——禁选无效/不应执行的动作（置0） | 状态-动作可达性——过滤到不可安全执行的动作，随连续状态实时收/缩安全集 |
| 类型 | 任务约束（环境可行性/作战规则） | 动态安全集过滤（计划书 v2.0 定性为安全过滤，非严格 CBF） |

**一句话边界**：动作屏蔽是"基于规则禁选某类动作"的静态/状态级约束，作者未考虑跟踪误差、感知误差与制动距离；本人的安全过滤是在连续状态空间上动态计算的保障性机制，可解释、可记录干预解得，作用时机与理论根基均不同。

**措辞建议（相关工作一句话）**：屈长虹等在定向能火力决策中用手工规则掩码屏蔽无效动作以加速 DQN 收敛；本文面向闭环无人机局部避障，用考虑跟踪误差、感知误差与制动距离的动态安全过滤替换静态动作屏蔽，实现覆盖可执行性判定的安全保证，二者目标与机理不同。

## 7. 可借鉴之处（对我们真正有用的）

1. **威胁评估"先生成优先级列表、再选动作"的分解思路**：把"评估谁危险"与"怎么执行动作"解耦，缩小动作选择面——可借鉴到我们 12 方向扇区 / 6 动作中做"按威胁排序裁剪候选扇区"的预筛，缓解局部参考偏移动作的语义重叠。
2. **掩码向量与动作向量点乘的实现形式**（式 11）：`Ã=A_l·M` 写法简洁，若我们要保留环境可行性检查（allowed_actions/is_action_valid），可用同一形式做动作空间约束的统一定义。
3. **集中式共享状态 + 同类型装备共享网络参数**：与我们多智能体扩展无直接关系，但其"同类型共享参数 + 其余补 0"可启发我们未来如需多无人机协同时的参数共享方案（边界：我们当前单机，不作扩展）。
4. **该刊审稿节奏/格式**：收稿到修回约 3 个月；公式按编号、逐变量解释、表格化超参数与结果——符合本刊正文习惯，写论文可仿照。
5. **奖励稀疏性处理的"输赢± + 单步 shaping"分层**（式 15-18）：与我们奖励拆"任务完成 + 单步避障"的结构思想一致，可为奖励量纲校准作参考。
