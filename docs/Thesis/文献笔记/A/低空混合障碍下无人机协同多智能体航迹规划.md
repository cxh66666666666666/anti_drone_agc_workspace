# A 类快读：低空混合障碍下无人机协同多智能体航迹规划（冯斯梦）

> 记录日期：2026-09-07；方法源。

**低空混合障碍下无人机协同多智能体航迹规划**——冯斯梦，张云弈，刘凯，李宝龙，董超，张磊，吴启晖（南京航空航天大学）；电子与信息学报，2025, 47(5): 1291-1300（DOI: 10.11999/JEIT250012）。

- **方法**：构建基于碰撞概率地图避障的无人机避障通信系统模型；提出用户调度优化的 MADDPG 算法实现多机协同航迹规划，兼顾通信能效与避障。
- **证据强度**：仿真分析：混合障碍空域提升能效，平均碰撞概率较传统避障方法下降约 8 倍。
- **与本人关系**：多智能体协同 + 避障，与本人单机局部避障场景不同；其**碰撞概率地图**思想可对照本人"几何净空/安全边界"的距离阈值体系（概率 vs 确定性边界）。
- **作用**：多机/空域类文献补充；引言可引"低空混合障碍下避障是当前研究热点"背景。
