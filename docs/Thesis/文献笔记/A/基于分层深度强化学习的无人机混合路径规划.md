# A 类快读：分层深度强化学习无人机混合路径规划（吕超）

> 记录日期：2026-09-07；方法源/范本。

**基于分层深度强化学习的无人机混合路径规划**——吕超，李慕宸，欧家骏；北京航空航天大学学报，2025, 51(10): 3451-3459（DOI: 10.13700/j.bh.1001-5965.2023.0550）。

- **方法**：障碍半已知环境下，将"自主感知避障"与"趋向全局规划航迹点"两个子任务用分层 DRL 模型有机结合：子任务模型分别训练，顶层调度模型基于其状态抽象选择任务输出，实现功能复合、降低训练难度。
- **证据强度**：仿真试验（13 图 5 表），标准仿真验证强度。
- **与本人关系**：层次化"全局规划 + 局部避障"与本人"外环参考 + 避障偏移"思想相近，但本人为单策略端到端 + 安全过滤。差异化：本人无显式全局地图依赖，SITL 闭环验证。
- **作用**：期刊同主题范本；其"子任务分解降低训练难度"论证可在引言引用。
