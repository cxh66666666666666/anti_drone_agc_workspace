# B 类快读：残差 RL 机器人控制（Johannink，R2）

> 记录日期：2026-09-07；背景（辅助）文献。

**Residual Reinforcement Learning for Robot Control**——Johannink, Bahl, Nair, Levine 等；arXiv:1812.03201。

- **方法**：把常规反馈（手工/程序化）控制器与 RL 学到的残差控制信号叠加为最终控制量，RL 用 TD3，残差只学针对目标补偿的分量。
- **证据强度**：仿真＋真实机器人（木块插入/装配，含接触）；真机随机转角下手控仅 2/20 成功、残差 RL 达 15/20；约 3 小时（8k 样本）收敛，抗制动噪声与偏置。
- **作用**："残差 RL 提升不完美基控制器 + 真机部署"的直接先例，其"仅学小修正量、样本效率高、安全性好"结论最适合做论文动机支撑。
