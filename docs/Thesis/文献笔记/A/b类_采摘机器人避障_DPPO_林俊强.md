# B 类快读：DPPO 移动采摘机器人避障（林俊强）

> 记录日期：2026-09-07；背景（辅助）文献。

**基于 DPPO 的移动采摘机器人避障路径规划及仿真**——《系统仿真学报》2023, 35(8): 1692-1704；DOI: 10.16182/j.issn1004731x.joss.22-0487；华南农业大学工程学院 王红军课题组。

- **方法**：DPPO（PPO + 多线程并行，16 进程），Unity ML-Agents + CNN 图像输入。核心改进＝基于人工势场思想的奖励设计，并针对势场"范围斥力"局限提出**碰撞锥避碰检测的障碍惩罚系数 λ**。
- **证据强度**：弱。多虚拟场景单次运行，无随机种子/置信区间/统计检验，仅均值与标准差。
- **作用**：
  - 与本人工作关系：同为 DRL 避障但为地面移动平台、PPO 连续动作，不构成直接算法对标。**最重要借鉴点：把"虚拟仿真验证"写成完整证据链**（系统架构→环境建模→奖励设定→训练收敛→定量实验表→效果截图），可作本人 PX4 SITL "仿真验证证据链"的模板。
  - 可引价值：引入处引用其"野外复杂随机环境"动机与 APF 奖励设计思路，支撑本人基于碰撞风险的奖励函数设计。
