# A 类快读：基于对抗强化学习的无人机逃离路径规划（黄湘松）

> 记录日期：2026-09-07；方法源/范本。

**基于对抗强化学习的无人机逃离路径规划方法**——黄湘松，王梦宇，潘大鹏（哈尔滨工程大学）；航空学报，2025, 46(17): 331637（DOI: 10.7527/S1000-6893.2024.31637）。

- **方法**：对抗强化学习框架解决无人机受围捕逃逸问题：围捕者-逃逸者博弈；针对接收错误信息干扰决策的问题建模，结合 APF 引入**逐步奖励（势场式过程奖励）**缓解稀疏奖励。
- **证据强度**：仿真（训练奖励/成功率曲线 + 测试表，DQN：51.7% vs PPO 69.5% vs 提出算法提升至更高），无真机。
- **与本人关系**：主题为逃逸而非避障，但**势场式逐步奖励**与本人类似奖励工程可互为参照；对抗环境与本人静态障碍场景不同。
- **作用**：奖励设计参考 + 航空学报同刊范本（其表格/曲线展示方式可仿照本刊要求）。
