# B 类快读：改进 PID 搜索山地无人机路径规划（彭艺）

> 记录日期：2026-09-07；背景（辅助）文献。

**改进 PID 搜索算法的山地环境无人机路径规划**——《系统仿真学报》2025, 37(12): 3075–3086；DOI: 10.16182/j.issn1004731x.joss.24-0721；彭艺、雷云揆、杨青青等，昆明理工大学。

- **方法**：元启发式（非 DRL）。目标函数 F=ω₁距离+ω₂高度+ω₃安全+ω₄稳定性；三项改进＝佳点集初始化、Q-learning 动调 PID 三参数、透镜成像反向学习跳局部最优。
- **证据强度**：较好。各算法独立运行 30 次，报告最优值/平均值/标准差；仍无置信区间与显著性检验。
- **作用**：
  - 与本人工作关系：非直接对标（元启发式 vs 本人 DRL）。**最重要借鉴点：30 次独立重复 + 报告标准差的量化规范**，是本人可对标补强的证据强度模板。
  - 可引价值：作为经典元启发式一支（PSO/WOA/改进搜索算法）的代表，用于引言中传统方法背景交代与 DRL 差异化论证。
