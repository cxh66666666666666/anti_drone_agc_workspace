# B 类快读：安全学习综述（Brunke，C5）

> 记录日期：2026-09-07；背景（辅助）文献。

**Safe Learning in Robotics: From Learning-Based Control to Safe Reinforcement Learning**——Brunke, Greeff, Hall, 等；Annu. Rev. Control Robot. Auton. Syst. 2022, 5:411-44。

- **方法**：横跨控制与 RL 两社区的安全学习控制综述：学习不确定动力学后接鲁棒/自适应/MPC 控制器、Safe-RL（CMDP、鲁棒 MDP、风险规避），及"RL 控制策略 + 安全过滤器"三分类框架。
- **证据强度**：综述类，提供方法分级与开源 benchmark。
- **作用**：论文框架/related work 引用来源；其中"control + safety filter"分类正是本人"残差 RL + 离散安全过滤"架构的定位依据。
