# A 类快读：融合深度强化学习的自适应势场路径规划（胥斌、王青）

> 记录日期：2026-09-07；方法源/范本。

**融合深度强化学习的自适应势场路径规划算法**——胥斌，王青；航天控制，2026, 44(3): 26-34（DOI: 10.16804/j.cnki.issn1006-3242.2026.03.004）。

- **方法**：PPO-APF 分层架构——上层 PPO 依据局部感知自适应输出斥力系数、起效距离与速率调节系数，下层改进 APF（引入目标距离因子与运动学约束）生成飞行指令；复合奖励含路径平滑度与参数稳定性抑制抖动。
- **证据强度**：仿真，22% 障碍覆盖率场景成功率 97.33%，显著优于改进 APF(53.67%) 与纯 PPO(85%)。
- **与本人关系**："RL 自适应调参数 + 基础控制器"与本人"残差 DRL + 基策略"同为两层级联思想；差异：其上层调参、本人上层直接输出残差动作并经安全过滤。可作为"RL+势场"路线代表在相关工作引用。
- **作用**：方法源参考；其奖励量纲/平滑度处理可对照本人奖励校准。
