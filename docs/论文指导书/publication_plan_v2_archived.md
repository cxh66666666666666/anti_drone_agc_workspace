# 无人机局部避障研究与投稿计划（最终版）

> 版本：v2.0
> 制定日期：2026-09-07
> 计划周期：2026-09-07 至 2028 年春季研究生复试前
> 主投期刊：中文期刊《系统仿真学报》（投稿当年复核 EI、核心目录和学校认定）
> 备选方向：《计算机仿真》或当年征稿要求匹配的国内会议（投稿前复核收录状态）
> 核心原则：先建立可信的仿真证据，再决定是否增加算法复杂度。

## 0. 最终决策摘要

### 0.1 主投期刊

本项目的首要投稿目标定为《系统仿真学报》，不是因为可以预先保证录用，而是因为当前项目的证据基础更接近“闭环仿真系统 + 算法方法 + 多场景验证 + 可复现实验”，与系统仿真类期刊的稿件结构较匹配。

投稿前必须完成以下核验，不能仅凭旧网页或第三方列表判断：

1. 核对期刊官网当年的投稿指南、栏目范围、模板、篇幅、审稿周期和费用。
2. 核对当年 EI 收录状态、北大核心/CSCD 等目录状态，以及目标学校对“中文 EI 核心”的具体认定。
3. 检索该刊近三年无人机、机器人、强化学习、路径规划和仿真验证论文，记录实验规模、实机/仿真比例、基线和理论要求。
4. 投稿前由指导教师确认题目、作者顺序、通信作者和是否需要补充硬件在环或实机实验。

如果投稿当年的收录或学校认定不符合预期，按同一实验包切换到备选期刊，不改变已冻结的测试集来迎合某个刊物。

### 0.2 DQN 与 PPO 的最终取舍

**DQN 保留为主算法，不进行整体替换。** 当前动作空间是 6 个离散局部避障动作，已有 Dueling、Double DQN、PER、动作约束和完整训练/评估管线；改换 PPO 会同时改变算法、采样方式、动作处理和调参过程，不能解决当前最主要的控制接口和证据可信度问题。

PPO 不是只能处理连续动作，也可以处理离散动作。因此“不换 PPO”不是算法能力限制，而是研究设计取舍：本论文先回答安全过滤和仿真可信评估问题，避免将算法更换造成的差异误认为方法贡献。

只有满足以下条件时，才增加 PPO 作为补充对照，不得替换 DQN 或推迟主线投稿：

- G4 已通过，P 方法在验证集上稳定优于 B2；
- 指导教师或目标期刊近年论文明确要求策略梯度基线；
- 使用完全相同的状态、动作、奖励、场景清单和统计脚本，至少运行 3 个 PPO 种子；
- 补充实验不会导致正式盲测、论文写作或考研主线延期。

如果未来把动作改为连续速度/局部速度残差，才重新评估 PPO、SAC 或其他连续控制算法；这不属于当前论文的必要工作。

### 0.3 论文主张边界

论文不把“CBF”术语本身当作创新，也不承诺无条件的安全不变性。当前更稳妥的表述是：

> 在名义轨迹跟踪外环上增加一个考虑跟踪误差、感知误差和制动距离的离散时间安全过滤器，由残差 Double DQN 提供候选局部动作，并通过统一仿真协议评估安全性、跟踪代价和泛化性能。

如果闭环辨识、误差上界和采样安全条件能够被实验验证，可在正文中给出“有条件的离散时间安全引理”；否则将其写成安全设计依据和经验过滤器，不写成严格 CBF 定理。

## 1. 研究定位与成功标准

### 1.1 核心研究问题

在无人机沿名义轨迹飞行、底层 PX4 内环保持不变的条件下，能否让残差强化学习策略只输出有界的局部参考修正，并通过考虑跟踪误差和控制滞后的安全过滤器，在未见静态障碍布局中降低碰撞风险，同时控制轨迹偏离、恢复时间和动作抖动？

### 1.2 系统边界

本轮论文只研究以下范围：

- ROS Noetic、PX4 SITL、Gazebo 和 MAVROS 构成的闭环仿真平台；
- 静态柱状或等价几何障碍物；
- LiDAR 点云压缩为方向扇区，策略输出离散局部参考偏移；
- 名义轨迹跟踪器负责底层跟踪，学习策略不直接输出电机、姿态或全局路径；
- 规则避障和 DQN 为主比较对象，安全过滤器是新增方法组件；
- 研究结果限定为仿真证据，不宣称已经完成实机飞行、真实反无人机拦截或 sim-to-real 验证。

以下内容不纳入本论文主线：多无人机协同、真实目标识别与拦截、动态障碍物、多智能体强化学习、完整建图任务和空地协同任务。

### 1.3 可控成功标准

2027 年 11 月前应完成：

1. 一篇符合目标期刊模板的完整中文论文；
2. 一套冻结的 train/validation/test 场景清单、配置、日志和分析脚本；
3. 至少 5 个策略随机种子、至少 30 个盲测布局、统一基线和置信区间；
4. 控制接口、碰撞测量、跟踪误差和复位流程均有可核验记录；
5. 完成一次真实投稿并保存投稿回执。

“录用”受外审周期和期刊决定影响，不能作为项目排期中的保证。2028 年春季前的可控目标是已投稿、可返修、可复现，并能在复试中准确说明论文状态和限制。

代码路径和论文描述必须保持一致。

### 2.2 历史结果的使用规则

已有固定两杆和六杆场景中的 98%–100% 成功率只能作为探索性结果，不能作为正式结论。原因包括：

1. 主要实验使用单一策略种子和少量固定布局；
2. best checkpoint、参数选择和独立评估场景存在相似性，不能排除验证集泄漏；
3. 旧碰撞指标主要由 LiDAR 距离阈值触发，不等同于 Gazebo 物理接触；
4. 训练评估存在明显震荡和单一动作占比过高，峰值模型不能代表稳定收敛；
5. 旧实验的最小距离、成功判定和 reset 处理没有全部由同一指标字典定义。

历史结果可以用于：提出假设、定位训练震荡、选择预实验场景和验证分析脚本；不得与新协议的正式结果混合汇总。

### 2.3 必须先修复的证据问题

在开始大规模训练前，必须完成以下审计：

- LQR 状态中的实际速度来自明确、带时间戳的速度话题，并与位置数据同步；
- 外环输入、双积分器模型、位置设定点输出和 PX4 内环之间的关系写成一致的数学模型；
- 真实几何净空、LiDAR 测距和 Gazebo 接触事件分开记录；
- reset、轨迹相位、障碍布局和初始状态均可追溯；
- 选定动作后实际执行动作、过滤原因和策略原始动作同时写入日志；
- 指标可以由单个原始日志重新计算，不能依靠手工修改 CSV。

## 3. 面向《系统仿真学报》的论文主线

### 3.1 推荐题目

首选题目：

> **轨迹跟踪约束下残差 Double DQN 无人机局部避障方法及仿真验证**

如果跟踪误差调制的过滤器通过 G4 和 G5 的预设检验，可使用：

> **考虑跟踪误差的安全过滤残差 Double DQN 无人机局部避障方法及仿真验证**

不建议在题目中直接使用“严格 CBF”“稳定性保证”或“LQR 加速度控制”，除非对应模型、接口和证明条件已经完整成立。

英文工作题目：

> **Residual Double DQN for UAV Local Obstacle Avoidance under Tracking Constraints: A Reproducible Simulation Study**

### 3.2 文章应突出什么

为了适配系统仿真类期刊，论文的中心不应是“用了一个流行网络”，而应是以下闭环证据链：

1. 建立名义轨迹跟踪、感知、残差动作、安全过滤和 PX4 内环组成的可复现仿真系统；
2. 明确仿真假设、状态和动作接口，并验证设定点到实际运动的响应；
3. 将跟踪误差、感知误差、反应时间和制动距离纳入离散安全过滤；
4. 用规则法、未过滤 DQN、静态过滤和误差调制过滤进行配对比较；
5. 在独立布局、多策略种子、曲率变化、障碍密度、传感噪声和控制延迟下报告统计结果；
6. 同时报告成功率、真实几何净空、碰撞、RMSE、恢复时间、路径长度和过滤干预率；
7. 公开足够的协议、清单、版本和日志摘要，使他人可以复现实验。

### 3.3 预期贡献（必须由实验支持）

1. 给出一种“名义轨迹跟踪 + 有界残差参考修正”的无人机局部避障系统结构，并明确其在 PX4 位置设定点接口上的实现边界。
2. 设计一种跟踪误差调制的离散安全过滤器：跟踪误差增大时收紧可执行净空要求，候选动作必须通过短时预测和不确定性裕量检查。
3. 建立面向闭环仿真的场景隔离、接触/几何净空交叉验证、多种子统计和复现归档协议。
4. 通过受控消融区分 DQN 策略、静态安全边界和跟踪误差调制项的作用，并报告失败案例与适用条件。

Dueling、Double DQN、PER、A\*、LQR 和 CBF 标准形式不能单独作为创新点。若 P 未稳定优于 B2，论文应降级为“残差 DQN 与离散安全过滤的仿真验证”，不得为了保留题目而夸大结论。

## 4. 方法定义与安全过滤

### 4.1 分层结构

```text
LiDAR / 位姿 / 实际速度 / 名义参考
                  |
                  v
       12 扇区观测 + 跟踪误差 + 动态量
                  |
                  v
     残差 Double DQN 输出候选动作 a_DQN
                  |
                  v
  离散时间安全过滤器：预测净空、误差裕量、制动距离
                  |
        +---------+----------+
        |                    |
   安全动作集合非空       安全动作集合为空
        |                    |
   执行候选/最小代价动作     终止并记录 shield_infeasible
        |                    |
        +---------+----------+
                  v
       有界、限速、平滑的局部参考偏移
                  |
                  v
       名义外环参考调节器 -> PX4 内环 -> 无人机
```

策略只负责方向和局部动作选择，底层飞控负责跟踪。过滤器不得读取测试场景的未来真值；它只能使用当前观测、可在线估计的速度、跟踪误差和已冻结的保守参数。

### 4.2 状态和动作

正式协议冻结前由脚本自动导出状态维度。按当前代码，状态包括：

- 12 个运动坐标系 LiDAR 扇区距离；
- 位置归一化量和当前位置跟踪误差；
- 运动方向速度、横向速度、垂向速度、参考速度；
- 上一步局部偏移、净空变化率和路径误差；
- 6 个动作独热编码。

动作定义固定为：

| 动作 | 含义       |
| -: | -------- |
|  0 | 沿名义路径    |
|  1 | 左移       |
|  2 | 右移       |
|  3 | 左移并上升    |
|  4 | 右移并上升    |
|  5 | 上升并暂停/悬停 |

动作的几何代价不能用动作编号差值代替。过滤器应定义显式代价，例如同一动作代价为 0、保持避障侧代价为 1、反向切换代价为 2、垂向变化代价按实际偏移量计算。

### 4.3 控制接口定义

当前实现把 LQR 计算的加速度通过离散双积分器近似转换为位置设定点，再发布到 `/mavros/setpoint_position/local`。在完成接口审计前，论文采用路线 B：

> LQR/轨迹跟踪器被定义为名义外环参考调节器，PX4 位置控制器为黑盒内环；学习模块只改变局部参考，不宣称直接控制加速度或电机。

需要在 G1 前完成：

1. 订阅实际位置和实际速度，确认坐标系、时间戳和单位；
2. 记录阶跃、直线、圆轨迹下的设定点—实际位置响应；
3. 估计动作延迟、速度响应和保守制动参数；
4. 若改为速度/加速度前馈接口，必须重新冻结控制模型和实验协议。

### 4.4 安全函数

定义归一化或物理单位一致的安全函数：

```text
h_k = d_obs,k
      - d_body
      - d_perc
      - d_react(v_k)
      - d_brake(v_k)
      - κ ||e_track,k||
```

其中：

- `d_obs,k` 是当前动作方向或短时扫掠方向上的障碍物距离；
- `d_body` 是无人机碰撞体的几何半径或保守包络；
- `d_perc` 是由 LiDAR 误差实验估计的感知裕量；
- `d_react(v) = v τ_react`，`τ_react` 包含感知、决策、通信和 PX4 响应延迟；
- `d_brake(v) = v²/(2 a_brake)`，`a_brake` 由阶跃/减速实验给出保守下界；
- `κ ||e_track||` 是跟踪误差调制项，`κ=0` 为静态边界消融。

所有参数必须在验证集上冻结，不能根据测试集结果反向调节。若距离、速度或跟踪误差无效，过滤器应进入保守状态并记录 `sensor_invalid`，不能用零值伪装成安全。

### 4.5 离散时间过滤规则

对每个候选动作 `a`，用一阶短时预测模型得到 `h_hat(k+1|a)`，并定义：

```text
Δh_hat_k(a) = h_hat(k+1|a) - h_k

A_safe(k) = { a in A |
              Δh_hat_k(a) + α h_k >= ε_pred }
```

其中 `0 < α <= 1`，`ε_pred` 是由闭环辨识和交叉验证得到的预测误差上界。这样在预测误差满足上界、当前 `h_k >= 0` 且动作保持时间满足模型条件时，可得到：

```text
h_(k+1) >= (1 - α) h_k >= 0
```

这只是**有条件的离散时间安全引理**。只有在 G1/G3 中实验证明感知误差、模型误差、动作延迟和采样周期满足假设时，才在论文中给出引理及其简短证明；否则改写为“具有保守裕量的安全过滤规则”，不宣称正向不变性。

动作执行规则如下：

1. 若 `a_DQN` 属于 `A_safe`，执行 `a_DQN`；
2. 若不属于且 `A_safe` 非空，在 `A_safe` 中选择与 `a_DQN` 几何代价最小的动作；
3. 若 `A_safe` 为空，立即终止 episode，终止原因记为 `shield_infeasible`；
4. 不使用“按动作编号最近”或未记录的隐式重映射；
5. 每一步记录候选动作、实际动作、`h_k`、预测 `h`、`α`、`ε_pred`、过滤原因和传感器新鲜度。

当前代码中的固定阈值 `allowed_actions()` 和 `_constrain_action()` 不能直接当作新方法。它们要么作为 B1 的冻结规则，要么在接入过滤器后明确拆分为环境可行性检查和论文方法过滤器。

## 5. 实验协议

### 5.1 方法组

| 编号        | 方法                               | 目的                 |
| --------- | -------------------------------- | ------------------ |

| 划分         |          建议规模 | 用途               | 规则             |
| ---------- | ------------: | ---------------- | -------------- |
| Train      | 40–60 个程序生成布局 | 训练策略             | 可重复采样，可加入随机扰动  |
| Validation |      12 个固定布局 | 选 checkpoint、选参数 | 不进入训练，不用于最终主结果 |
| Test       |   至少 30 个固定布局 | 最终盲测             | 协议冻结后只读，禁止调参   |

每个划分至少覆盖：无障碍、稀疏障碍、密集障碍、左右对称布局、不同障碍尺寸组合、直线/圆/水平八字等不同曲率。测试集应包含训练未出现的尺寸或组合，但必须通过 A\* 或等价方法确认存在可行路径。

随机种子分为三类并分别记录：

- `policy_seed`：网络初始化、探索和训练随机性；
- `scenario_seed`：布局生成随机性；
- `disturbance_seed`：传感噪声、延迟或动力学扰动随机性。

不得用一个 `seed=0` 代替三类随机性，也不得把测试布局用于超参数选择。

### 5.3 样本量和运行方式

正式主测试采用：

- B2、A1、P 各至少 5 个策略种子；
- 每个种子在相同 30 个测试布局上各运行一次，形成每种学习方法 150 个配对试验；
- B0、B1 使用完全相同的测试布局、初态和扰动清单；
- 在 10 个测试布局上增加 3 个扰动种子，用于延迟、传感噪声和轻度响应变化的鲁棒性分析；
- 任何 reset 失败、传感器超时、Gazebo 崩溃和协议外试验均保留并单独统计，不从分母中静默删除。

先运行 `2 个策略种子 × 5 个布局` 的管线烟雾实验。烟雾实验只检验接口和统计脚本，不用于论文结果或 checkpoint 选择。

### 5.4 指标定义

**主要指标**

1. **物理/几何碰撞率**：本项目主协议使用由障碍物几何和无人机碰撞包络计算的有符号表面净空，并报告“几何碰撞代理率”；若后续接入 Gazebo 接触事件，则作为独立交叉验证列，不能覆盖代理列。没有接触传感器时不得称“物理碰撞率”。
2. **任务成功率**：遇到障碍、无碰撞通过、路径进度达到要求、位置误差回到规定误差带并持续 `T_hold`；普通安全超时不得自动计为成功。
3. **最小净空**：无人机碰撞包络到障碍物表面的直接几何距离，单位为米；LiDAR 距离作为单独感知指标。

**次要指标**

- 名义轨迹位置 RMSE、最大误差、避障期 RMSE、恢复期 RMSE；
- 避障后回到误差带的恢复时间；
- 实际路径长度与无障碍参考路径长度之比；
- 局部偏移的一阶差分、二阶差分、动作切换率和反向切换率；
- 安全过滤干预率、候选动作与实际动作差异、`h` 和预测裕量分布；
- 传感器超时、reset 失败、协议外试验和 `shield_infeasible` 比例。

每个指标在“指标字典”中固定数据源、单位、采样频率、公式、缺失值处理和统计单位。分析脚本必须能从原始日志重算汇总表。

### 5.5 统计分析

- 碰撞率和成功率报告原始计数、比例和 95% Wilson 置信区间；
- 连续指标报告中位数、四分位距和按场景聚类 bootstrap 95% 置信区间；
- 方法比较使用相同布局的配对差异，bootstrap 重采样单位为场景而不是单个时间步；
- 对多种子结果报告均值/中位数、最优种子、最差种子和种子间分布；
- 若使用显著性检验，提前指定检验、效应量和多重比较校正，不只展示有利的 p 值；
- 测试协议冻结后不根据结果更改主要指标或阈值。代码错误修复必须升级协议版本并整批重跑。

### 5.6 预注册的 Go/No-Go 假设

这些阈值在看到盲测结果前冻结：

- **H1 安全收益**：P 相对 B2 的碰撞率绝对下降至少 5 个百分点，且配对 bootstrap 结果显示方向稳定；
- **H2 控制代价**：P 相对 B1 的任务成功率下降不超过 5 个百分点，且总体轨迹 RMSE 增幅不超过 20%；
- **H3 自适应项有效性**：在高曲率或扰动子集上，P 相对 A1 的碰撞率下降至少 5 个百分点，或最小净空分布有明确改善；
- **H4 种子稳健性**：至少 4/5 个策略种子与总体方向一致，结论不能由单个 best checkpoint 或单个种子贡献超过一半的收益；
- **H5 仿真可信度**：几何净空、LiDAR 距离和接触事件在抽查样本上的差异满足预设容差，所有异常均有分类记录。

如果 H1–H5 未全部支持，仍可投稿，但必须缩小题目和结论，明确报告负结果，不把未支持假设写成贡献。

## 6. 仿真验证、复现与论文证据链

### 6.1 验证与确认（V\&V）

为提高系统仿真学报录用机会，论文需要独立于算法结果展示以下检查：

1. **软件验证**：扇区转换、坐标旋转、动作几何、净空计算、RMSE、恢复时间、随机清单和日志字段的单元测试；
2. **模型验证**：无障碍直线、圆和阶跃响应，检查名义参考、设定点和实际轨迹的关系；
3. **碰撞交叉验证**：几何代理和 LiDAR 观测分别记录，在典型成功/失败轨迹中按时间戳对齐；若 H5 要求接触真值，再加入独立接触事件列，不把插件输出混入代理定义；
4. **场景确认**：所有测试布局经过可行路径检查，排除“本来就不可通过”的样本；
5. **鲁棒性确认**：加入轻度传感噪声、决策延迟和闭环响应变化，观察方法是否仍保持方向一致；
6. **复位确认**：同一场景清单重复复位时初态、轨迹相位、障碍布局和观测新鲜度一致。
