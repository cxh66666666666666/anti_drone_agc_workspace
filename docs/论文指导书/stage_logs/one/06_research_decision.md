## 1. 接口选择依据

### 1.1 现状（来自 `01_baseline_audit.md`）

- **唯一真实执行链路**（`01` §3）：任务路径 → 候选偏移/局部控制（`/rl_planner/local_offset`、`/rl_planner/local_control`，10 Hz）→ LQR 外环 → **位置设定点** `/mavros/setpoint_position/local`（50 Hz）→ PX4 内环 → 机体。
- **延迟数值**（`01` §3.7，实测冻结）：阶跃纯延迟 `0.24/0.24/0.28 s`，时间常数 `0.85/0.85/0.80 s`，`position_lead_time=0.80 s`（节点默认仍 `0.02 s`），`tau_react=0.84 s`。
- 位置接口下，`position_lead_time` 是**实验协议参数**，不改节点默认；接口是位置外环、不是速度指令。

### 1.2 制动可复现性（来自 `02_brake_hold.md`）

- 在**位置设定点接口**上，「把设定点回退到命令时刻实测位置并保持（候选 C）」实现制动是**可复现**的：纵向 3/3、横向 3/3 达到停稳判据。
- 命令生效延迟 `0.18—0.20 s`；**初始减速段**减速度约 `0.67 m/s²`（0.5→0.1 m/s 用 ~0.7 s）；**整窗线性拟合仅 0.041—0.053 m/s²**——剖面**非等减速**。
- 净漂移 `cm 级`（0.019—0.052 m）但**瞬态过冲 ~0.24 m**；停稳后 5 s 尾段速度 ≤0.05 m/s、位移 ≤0.08 m，**未失控漂移**。
- 明确**不沿用旧 `a_brake=0.044 m/s²`**。

### 1.3 决策

**保留现有「位置参考/位置设定点」接口，不切换速度设定点接口。**

理由：
1. 位置接口是**唯一被验证过的真实链路**（`01` §3），切换会作废整条既有的辨识/协议与冻结数据；
2. 在位置接口上制动/保持**已实测可复现**（`02`），满足"先确认接口能形成可重复制动/保持行为"这一切换前提，故**无需**切换；
3. 指导书 §5.2 默认优先保留位置接口，并要求"不能把 `LQR 输出→位置设定点` 简化成直接加速度控制"——保留接口正好要求我们把外环 + PX4 视为**组合闭环**来辨识。

### 1.4 第六周前的复核点（触发则切换）

出现以下任一情形，在**第六周前**改为明确的速度设定点接口并重新辨识（旧接口仅留背景对照）：
- **R1 可重复性**：延迟/滞后在**更宽速度档或转弯**下不可重复（当前仅 0.5 m/s 与 1.0 m/s 直线档，见 `02` §8、`04` §7）；
- **R2 制动充分性**：位置接口无法在不切模式的情况下实现"必要减速/制动"（尾段速度非严格归零、仍 cm 级往复微动，`02` §7）；
- **R3 误差范围过宽**：接口滞后导致的误差集合在位置接口上过宽，使**几乎所有通道都不可行**（指导书 §11 对应风险信号）。

## 2. 前 3 个月工作量预算

### 2.1 口径

对齐指导书 §9.1 工作包口径。前 3 个月约 13 周，按每周 21—35 h，合计约 **273—455 h**（低—高）；相对前 12 个月主动研究预算 850—1150 h 占约 **30—40%**，因 R0、检索与接口/制动/验证集中在前期而**前置倾斜**。

### 2.3 关键风险与止损点（对齐 §11）

| 风险 | 识别信号 | 止损/决策 |
|---|---|---|
| 新颖性被现有工作覆盖 | v2 差异表显示最近邻已处理相同接口/滞后/集合且证据更充分 | **第六周前**调整具体问题；不以"首次用于本平台"替代贡献 |
| 标准强基线已足够 | B2/B3 与 P 效果相同或更好 | 检查是否有计算/保守性取舍；无则**停止该方法的创新主张** |
| 误差范围过宽 | 几乎所有通道不可行 | 找主因（延迟/感知/模型）、改进模型或**缩小真实适用域**；不任意缩裕量 |
| 模型覆盖不成立 | 回放测试残差频繁越界（`under_covered>0`） | **停止安全保证主张**，修正辨识/集合；不得仅删异常 |
| 安全靠提前结束获得 | shield 失败多、尾段碰撞未统计 | 固定尾段观察与任务失败规则后**重评全部方法**（`02` §7 已提供尾段窗口） |
| 感知改造吞噬时间 | 长期在建图/定位而非方法 | **定高、局部已观测自由空间、冻结感知模块**，降低感知贡献主张 |
| 接口不可重复（R1—R3） | 见 §1.4 | 第六周前**切换速度设定点接口**并重新辨识 |

### 2.4 与 §9.1 六工作包的对应关系

本 3 个月覆盖 §9.1 的**前三个工作包**（检索/理论、接口/制动/验证、拟议方法）与**第四个工作包**（强基线/消融/验证集）的起步；第五、六工作包（正式实验/跨配置统计、写作/首投）按 §9.1 在后续月份展开。3 个月结束时对应 §9.2 的**R0 决策输入**：是否需要按"问题有价值但候选方法无新增内容"分支调整，或继续主线。
