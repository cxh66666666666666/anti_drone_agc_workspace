## 2. 两周结论

### 2.1 旧距离/瞬时动作模型在哪种可重复条件下失败

（全部引自 `04_mechanism_counterexamples.md` 与其原始结果 `experiments/paper_v3/mechanisms/results/*.json`）

1. **同位置、同几何净空、不同速度**：制动所需扫掠距离随速度增大约 **2.13×**（0.239→0.509 m）；在同阈值纯距离判据下，**3/3 高速样本被误判安全**。
2. **同误差模长、不同方向**：模长 0.20 m 时，朝墙使净空 0.30→0.10 m（危），平行不改变净空（安）；**方向盲的标量膨胀 κ=1 在 7 个朝向中 4 个误拒**、κ=0.5 则漏判朝墙。
3. **同路径、不同执行滞后**：以"设定点瞬时实现"为差模型时，命令变化处残差 **L=0 已 0.82 m、L=0.24 s 达 1.04 m**（延迟边际 0.216 m）。

**关键**：给规则法与预测法**同一份含备份制动的可达距离**后，三个反例**全部仍成立**（`fair_brake_compare.json`，`all_survive=true`）——问题源于**信息/表示**（速度、方向、延迟），不是"没有刹车"。

### 2.2 标准方法能解决多少

（引自 `03_b1_b2_design.md`）

- **B1（标准标称预测安全过滤）**：给定状态/输入定义（对齐位置设定点接口）、点预测、备份制动、相位/进度调节、约束判据（离散 DCBF `Δh+αh≥ε_pred`）与终端/超时处理。
- **B2（延迟增广、方向相关的鲁棒预测安全过滤）**：在 B1 之上**只改一项**——误差集合表示（方向相关 `E(n)` + 支持函数 `σ_E(n)`，默认 `E={0}`）及延迟增广状态/集合传播；其余（中心预测、参数范围、输入权限、校准数据、备份、相位调节）**全部共享**。
- **未完成/如实说明**：B1/B2 **目前仅为设计，尚未闭环实现**；现有代码存在 6 项落地阻塞（恒速预测、真值几何 `_safety_obstacles()`、六动作集无制动档、偏移上限当速度、空集立即终止不复位证明、交叉验证不验证未来），见 `03` §5。因此标准方法"能解决多少"**尚无闭环证据**，仅能确认设计上可覆盖反例 1—3 所指的机制。

### 2.3 剩下的具体问题

1. **误差集合的可辨识性与紧度**：在位置接口上，`σ_E(n)` 的标定数据与覆盖性需闭环验证（`prediction_replay_format_v1.md`，判据 `under_covered==0`）。
2. **接口延迟的时变性与可重复范围外的行为**：当前仅 0.5/1.0 m/s 直线档、2.0 m 高度、无障碍；转弯与更宽速度档未验证（`06` §1.4 R1）。
3. **真值几何隔离**：主实验须改纯局部感知输入，否则不能主张"纯 LiDAR、未知环境"（`01` §4）。
4. **闭环覆盖验证尚未做**：反例 2/3 为**模型级**，尚未在闭环仿真注入"同净空/不同方向/不同延迟"观测（`04` §7）。
5. **与最近邻的区分**：DDSF 与 Layered Safety 须纳入正式对照；Wabersich–Zeilinger / RTD / FaSTrack **原文未读**，差异表 v1 **尚不能确认可区分**（`05` §2）。
6. **制动档适配**：六动作集无制动档、备份制动需新增通道（`03` §5）。
