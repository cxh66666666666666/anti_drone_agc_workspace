# 08 导师讨论备忘录（一页）

## 1. 问题

在**位置设定点执行**（带未知纯延迟与一阶滞后）的无人机避障中，**能否用"执行历史约束的方向相关制动可达范围 + 可执行制动备份"**，比"只看当前距离/瞬时动作"的旧模型、以及"标准标称预测安全过滤"（B1），**同时减少危险误放行与过度保守**？

## 2. 证据（均为本地已产出文件）

- **旧模型失败的可重复条件**（`04_mechanism_counterexamples.md`，含原始 `experiments/paper_v3/mechanisms/results/*.json`）：
  - 同净空、更高速度：制动扫掠距离 0.239→0.509 m（**×2.13**），纯距离判据 3/3 高速样本**误判安全**；
  - 同误差模长、不同方向：模长 0.20 m 下朝墙净空 0.10 m（危）vs 平行 0.30 m（安），标量膨胀 κ=1 有 **4/7 误拒**；
  - 同路径、不同执行滞后："瞬时实现"残差 **0.82→1.04 m**（延迟边际 0.216 m）；
  - **公平制动后三反例全部仍成立**（`fair_brake_compare.json`，`all_survive=true`）——问题不是"别人没刹车"。
- **实物/仿真执行事实**（`02_brake_hold.md`）：位置接口制动**可复现**（纵 3/3、横 3/3 停稳）；命令延迟 0.18—0.20 s；初始减速段 ~0.67 m/s²、**非等减速**；净漂移 cm 级但**瞬态过冲 ~0.24 m**。
- **接口与真值权限**（`01_baseline_audit.md`）：唯一真实链路为位置设定点外环 + PX4 内环；`_safety_obstacles()` 用**真值几何**，不能支撑"纯 LiDAR、未知环境"。
- **标准方法与最近邻**（`03_b1_b2_design.md`、`05_nearest_neighbor_table_v1.md`）：B1/B2 设计就绪；但 DDSF/Layered Safety **尚未在正式对照纳入**，Wabersich–Zeilinger/RTD/FaSTrack **原文未读**。

## 3. 当前结论

1. 旧"距离/瞬时动作"模型的失败是**表示问题（速度、方向、延迟）**，不是"缺刹车"；已用可复现反例 + 公平制动固定住。
2. 标准方法（B1/B2）**设计完成**，能覆盖部分问题；但 **B1/B2 尚未闭环实现**，现有代码有 6 项落地阻塞（恒速预测、真值几何、无制动档、偏移=速度口径、终止不复位证明、交叉验证不验证未来），见 `03` §5。
3. 拟议贡献**当前还不能声称与最近邻可区分**（`05` §2）：须补读三篇原文、并把 DDSF 与 Layered Safety 纳入正式对照。
4. 接口决策：**保留位置参考接口**（理由与第六周复核点见 `06` §1）。
