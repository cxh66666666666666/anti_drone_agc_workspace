# 制动/保持命令规范与低速纵横向短段实测（Task 2）

> 阶段：`publication_plan.md` §9.3 第 4—7 天「验证刹车与标准方法」
> 日期：2026-09-24；环境：ROS Noetic + PX4 SITL + Gazebo + MAVROS，headless。
> 规范：`experiments/paper_v3/protocols/brake_hold_protocol_v1.md`
> 脚本：`experiments/paper_v3/scripts/brake_hold_test.py`
> 数据：`experiments/paper_v3/identification/brake_hold/<run_id>/`（`trace.csv` + `meta.json`）

## 0. 结论速览

- 在当前位置设定点接口上，用「把设定点回退到命令时刻的实测位置并保持」实现制动是**可复现**的：
  纵向 3/3、横向 3/3 均达到停稳判据（状态 `ok`）。
- **命令生效延迟** 0.18—0.20 s；**初始减速段减速度**约 0.65—0.69 m/s²（0.68 s 内 0.50→0.10 m/s）；
  但**整窗线性拟合**仅 0.041—0.053 m/s²，两者差一个数量级——因为减速剖面**不是等减速斜坡**，
  而是「先快速减速 → 位置过冲 → 缓慢振荡收敛」（见 §3）。
- **最大漂移**（命令时刻→尾段末即时位置，meta 口径；§4）仅 0.019—0.052 m；但**瞬态过冲**（沿向峰值外扩）约 0.22—0.25 m。
- **明确声明：本次不沿用阶段 1 的 `a_brake = 0.044 m/s²`（p10）**。该值在本批数据里恰好接近
  「整窗线性拟合」的量级，但它描述的是**缓慢收敛尾段**、而非制动能力，不可作为制动下界使用。

## 1. 口径与制动定义（摘要，详见规范）

- 接口：`/mavros/setpoint_position/local`，本脚本在 OFFBOARD 下以 50 Hz 独占发布。
- **制动触发**：巡航设定点沿方向单位向量前进满 `cruise_distance`（默认 3.0 m）的那一拍，记为
  `t_brake_cmd`。
- **制动定义**：在 `t_brake_cmd` 采集 `/mavros/local_position/pose` 实测位置 `p_b`，此后设定点
  恒为 `p_b`（不冻结前进参考、不切 PX4 内置 HOLD）。
- **终止判据**：`|v| < 0.05 m/s` 连续 2.0 s。速度来源为 **Gazebo 机体真值**（见 §7 说明）。
- **尾段观察**：停稳后再记录 5.0 s。
- 记录两路数据源：MAVROS（pose/velocity_local）与 Gazebo（`/gazebo/model_states`，机体 `iris`）。


| run_id | 方向 | 状态 | 说明 |
|---|---|---|---|
| `long_01` | 纵向 | `startup_failed` | 未进入 OFFBOARD（脚本服务返回值用法错误，非物理失败，见 §6） |

| `lat_01` / `lat_02` / `lat_03` | 横向 | `ok` | 有效运行 |

有效样本：**纵向 3 次、横向 3 次**（各含 `trace.csv` 逐样本与 `meta.json`）。

## 3. 减速过程

速度剖面（以 `long_03` 为例，Gazebo 真值）呈三段：
`0.50 m/s →（约 0.7—0.9 s 快速下降）→ ≈0.05 m/s →（速度回升至 ≈0.16 m/s，位置过冲后回摆）
→（缓慢衰减）→ 稳定于 ≤0.05 m/s`。故采用**两个口径**分别报告：

### 3.1 整窗线性拟合（规范 v1 定义）

窗口 = `[t_drop, t_stop]`，`t_drop` 为命令后速度首次跌破 `0.95·v_peak`、`t_stop` 为停稳时刻；
对 `|v| = a + b·t` 最小二乘，减速度 `= -b`。窗口相对 `t_brake_cmd` 计时。
（数值取自各 run `meta.json` 的 `decel_fit`，按上述定义可复算。）

| run | 减速度 (m/s²) | 窗口 rel (s) | 样本数 | RMSE (m/s) |
|---|---|---|---|---|
| long_03 | 0.0490 | 0.18 — 3.30 | 157 | 0.0728 |
| long_04 | 0.0426 | 0.20 — 3.56 | 169 | 0.0691 |
| long_05 | 0.0444 | 0.20 — 3.38 | 160 | 0.0734 |
| lat_01 | 0.0411 | 0.18 — 4.14 | 199 | 0.0630 |
| lat_02 | 0.0526 | 0.18 — 3.18 | 151 | 0.0665 |
| lat_03 | 0.0489 | 0.18 — 3.30 | 157 | 0.0669 |

RMSE 偏大（0.063—0.073 m/s ≈ 0.1×峰值）说明**该窗口内速度并不线性**，此拟合描述迟缓收敛段。

### 3.2 初始减速段拟合（补充口径，报告级分析）

窗口 = `[t_brake_cmd, t_ramp]`，`t_ramp` 为命令后速度首次 ≤0.10 m/s 的时刻；对该段做同样的线性拟合。
（由 `trace.csv` 重算；方法：取 `phase∈{brake}` 且 `t≥t_brake_cmd` 的 Gazebo 速度样本。）

| run | 初始减速度 (m/s²) | `t_ramp` (s) | 样本数 | RMSE (m/s) |
|---|---|---|---|---|
| long_03 | 0.685 | 0.70 | 36 | 0.0230 |
| long_04 | 0.671 | 0.72 | 37 | 0.0237 |
| long_05 | 0.673 | 0.74 | 38 | 0.0244 |
| lat_01 | 0.651 | 0.74 | 38 | 0.0212 |
| lat_02 | 0.669 | 0.70 | 36 | 0.0226 |
| lat_03 | 0.673 | 0.68 | 35 | 0.0242 |

初始段 RMSE 仅 0.02 m/s，拟合良好：**制动初期确是近似等减速**，减速度约 0.67 m/s²（0.5→0.1 m/s 用 ~0.7 s）。
纵横向差异不显著。

## 4. 最大漂移

- **采集脚本口径（`meta.json` 的 `max_drift_m`）= 命令时刻位置 → `analyze()` 读取的即时 MAVROS 位置的水平位移**。
  按 `scripts/brake_hold_test.py`：`p_brake` 在**制动触发那一拍**取 `rec.mav_pos()`（即时值）；
  `p_stop = rec.mav_pos()` 在 `analyze()` 内读取，而 `analyze()` 于 **5 s 尾段观察结束后**才被调用，
  故端点实为**尾段末的即时值**（≈ `trace.csv` 末样本），并非「停稳那一拍」，也**不对应 trace 中某一固定行**：

| run | 净漂移 (m) | 沿向分量 (m) | 横向分量 (m) |
|---|---|---|---|
| long_03 | 0.0478 | 0.0435 | 0.0197 |
| long_04 | 0.0524 | 0.0458 | 0.0255 |
| long_05 | 0.0428 | 0.0357 | 0.0236 |
| lat_01 | 0.0325 | -0.0014 | 0.0324 |
| lat_02 | 0.0360 | -0.0250 | 0.0260 |
| lat_03 | 0.0189 | -0.0171 | 0.0081 |

  该口径**不能由 trace 精确复算**（端点为订阅者即时值）：与「`brake` 首样本位置 → 末样本位置」相比，
  6 次 run 偏差均 ≤0.0011 m（如 long_03 末样本复算 0.0489 vs meta 0.0478），差异仅来自订阅者时序。

- **trace 复算口径**（规则：`brake` 阶段首个样本的 MAVROS 水平位置 → 首个满足 `|gz_speed|<0.05`
  起持续 2 s 的样本（即停稳窗口起点，与 meta 的 `t_stop_ros` 同拍）的 MAVROS 水平位置）：

| run | 净漂移 (m) | 沿向分量 (m) | 横向分量 (m) |
|---|---|---|---|
| long_03 | 0.0356 | 0.0283 | 0.0216 |
| long_04 | 0.0228 | 0.0200 | 0.0110 |
| long_05 | 0.0365 | 0.0343 | 0.0126 |
| lat_01 | 0.0763 | 0.0026 | 0.0763 |
| lat_02 | 0.0617 | 0.0134 | 0.0602 |
| lat_03 | 0.0541 | 0.0047 | 0.0539 |

  两口径差 **−0.030—+0.044 m**（符号不固定）：一端取「停稳窗口起点」、一端取「尾段末即时值」，
  其间机体在保持点附近仍有厘米级往复微动，两点水平位置可上可下。**本节以可复算的 trace 口径为主。**

净漂移量级 0.02—0.05 m（trace 口径 0.02—0.08 m），且终态基本回到保持点（纵向沿向略为正、横向沿向略为负，均在厘米级）。

> **与 `04_mechanism_counterexamples.md` / `ce1_speed_sweep.json` 的 `net_drift_m` 是不同定义 + 不同数据源**：
> 后者为 **Gazebo 真值**，取「`brake` 阶段首样本位置 → 停稳（`|gz_speed|<0.05` 持续 2 s）**窗口末样本**位置」。
> long_03 三口径对照：**meta（MAVROS，尾段末即时值）0.0478 m / trace-mav 复算（停稳窗口起点）0.0356 m /
> ce1（Gazebo，停稳窗口末样本）0.0287 m** —— 三者口径与数据源不同，并不矛盾。

- **瞬态峰值过冲**（补充，Gazebo 真值；制动后沿向/横向相对 `p_b` 的最大外扩）：
  （复算规则：`brake`+`tail` 阶段各样本的 Gazebo 位置相对 `p_b` 的沿向/横向分量分别取最大值；可复算。）

| run | 沿向峰值 (m) | 横向峰值 (m) |
|---|---|---|
| long_03 | 0.230 | 0.032 |
| long_04 | 0.240 | 0.041 |
| long_05 | 0.246 | 0.048 |
| lat_01 | 0.239 | 0.089 |
| lat_02 | 0.223 | 0.070 |
| lat_03 | 0.216 | 0.071 |

**关键**：制动命令后机体沿原方向仍会外扩 0.22—0.25 m（约 0.5 m/s × 0.5 s 的不可瞬时停止部分），
随后被位置环拉回。做制动可达集/安全裕量时必须用**峰值过冲**，不能用净漂移。

## 5. 命令生效延迟

`t_brake_cmd` → 速度首次跌破 `0.95·v_peak` 的时间：**0.18—0.20 s**
（纵 0.18/0.20/0.20，横 0.18/0.18/0.18），与阶段 1 阶跃纯延迟（0.24/0.24/0.28 s）同量级、略小。

## 6. 失败形态

1. **`startup_failed`（`long_01`）**：脚本 `set_mode` 服务返回值读取错误
   （`req.response.mode_sent` 应为 `resp.mode_sent`），误判「未进入 OFFBOARD」。
   已修复；属**脚本启动缺陷**，非物理失败。原始记录见 `long_01/meta.json` 与 `long_01/start_sim.log`。
2. **`not_settled`（`long_02`）**：以 MAVROS `velocity_local` 判停稳时，其速度估计在停稳后仍残存
   ±0.05 m/s 抖动，无法满足 `|v|<0.05` 连续 2 s。Gazebo 真值同期已 ≤0.03 m/s（物理已停）。
   属**测量源局限**，促成 §7 改用真值判停稳。原始记录见 `long_02/`。
3. 本批未出现 `drift_exceeded`（净漂移 ≪ 1.0 m 阈值）与 `timeout`。

## 7. 停稳判据的数据源与尾段观察

- **改用 Gazebo 真值速度**作停稳主判据（规范 §4）：MAVROS 速度估计噪声与 0.05 m/s 阈值同阶。
- **停稳后尾段（≥5 s）漂移**（Gazebo 真值；复算规则：停稳判定成立那一拍——`|gz_speed|<0.05` 持续满 2 s 的**窗口末样本**——的 Gazebo 位置 → 尾段末样本的 Gazebo 位置；可复算）：

| run | 尾段最大速度 (m/s) | 尾段位移 (m) |
|---|---|---|
| long_03 | 0.043 | 0.0359 |
| long_04 | 0.033 | 0.0348 |
| long_05 | 0.043 | 0.0389 |
| lat_01 | 0.042 | 0.0793 |
| lat_02 | 0.049 | 0.0265 |
| lat_03 | 0.040 | 0.0095 |

停稳后 5 s 内速度仍 ≤0.05 m/s、位移 ≤0.08 m，**未观察到失控漂移**；但速度并非严格归零，
机体在保持点附近有厘米级、缓慢的往复微动。这印证指导书 §7.7：任务/制动判定结束 ≠ 立刻完全静止，

## 8. 样本量与适用范围

- 定义：单次运行 = 一次完整「起飞 → 3.0 m 巡航 → 制动 → 停稳 → 5 s 尾段」，共 6 次有效（纵 3、横 3）。
- 逐样本：各 run `trace.csv` 约 1392—1475 行（50 Hz），含 MAVROS 与 Gazebo 两路。
- 速度档：**0.5 m/s**（仅此档，不外推）。
- 高度：**2.0 m**（与场景一致，仅此档）。
- 方向：**longitudinal（map +X）/ lateral（map +Y）**。
- 环境：**无障碍**、headless、单一 OFFBOARD 位置设定点接口。

## 9. 与旧 `a_brake` 及阶段 1 的关系（显式声明）

- **本次重新测量，不沿用旧 `a_brake = 0.044 m/s²`（3 次拟合 p10）**。
- 有趣但需澄清的巧合：新测「整窗线性拟合」减速度 0.041—0.053 m/s² 与旧 p10 量级相同，
  但这些数值**都描述制动后的缓慢振荡收敛尾段**，**不代表制动能力**；真正的初期减速度约
  **0.67 m/s²**（约 15×以上）。因此无论新旧，把这类整窗拟合值当作制动下界都是错误的。
- 拟合窗口未沿用阶段 1 的「峰值至末端前 0.2 s」固定切尾：本规范按速度跌落阈值自动定窗，
  并额外给出初始减速段口径以暴露非等减速本质。

## 10. 与他处不一致 / 预期外发现

1. 制动剖面**非等减速**：快速减速（~0.67 m/s²）后出现过冲与回摆，整窗线性拟合严重低估制动。
2. MAVROS 速度估计噪声（±0.05 m/s）足以妨碍 0.05 m/s 级停稳判定，需用真值或滤波。
3. 净漂移小（cm 级）但**瞬态过冲大**（~0.24 m），二者不可混用。
4. 横向运行的横向峰值过冲（0.07—0.09 m）大于纵向（0.03—0.05 m），或与侧向控制增益/耦合有关，
   样本少、未下结论。
