### 2.1 Nouwens, Paulides, Heemels —— 在线约束移除（soft-constrained ca-MPC）

- 题名：*Accelerating soft-constrained MPC for linear systems through online constraint removal*
- 版本/发表处：arXiv:2410.17646v1（6 页，2024-10-23）；**PDF 页脚自述 DOI `10.1109/CDC49753.2023.10383769`、©2023 IEEE**，即由 PDF 正文核实的 CDC 2023 版本。
- 读取深度：**原文**。
- 页码与公式/定理：椭球定义 Eq.(4) 与「椭球—半空间包含判定」Eq.(5) 在 **p.2**；一阶最优性外包椭球 Eq.(10)—(11) 在 **p.2—3**；筛选映射 Eq.(12)—(13) 在 **p.3**；`Algorithm 1`（soft-constrained ca-MPC）在 **p.4**。
- 归档文件名：`Nouwens_OnlineConstraintRemoval_softMPC.pdf`；SHA-256 `5577a02838fd598695e78e1a1e1b52ee035644530a24c5969791ecd39663f122`。
- 算法与关键假设（本人复述）：
  - 对象是**线性时不变（LTI）离散模型 + 二次代价 + 不等式约束（本变体全为软约束）**的收缩 MPC（问题 (2)）。
  - 关键思想：一个凸问题的极小值点满足一阶最优性，其负梯度落在约束集法锥内；用一个**可行输入序列** `ṽ_k` 把法锥外包，得到**外包极小值点的椭球** `E(P,q)`（Eq.(10)—(11)）；再用 Eq.(5) 判定「椭球是否整个落在某约束半空间内」——若是，则该约束**不可能被触到**，可在简化问题 (3) 中删除。删除同时伴随软约束松弛变量维数下降。
  - 保守性/等价性前提：**假设 `ṽ_k` 不违反任何约束**（保证椭球与半空间交集非空，Section II-E）；`ṽ_k` 由上一拍最优解移位＋末端补零生成。删约束**不改变极小值点**，故**精确继承**原 MPC 的稳定性与可行性。
  - 计算：筛选开销 `2n_c(n_v+1)+3n_v²+n_v+1`，随约束数 `n_c` **线性**；算例 2030 约束降到最多 62（3.1%）。
  - 对本文拟议问题：**否**。它是固定模型 QP 的**约束**筛选，**不涉及执行延迟/延迟分支**，**没有每拍 rollout 预算**，**没有共同备份终端**概念。

### 2.2 SHIELD —— 对偶与强凸性的可认证安全筛选

- 题名：*SHIELD: Scalable Optimal Control with Certification using Duality and Convexity*
- 版本/发表处：arXiv:2605.09171v1（9 页，2026-05-09）；发表处**待核验**（原文未标会议/期刊）。
- 读取深度：**原文**。
- 页码与公式/定理：`Proposition 1`（筛选条件 + `ε_crit`）与 `Corollary 1` 在 **p.3**；`Theorem 1`（把安全筛选推广到**任意可行对偶**，用对偶间隙界 gap）在 **p.4**；`Algorithm 1`（SHIELD）在 **p.5**；筛选索引集 Eq.(12)(16) 在 **p.4**。
- 归档文件名：`Kim_SHIELD_ConstraintScreening.pdf`；SHA-256 `54a07a68e4514bd988f9a3f37339c8001cde9263c7178f0c860f9dd1cec19208`。
- 算法与关键假设（本人复述）：
  - 对象是 **ℓ1 正则凸程序**（含时间变化约束/变量/代价），用**强凸性 + 拉格朗日对偶 + Slater**导出**可认证的约束/决策变量筛选**。
  - 关键步骤：先用学习分类器 `π_class` 预测对偶类别（哪些 `µ_i>0`、哪些 `g_i` 达 `λ`），只解**降维对偶**再投影回可行域；然后按 `Theorem 1`——若 `‖µ_i‖₂ + gap ≤ ε/ζ` 且 `ε ≤ (σζ²/2)·min_i 1/L_i²`，则该约束可安全删；若 `‖g_i‖∞ + gap < λ`，则相应决策变量必为零、可删。
  - 保守性/等价性前提：`Assumption 1` 强凸（`σ`-强凸、`σ̄`-Lipschitz）、`Assumption 2` Slater、`Assumption 3` 约束 `L_i`-Lipschitz。对**screenable 约束做 ζ-收紧**（`f̃ ≤ −ζ`）以留出安全裕量，从而删约束后仍满足**原始**约束。
  - 计算与回退：**筛选不确定就退回解全问题**（最坏行为等价标准 MPC）；算例 35×（含外挂）加速、6.8% 约束保留。
  - 对本文拟议问题：**否**。对象是 ℓ1 凸程序的约束/变量，**不涉及时间延迟分支**；其回退是**算力回退**（解全问题），不是**安全备份**；**没有每拍 rollout 预算口径**。

### 2.4 Shaw Cortez, Drgoňa, Vrabie, Halappanavar —— 鲁棒高效的预测安全过滤（事件触发）

- 题名：*A Robust, Efficient Predictive Safety Filter*
- 版本/发表处：arXiv:2311.08496v2（14 页，2024-04-26）；发表处**待核验**（原文未标会议/期刊）。
- 读取深度：**原文**。
- 页码与公式/定理：`Definition 1`（N-步鲁棒离散时间 barrier）在 **p.3**；`Algorithm 1`（事件触发式鲁棒安全过滤）在 **p.6**；`Corollary 1`（Alg.1 的安全性）在 **p.6**；`Theorem 3`（1-步版 + 条件 (21)）在 **p.7**；`Algorithm 2`（1-步事件触发）在 **p.8**。
- 归档文件名：`ShawCortez_Robust_Efficient_PredictiveSafetyFilter.pdf`；SHA-256 `72c9c7c3ad68ebe8b6ba59c7536746fcc66da46fa2adff68e27dff66e1445620`。
- 算法与关键假设（本人复述）：
  - 对象是**离散时间、时变、有界加性扰动**下的安全过滤；用**鲁棒离散时间 barrier**（`Assumption 1`：`f` 局部 Lipschitz、扰动有界 `L_d`；`Assumption 2`：`b`、`h` Lipschitz）。
  - 关键步骤：`Alg.1` 先对**名义控制做 N 步开环 rollout**，若整段都落在鲁棒安全集 `X^l(k)`/终端集 `X_f^N(k)` 内，**直接发布名义控制、不求解过滤 QP**；否则才解安全过滤 (13)。1-步版 `Alg.2` 只检查 `h(x_k,k)>a`，无需 dynamics rollout，其中 `a ≥ L^h_x(L_f+L_d)+L^h_k`（定理 3 条件 (21)）。
  - 保守性/等价性前提：`Assumption 3`（`h` 是 N-步鲁棒 barrier）、`Assumption 4`（鲁棒安全集非空、终端集包含关系）。**跳过计算不损失安全**：`Theorem 1`/`Corollary 1` 保证可行性对所有 `k` 成立、`x_k∈X(k)`。
  - 代价/权衡：`N` 越大鲁棒裕量越大但计算越重；算例较文献 [12] 快 66%。
  - 对本文拟议问题：**部分（不含延迟分支）**。它给出「**何时不必计算且不损安全**」的调度，但判断对象是**名义控制的单条轨迹**（单一模型 rollout），**不是延迟分支集合**；其「跳过 vs 覆盖」在**无执行延迟**下成立，**未覆盖逐拍任意延迟的多个后继分支**。

## 4. 单一可证伪候选步骤

> 只选**一个**候选步骤。术语「延迟分支」沿用 `two/15` §2—3：允许延迟集合 `D`（辨识区间离散，如 `branches_s=[0.18,…,0.30]`，`n_branches=7`），主转移规律为**逐拍任意**（`per_step_arbitrary`）；sound 基线为 `two/15` 的**逐拍所有后继可达集传播**。

### 4.1 候选步骤：固定每拍传播预算下的「延迟分支支配筛选」（Delay-Branch Dominance Screening, 简称 DBDS）＋共享备份终端的包含证书

**输入（每拍 `k`）**

1. 控制侧可得的状态估计（实测位置/速度）与已发布命令历史（**不读真值延迟**）；
2. 本拍候选动作序列 ＋ 共同备份（制动保持）序列；
3. 允许延迟分支集合 `D` 及其转移规律（主：逐拍任意）；
4. 已确认自由空间 `F_k`，以及**预测时域内可能成为净空约束边界的法向过近似集合** `N̄`；
5. 本拍确定性传播预算 `B`（分支 rollout 上限）。

**输出（每拍 `k`）**

1. 本拍**实际传播的分支子集** `D' ⊆ D`，且 `rollout(D') ≤ B`；
2. 由 `D'` 得到的可达集包络与安全判定（接受 / 拒绝 / 转备份）；
3. 一份**分支筛选证书**：对每个被筛掉的分支 `b ∈ D\D'`，给出它在 `N̄` 上的**支持函数支配证据** `σ_{P_b}(n) ≤ max_{b'∈D'} σ_{P_{b'}}(n) + slack`（∀`n∈N̄`），并声明该关系对「在 `D'` 的每个分支上再拼接**任意后继延迟分支**」封闭；
4. 若证书无法在预算 `B` 内建立 → **不作筛选**，回退到 sound 全分支传播，记 `timeout/fallback`（不计为安全违例）。

**保守性条件（保持覆盖 / 不虚报安全）**

当且仅当以下两条同时成立时，筛选后的包络 `⊇` sound 全分支包络、安全判定与 sound 一致：

- (C1) **法向支配**：对所有 `n ∈ N̄`（`N̄` 为**时域内**可能活跃合法的净空约束法向的过近似，而非本拍活跃法向），被筛分支的可达集位置投影支持函数不超过保留分支支持函数的最大值（含 `slack`）；
- (C2) **后继封闭**：对 `D'` 的每一分支，在任意允许后继延迟上重做传播，其包络仍被 `D'` 的证书包络覆盖（保证“逐拍任意”不破坏支配）。

任一条不成立 → 该分支必须保留；预算不足 → 回退全传播。

**一个能让它失败的例子（具体到场景与机制）**

- 场景：**走廊沿航向接近一堵墙、随后拐向一扇门**；允许延迟 `D = {9,10,…,15}` 拍；真值延迟**逐拍任意**。
- 机制：**naive 版本**只在**本拍已确认自由空间的当前活跃法向**上做支配检查。`k` 拍真值延迟取小端，较长延迟分支的**前向（沿航向）支撑**被较短延迟分支支配，于是长延迟分支被筛掉；`k+1` 拍真值延迟跳到区间端点，且**新出现的活跃法向是侧向门框法向**，此时被筛掉的长延迟分支**侧向支撑最大**。由于筛选只对旧的当前活跃法向成立、未对时域内可新出现的法向成立，被筛分支的真实运动落在证书声明的包络之外 → **漏覆盖（missed coverage）→ 假安全**。
- 该反例是 `two/15` 必过样例（真值延迟取端点、被筛掉端点分支）在**分支筛选**机制下的重现；失败根因**不是**「历史剪枝」，而是「**支配证书只对当前活跃法向成立、未覆盖时域内可新出现的法向**」。
- 修复（使其满足 C1/C2）：把法向检查集合扩为**时域内可能活跃的法向过近似 `N̄`**，并要求对「`D'` 分支 + 任意后继」封闭；修复后该反例**应不再漏覆盖**——这是 T3 必须检验的。

**相对最近邻的「新内容」到底新在哪（必须是算法步骤或可检查性质层面）**

- **被筛选的对象不同**：Nouwens/SHIELD/TransformerMPC 筛选的是**同一固定模型下某个凸优化问题的约束/决策变量**；DBDS 筛选的是**时变延迟不确定集的「分支」**——一个随拍演化、且必须对「任意后继拼接」闭合的**索引集合**。Shaw Cortez/Ong 的事件触发决定「**要不要解/要不要过滤**」，既不筛约束也不筛分支；Bajcsy 复用/暖启动的是**自由空间变化下的值函数**，其保证是安全集的**欠近似（保守）**，不是对延迟分支集合的**覆盖等价**。
- **可检查性质不同**：DBDS 要求一条**可检查的覆盖等价证书**——筛选后包络 `⊇` sound 全分支包络，且对被筛分支在**时域法向过近似 `N̄`** 上给出支持函数支配（C1）与后继封闭（C2）。**这两条在 6 篇新增原文与 `two/08` 的 7 篇中都没有以「延迟分支 + 逐拍任意后继 + 共享备份终端」为对象被陈述。**
- **与计算预算绑定**：筛选必须在**固定每拍 rollout 预算 `B`** 内完成并给**确定性计数**；SHIELD 有「不确定则解全问题」的回退，但没有预算口径；Nouwens 开销随 `n_c` 线性但没有时限，也非「逐拍任意延迟」。
- **工具相同、性质与对象不同（如实声明）**：「集合包含/支持函数支配」本身是标准工具（Nouwens Eq.(5) 的「椭球⊂半空间」判定即是其一）。DBDS 的差异**不在工具**，而在**对象（延迟分支集合 vs 约束）**与**性质（逐拍任意延迟下的覆盖等价 vs 固定模型的精确极小值点/单实例可行性）**。
- 因此新内容属**算法步骤 + 可检查性质**层面，**不是**「代码更快」「比旧 DQN 好」「换平台」。

## 5. 通过判据自检留痕（SubTask 1.4）

**通过判据**（`tasks.md` Task 1 / `spec.md` T1 / [任务书](第三波任务.md) §2）：能指出具体算法步骤及最近邻未覆盖的条件/性质；「代码更快」「比旧 DQN 好」不算差异。

- **能指出具体算法步骤吗？** 是。见 §4.1：`输入 → 分支筛选（C1/C2 检查）→ 输出 D' 与覆盖证书 → 预算不足回退`，共 4 步，每步可检查。
- **能指出最近邻未覆盖的条件/性质吗？** 是。逐条比对：
  - 对 Nouwens/SHIELD/TransformerMPC：其对象是**固定模型凸问题的约束**，**从未**筛选「延迟分支集合」，也**没有**「逐拍任意后继的覆盖等价（C2）」这一性质。
  - 对 Shaw Cortez/Ong：其决策是「**是否计算/是否过滤**」，判断对象是**单条名义轨迹/barrier 值**，**没有**分支支配证书，**没有**每拍 rollout 预算。
  - 对 Bajcsy：其复用保证是**欠近似（保守）**，与 DBDS 要求的**覆盖等价**方向相反；也不涉延迟分支。
  - 对 `two/08` 7 篇：均未涉及约束筛选/计算调度/证书复用，且多数未显式处理延迟。
- **这个候选可证伪吗？用什么实验能证伪它？** 可证伪。T3 的证伪实验：
  1. **反例实验**：构造 §4.1 的逐拍任意延迟反例（`two/15` must-pass 结构升级），检验 naive 版（仅当前活跃法向）**漏覆盖**；并检验修复版（法向过近似 `N̄`）**不再漏覆盖**。若修复版仍漏覆盖 → 候选不成立。
  2. **覆盖等价实验**：同一组**预先登记**场景，逐拍比较 DBDS 包络与 sound 全分支包络的包含关系。**任一拍 DBDS 包络不 `⊇` sound 包络 → 判失败**（不靠事后调大裕量遮盖）。
  3. **有效性实验**：统计被筛分支比例与确定性 rollout 计数。若被筛比例 ≈ 0（筛选无收益）或**恒需全保留**（预算内无法建立证书）→ 无实际收益 → 按 §4 止损。
  4. **等价性实验**：把 DBDS 与「标准包含筛选/对偶证书（Nouwens Eq.(5)、SHIELD `Thm.1`）直接套到分支上」在同一实现路径下对照。若二者在覆盖与预算上**无差别** → 判为**已有算法的等价实现** → 按 §4 否决。
- **自检结论**：**T1 通过**（能指出具体算法步骤及最近邻未覆盖的条件/性质）。但须在 §6 记录**等价性风险**，由 T3 的「等价性实验」决断。
