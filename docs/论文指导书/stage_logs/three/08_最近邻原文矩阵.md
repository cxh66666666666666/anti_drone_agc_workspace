## ③ 覆盖判定与尚缺核查项

**本轮检索到的、已被覆盖的做法（不可作为本项目新意）：**
1. 区分 `terminated` / `truncated` 并据此自举——Gymnasium 论文 §4.2、Pardo 2018（方向1）。
2. 时间上限偏差（state aliasing / PEB）——Pardo 2018。
3. 「截断 = 右删失、后续不可观测」——SVL §4.1；删失致偏差——Kubota 2026 等（方向2，含摘要级）。
4. 成功 / 碰撞 / 超时 / 耗时**分列报告**——Gao&Huang、SONG §4.3、HA-VLN 2.0 §D.1、RoboGate（方向4）。
5. 「只报成功率会高估 / 掩盖碰撞行为」——VFN Navigate §IV、SoftVTBench §4.4。
6. 「几何碰撞代理」被广泛使用；「几何擦碰 vs 有效碰撞」已有区分先例——Bench2FreeAD §III-C、BARN（硬/软碰撞）、SONG §3.4（collision proxies）。
7. Gazebo 内建**接触传感器 / TouchPlugin**；接触保真度有限且有实证——Gazebo 文档、PhysX 文档、Acosta 2022（方向3）。

## ⑤ 本项目可能的贡献边界判定

**逐条判定**

1. **「区分终止/截断」**：已被 Gymnasium §4.2、Pardo 2018 覆盖 → **不可作新意**。本项目只把它作为实现前提。
2. **「截断时的物理后效」**：Gymnasium/Pardo 只谈自举语义，SVL §4.1 更进一步把截断等同于右删失并声明**后续不可观测**；**三者均未讨论软件终止后机体继续运动的物理尾段**。本轮**未检索到**把它当评测偏差做配对实证的工作。→ **可作候选差异点**，但须以「实测偏差大小与对排序的影响」为结果，不得只换命名。
3. **「接触测量 vs 几何代理」**：Gazebo 有接触传感器/TouchPlugin；BARN 已有硬/软碰撞区分；SONG 有 collision proxy 与高斯体积双路径；PhysX/Acosta 说明几何代理会漏检、接触保真度有限。→ 「两者不同」本身**不可作新意**；本项目须给出**同一 PX4 回合内两口径不一致的发生率与对结论的影响**。
4. **「成功/碰撞/超时分列」与「只报成功会高估」**：已被 Gao&Huang、SONG、HA-VLN、RoboGate、VFN、SoftVTBench 覆盖 → **不可作新意**。本项目旧口径的问题不是「没分列」，而是**分母只含已观察部分**；要证明的是**分母缺尾段**会改变结论。
5. **「任务失败 vs 物理风险」区分**：已被 OOPSIEVERSE（接触力→损伤）、SoftVTBench（Goal vs Safety Success）覆盖 → **不可作新意**；FailBench（摘要级）已涉及「失效后交互后果」，但方向是规划而非评测偏差。
6. **「终止后观察窗口」作为协议要素**：SONG 等给出「碰撞即复位到 last safe pose」的**设计选择**，但**未把它作为偏差来源**；本轮**未检索到**把「统一终止后观察窗口 + 其敏感性」写入评测协议的工作。

**综上（保守结论）**：本轮检索把方向1、3、4、5 的多数**机制与做法**判定为已被覆盖；本项目**可能**的贡献边界收窄为——
①在同一 PX4 SITL/Gazebo 四旋翼闭环上，**实证**「软件截断后物理尾段」被漏观测所带来的**偏差大小、发生条件与对算法比较排序的影响**；②**交叉核验**两帧几何净空阈值与独立 Gazebo 接触事件的不一致，并给出可复算的原始轨迹与工具。
**这只是「本轮未检索到同等证据」，不等于研究空白**；能否成立取决于探针能否稳定记录终止后轨迹与接触事件，以及偏差是否稳定、可解释、跨代表场景出现（见 [`07`](07_改题决定_终止后物理结局评测.md) §四）。**本轮未覆盖的最近邻**已在 §③ 列明，正式实验前仍须补核 Ugurlu 2022 原文、RL 评测统计方法类工作，以及「终止后继续仿真」的专门工作。
