## 三、统计口径（在看结果前预定）

1. **试验单位 = 整回合**；同一回合的两个读数为配对：`立即结算`（用终止拍 `done_reason`）与 `继续观察`（含尾段至停稳/上限）。
2. **算法比较按相同场景/种子配对**；**按场景家族聚类**给不确定性区间（仅给区间，不做确认性检验）。
3. 每回合分列这些二元结局：任务完成、软件提前终止、尾段真值几何相交、尾段已验证接触、尾段超时/未停稳（右删失）、传感缺失、复位失败。**时间步不作独立样本**。
4. **主判据（预定，不可事后更换）**：`配对翻转率` = 在「立即结算判为未碰撞」的回合中，「完整口径判为发生真值几何相交或已验证接触」的比例。
   - **最小有意义差异**：翻转率 ≥ 1/3，且**至少跨 2 个场景家族**出现，并且方向一致（完整口径**不低于**立即结算口径）。
5. **敏感性**：对尾段观察上限 `{2, 4, 8} s` 预定三档，报告翻转率随上限的变化；窗末仍未停稳标**右删失**，不视为安全。

## 四、冻结的评测协议（v4.0，冻结于 2026-09-25，T5 结果产生之前）

**接口**：PX4 SITL + Gazebo，无头；位置设定点台架（`/mavros/setpoint_position/local`）；控制器=LQR 跟踪器；运行时控制器与真值评分器隔离（观察器只读物理真值）。

**场景家族（3 个，取自旧诊断批次，仅作代表，不作盲测集）与种子**：

| 家族 | 场景 | 旧批次曾出现的终止原因 |
|---|---|---|
| `mirror_pair` | `s2v4-2e242386b8` | shield_infeasible / collision |
| `dense_corridor` | `s2v4-4e63a74d8a` | shield_infeasible / collision |
| `sensor_blackout_midflight` | `s3v1-58fa8c6b96` | sensor_invalid / perception_timeout |

**方法与对照**：`B2`=`safety_filter_mode=disabled`（既有 B0/B1/B2 掩码路径，令距离掩码承担裁决）；`A1`=`safety_filter_mode=a1`（空集严格终止档 `empty_set_terminal=true`）；`P`=`safety_filter_mode=p`。

**固定参数**：任务期限 `max_steps=450`；终止后命令=**hold**（冻结到终止拍实测位置）；尾段观察上限=**8 s**（敏感性另跑 2/4 s）；停稳定义=`speed<0.05 m/s` 持续 `2.0 s`；控制周期 `action_duration=0.1 s`；净空判据 `contact_dist=0.0`、**连续两帧**。

**复位规则**：每回合 `env.reset()`；复位失败=**基础设施失败**，原地重试最多 2 次（**不占**预试回合预算），仍失败则该 (场景,方法,种子) 记缺失。

**失联规则**：整个 run `/drone_contact` 零消息=接触信号缺失，记**基础设施失败**；窗口内消息不增长而 `/clock` 仍推进=**局部失联**，同样记失败。二者**不得**写成「无接触」。

**模型/版本指纹**：

| 项 | 值 |
|---|---|
| 策略 checkpoint | `training_runs/dqn_v5b_raw_s101/best_model.pt` |
| 派生 bumper 机体 SDF | `iris_3d_lidar_contact.sdf`，SHA-256 `92c16d05…7b28` |
| 原版碰撞体接触机体 SDF | `iris_3d_lidar_origcontact.sdf`，SHA-256 `3d8ec420…8dfc5` |
| 场景文件 | 上表三份，逐一记录 SHA-256（见 `four/05`） |

**排除条件**：`status=startup_failed`、`termination_reason∈{clock_anomaly, drop_frame}`、复位失败、接触信号缺失/局部失联——均记基础设施失败并保留原始记录，不计入有效配对。

**旧口径重算规则**：`立即结算` 一律按**真实控制周期 `0.1 s`** 与**连续两帧**判据重放（不用逐拍采样值直接断言），并检查 `features_fresh`。

**完整口径**：分别报 **① Gazebo 真值几何相交**（`geom_clearance_gz<=0`）与 **② 已验证接触**（bumper 接触 **与** 原版碰撞体接触**二者分列**，因 `four/02` 已证明二者不同尺度——不得把 bumper 接触单独当「原版机体接触真值」）。

**接触源限定（来自 T2）**：bumper 接触≈几何包络，与原版机体接触差 ~0.13 s / 力差 ~30×；主指标须**同时**报 bumper 接触与原版机体接触（或真值几何）。
