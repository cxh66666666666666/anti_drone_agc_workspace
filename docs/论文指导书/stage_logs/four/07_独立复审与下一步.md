# 第四轮独立复审：先修测量协议，再决定补充实验

> 2026-09-26。复审 [`01`](01_现有证据复核.md)—[`06`](06_阶段裁决.md)、T5 原始 `meta.json`/`episodes.csv`/`trace.csv`/`contact.csv` 与采集、复算代码。**只读核对既有日志；不改写冻结协议、原始数据或原阶段裁决。** 本页记录独立复审后的执行顺序。

## 一、裁决

T2 已证明可以在原版碰撞体上挂接触传感器；T3 已取得 `shield_infeasible`、`sensor_invalid`、`perception_timeout` 的真实闭环尾段。这两项可行性成果成立。

T5 的 **5/21** 是“**当前 bumper 模型、当前终止后行为**下，立即结算与尾段几何相交/bumper 接触并集”的探索值；它低于预定的 1/3。**不能把它当成 [`04`](04_冻结评测协议.md) 冻结协议的主结果**，因为终止后动作与接触源均未按协议实施。因此，先暂停 [`06`](06_阶段裁决.md) §三所提“新增 1—2 个窄走廊家族、≤24 回合”的补充运行；先完成下列协议修复与最小复核。此前数据保留为探索性证据。

### 原始 T5 数据可支持的计数

排除 3 个 smoke 和 1 个 `reset_failure` 后，有效 **26** 回合；其中立即口径判未碰撞 **21** 回合。在这 21 回合中，尾段/全程真值几何相交 **2** 回合，尾段 bumper 接触 **4** 回合，两者并集 **5** 回合（1 回合两者兼有）。按家族的并集为 `blackout=0/9`、`dense_corridor=4/6`、`mirror_pair=1/6`。**原版碰撞体接触的对应数值未知**。

上述 5 个并集事件均落在终止后的尾段；不受本页指出的敏感性分母修正影响。但由于共同动作和接触源不符合冻结协议，该比例仅描述已实际执行的探索配置。`06` 的“主判据未达”方向仍成立；其“已足以裁决 ② 并直接做窄走廊补充验证”的实验前提不成立。

## 三、下一步的最小门槛

1. **落实唯一尾段控制者。** 在每种 `done_reason` 后发布同一个预定 hold 设定点，并记录命令时间、值、实际发布者与 LQR/其他发布者的状态；控制使用终止拍 MAVROS 估计位姿，不读 Gazebo 评分真值。用 `shield_infeasible`、`sensor_invalid/perception_timeout`、`collision` 各一个烟雾回合，核实 `/mavros/setpoint_position/local` 实际保持、无发布者竞争。
2. **主接触源改为原版碰撞体。** 使用 T2 已做的 `origcontact` 派生模型（不新增 bumper 几何），分别报原版 `base_link`/rotor 接触与真值几何相交；bumper 结果留作包络传感器的探索对照。contact 话题须落盘空消息 heartbeat 或消息时间/序号，能对尾段每个窗口判断信号是否存在。
3. **修复复算口径并保留旧版本。** 对所有分析按相同有效回合集合计算主值与 2/4/8 s 敏感性；按 `/clock` 时间检测连续 2 s 低速；记录每个终止后观察窗的实际仿真时长。新增分析版本和修订注记，**不覆盖** T5 原始日志、冻结协议 v4.0 或原分析结果。
4. **先做固定清单的小复核。** 在改动前写 v4.1 协议补充说明：选一个已出现翻转的近障场景、一个未翻转近障场景、一个黑障场景，每个至少覆盖相关终止类型。只要共同 hold、原版 contact、heartbeat 与停稳复算未同时通过，就不追加 24 个窄走廊回合。
5. **再决定研究范围。** 若原版接触/真值相交在修正控制下仍稳定造成可解释的漏报，才按预先定义的场景总体设计新批次与样本量。若只在挑选的近障家族出现，改成“近障提前终止条件下的评测偏差”并另设独立场景家族验证；**不能把事后增加高风险走廊回合用来追认 v4.0 的总体 ≥1/3 判据**。若差异主要来自 bumper 或尾段控制差异，则停止当前论文主张，保留为平台测量修复。
