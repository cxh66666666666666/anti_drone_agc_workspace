**标签来源核对（重要）**：`sensor_invalid` 与 `perception_timeout` **都由「注入的传感器失效窗口」间接引起**，但落到哪个标签取决于**过滤器是否启用**：
- 过滤器启用（a1/p）：`step()` 先执行 `_publish_action()`（L1473），空/无效传感 → 过滤器的 `sensor_invalid` **先**返回，故 `done_reason=sensor_invalid`。
- 过滤器禁用：走 legacy 路径，无 `sensor_invalid` 分支，随后 `is_done()` 判 `perception_timeout`。

即：**同一注入故障在不同过滤器档下产生不同 `done_reason`**——不能把「注入故障标签」当作与控制器无关的 `done_reason`，必须连同过滤器档一起报。本批用实测证实了这一点（§三）。

## 四、可复现的实测结论

1. **同一注入故障、不同档 → 不同 `done_reason`（已实测）**：黑障窗口 `[5,8]` 下，a1 档终止在相位≈5.02 → `sensor_invalid`；disabled 档终止在相位≈5.02 → `perception_timeout`。**证明 `sensor_invalid`/`perception_timeout` 是「注入故障 × 过滤器档」的联合标签**，不是与控制器无关的物理事件。
2. **终止后机体继续运动**：所有尾段最大速度 0.33—0.76 m/s（终止瞬间并非静止）。
3. **存在「真值几何相交但无接触事件」的回合**：`t3_pt_1` 尾段真值最小净空 **−0.161 m**（包络与障碍重叠）、`t3_shield_mirror` **−0.024 m**，但**两回合均无物体接触消息**。这是 T2 所证「几何包络 ≠ 物理接触」的**闭环实例**；本批仅 2 例，且未分离机理（俯仰出包络 / 求解器接触容差），**不作发生率结论**。
4. **无 `shield_infeasible` 回合的 `timeout` 对照**：`t3_dense_a1`（未用旧参数档）得 3× `timeout`，说明 `shield_infeasible` 的出现依赖过滤器参数档，**不是每个 a1 回合都会出现**。
