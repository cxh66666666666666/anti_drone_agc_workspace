## 二、三选一裁决

### **裁定：② 机制成立但当前证据/统计精度不足 —— 指定一个有上限的补充验证**

**理由（逐条链接原始数据）**

1. **机制成立、非纯命名刷新**：5 个翻转回合中 3 例的真值几何净空在**正**（+0.017 / +0.098 / +0.047 m）却发生了**物理接触**（[`four/05`](05_配对预试结果.md) §二、`t5_analyze.json`）。这**不是**把同一包络换个名字：轴对齐代理判「未碰撞」，而机体俯仰后 bumper 角点仍擦到障碍（[`four/02`](02_接触源标定.md) §四）。即「终止即结算」确有漏报，方向与 `three/09` 的受控样例一致。
2. **量级不足**：整体翻转率 0.238 低于预定的 1/3。
3. **高度依赖场景家族**：窄走廊 `dense_corridor` 0.667，开阔黑障 `blackout` 0.000，`mirror_pair` 0.167。差异来源**不是**随机噪声——blackout 家族终止时净空普遍 >2 m（尾段无接触），dense 家族终止时贴近墙体。这提示「偏差是否重要」取决于任务是否让机体在终止瞬间仍贴近障碍。
4. **统计精度不足**：每格仅 3 回合、平台无显式种子（重复回合代替），不足以给区间或排序结论；12/27 回合窗末仍未停稳（右删失）。

**为何不选 ①**：主判据（≥1/3）未达，预定规则不允许见结果后放宽。

**为何不选 ③**：差异**不是**「只来自 bumper 改模或实现错误」——它由独立物理接触事件与真值几何共同支撑，且 T2 已把 bumper 与包络的关系界定清楚；也**不是**已被近邻覆盖（[`four/04`](04_冻结评测协议.md) §一：本轮未检索到「截断后继续推进仿真的物理尾段当评测偏差做配对实证」的工作）。但**若**补充验证在新增窄走廊家族里翻转率仍 <1/3，则**转为 ③**。

## 三、有上限的补充验证（预定，≤2 个工作日）

- **问题**：把「窄走廊型」纳入场景家族后，翻转率是否稳定 ≥1/3？blackout 型是否应**明确排除**在「尾段偏差」主张之外？
- **做法**：新增 **1—2 个窄走廊/贴近墙面的场景家族**（机理与 dense_corridor 同族、参数不同），3 方法 × 3 重复；**按家族分层**报翻转率，**不合并成单一数**。
- **预定判据**：新增家族翻转率 ≥ **0.5** 且方向一致 → 支持把「尾段偏差」作为**窄走廊任务**下的可辩护发现；新增家族 < **1/3** → 转 ③ 停止论文主张。
- **上限**：≤ 2 工作日、≤ 24 个新回合；不新增方法、不改协议口径、不看结果再换判据。
- **必须同时报告**：右删失比例、复位/启动基础设施失败率、bumper 与真值几何的分歧例数。

## 四、论文题目与投稿价值的重新裁决

**结论：暂不构成可投的独立实证论文；论文主张下调。**

- **尚不能主张**：「终止后物理结局偏差」有**普遍**重要性、或会稳定改变算法排序（预试未达预定bar，家族异质）。
- **可以主张**（作为测量/平台质量贡献或方法注记）：
  1. **三类事件不可混同**：[`four/01`](01_现有证据复核.md)、[`four/02`](02_接触源标定.md) 证明「估计位姿几何代理 / 真值几何相交 / 指定碰撞体接触」在时刻与符号上都会不一致。
  2. **轴对齐包络会漏报姿态接触**：3 个翻转回合在包络判正时发生物理接触。
  3. **`done_reason` 与过滤器档耦合**：同一次注入故障在 A1/P 下记 `sensor_invalid`、在 disabled 下记 `perception_timeout`（[`four/03`](03_真实终止链路.md) §一、[`four/05`](05_配对预试结果.md) §二）——评测口径必须连同控制器档一起报。
- **去向判断**：[`four/04`](04_冻结评测协议.md) §二已核查 IEEE RA-P（明列 empirical studies / case studies）与 RA-L（application case studies 在范围内）为最合适去向；**但需先完成 §三 的补充验证**再定投稿形态。若补充验证转 ③，则把上述测量发现作为**平台质量改进**归档（可考虑 RAM 的 Reproducible Articles 类）。
- **本轮不声称**「首次」「研究空白」；所有负面/未达成结果（主判据未过、家族异质、右删失、基础设施失败）已完整保留。
