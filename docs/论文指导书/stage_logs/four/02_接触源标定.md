## 四、原版 vs 派生机体的差异界定（核心）

用**相同命令**（0.6 m/s 直线逼近同一静态柱）与相同探针参数比较：

| 量 | bumper（派生） | 原版碰撞体 |
|---|---:|---:|
| 首次物体接触（相对**本 run** 真值几何穿越） | **早 0.024 s** | **晚 0.132 s** |
| 首次接触碰撞体 | `bumper_collision`（0.70×0.70） | `base_link_inertia_collision`（0.47×0.47）/ rotor |
| 首次接触力 | **0.60 N** | **18.48 N** |

**结论（限派生模型）：**

1. **bumper 盒尺寸被有意取成与几何代理包络一致**（0.70×0.70×0.11 ≈ 包络 0.70×0.70×0.12）。因此 **bumper 的接触时刻在构造上就≈几何代理穿越时刻**（实测差 1 采样）。这意味 `three/09` 的 bumper 接触**在时间上并不独立于几何代理**——它复现的是同一个包络，而不是原版机体何时真正碰上。
2. **原版机体比包络晚接触**：原版 `base_link` 盒 0.47 m 比包络窄 0.115 m，实测首次接触比几何穿越**晚 0.132 s**（≈0.08 m @0.6 m/s）。若用「物理接触 = 原版机体相碰」，其时刻与几何代理**不一致**，且方向是「几何代理偏保守（早报）」。
3. **力差 ~30×**：轻 bumper（0.01 kg）接触力 0.60 N，原版机体接触力 18.48 N。bumper 测到的是**包络级邻接**，原版机体测到的是**真实碰撞**。
4. **动力学影响**：bumper 增加 0.01 kg（相对机体 ~1.5 kg 约 0.7%），惯性影响可忽略；两次 run 的**绝对**时间差异主要由起飞/对齐抖动造成，本批**不足以分离** bumper 对轨迹的因果影响。故本轮**把运动学结论限定为「派生模型」**，不外推到原版机体。

**对证据等级的影响**：`three/09` 把 bumper 接触称为「独立 Gazebo 接触事件」在**来源**上成立（是真实物理接触），但在**独立性**上需降格——它与几何包络同尺度、几乎同时。若要「原版机体的接触时刻」，须用本轮 `iris_3d_lidar_origcontact` 这类挂在原版碰撞体上的传感器，或用原版机体本身。

## 五、消息丢失与时钟对齐

- **检测规则**：`contact_signal_missing := ` 整个 run `/drone_contact` 零消息；局部失联按「窗口内 `n_msgs` 不增长而 `/clock` 仍推进」标记为**基础设施失败**。本轮 4 个 run 的 `n_msgs` 为 2659—13018，均远超 0，无失联。
- **时钟**：`clock.csv` 逐样本 `d_clock` 均值 0.004 s（250 Hz），**无非正步**；`use_sim_time=true`；`drop_rows=0`（每拍至少一路链路新鲜）。空场景/接触/地面各 run 的时间基对齐通过。
- **一例基础设施失败（如实记录）**：首次 `t2_contact_origbody` 误用**相对路径**传 `--model-sdf`，Gazebo 报 `FATAL: specified file … does not exist`，机体未生成→MAVROS 在 90 s 内未连接→`status=startup_failed`、`status_reason="MAVROS 未在 90s 内连接"`。修法：探针把 `--model-sdf` 解析为**绝对路径**（已改进）；该次失败记录保留在 `t2_contact/results/t2_contact_origbody/`（重跑前的日志）与本文，**不写成「无接触」**。

## 六、T2 通过判定

- **contact 测到的碰撞体**：默认为派生 **bumper 盒**；本轮另建 `origcontact` 模型可测**原版碰撞体**。
- **误检/漏检边界**：bumper 在包络级邻接时即报接触（比真值几何穿越早约 1 采样）；原版机体接触比几何穿越晚约 0.13 s；落地停机时 bumper 抬高**不**报伪地面接触。
- **派生模型影响**：质量影响可忽略；几何影响显著——bumper 接触≈几何代理，**不能当作独立于几何代理的原版机体接触真值**；运动学影响本批无法分离，限「派生模型」。

→ T2 **通过**，但**限定**：接触结局若要作为「独立接触真值」进入主指标，**必须**区分「bumper 包络级接触」与「原版机体接触」，或在主指标里同时报两者；直接沿用 `three/09` 的 bumper 接触当「独立真值」不成立。
