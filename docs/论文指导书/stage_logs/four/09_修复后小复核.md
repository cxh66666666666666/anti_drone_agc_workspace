## 一、三项修复的落地

1. **R1 唯一尾段控制者**：新探针 `t6_recheck/episode_tail_probe_v3.py` 在 `done` 后由**本探针单独**发布同一 hold（`/rl_planner/local_control=(0,1,1)` 冻结 LQR 参考相位 + 恒定 `/rl_planner/local_offset`，使命令参考≈终止拍 **MAVROS 估计位姿** `p_hold`）。控制只用 MAVROS 与 LQR 上报量（`/lqr_tracker/adjusted_ref`、`/rl_planner/local_offset`），**不读 Gazebo 真值**。逐 hold 命令记录时间/值/发布者，并订阅落盘实际 `/mavros/setpoint_position/local`。
   - **实测**：所有有效回合 `hold_mode=pose_pin`（无退化）；`max_hold_gap≈0.052 s`；`p_hold` 与实测 setpoint 窗末偏差 ≤ **0.0002 m**（远小于 0.15 m 容差）。
   - **发布者竞争核查**：`/rl_planner/local_offset`、`/rl_planner/local_control` 均**单发布节点**。`/mavros/setpoint_position/local` 的 advertiser 列表含 `/drone_launch_controller` 与 `/lqr_tracker_node`；前者在起飞后调用 `releaseControl()`（`drone_launch_controller_node.cpp` L526）即**停止发布**，轨迹跟踪段唯一实际发布者为 `lqr_tracker_node`，尾段 setpoint 锁定在 `p_hold` 亦证实无第二控制源。此为**既有平台结构**，非本轮引入。
2. **R2 主接触源**：全部 run 用 `iris_3d_lidar_origcontact.sdf`（SHA-256 `3d8ec420…8dfc5`，原版碰撞体挂接触传感器，**不加 bumper 几何**）。`contact.csv` 的 `collision1` 全为原版 `base_link_inertia_collision`/`rotor_*_collision`，**bumper 行 = 0**。
3. **R3 复算口径**：`t6_recheck/t6_analyze.py`（v2）对**同一有效集合**算主值与 2/4/8 s 敏感性，按 `/clock` 判**连续 2.0 s** 停稳，记录窗口实际仿真时长，**分列**原版接触/真值几何相交/bumper 对照。

## 五、修正控制下的整体主判据（`results_recomputed_v2.json`）

把固定清单 + 窄走廊批次一并按 v2 口径（同一有效集合）复算：

| 家族 | denom | 翻转(完整口径) | 翻转率 | 翻转(仅尾段) |
|---|---:|---:|---:|---:|
| dense_corridor | 1 | 1 | 1.000 | 1 |
| nc_tight | 8 | 3 | 0.375 | 1 |
| nc_mid | 5 | 2 | 0.400 | 2 |
| mirror_pair | 2 | 0 | 0.000 | 0 |
| blackout | 3 | 0 | 0.000 | 0 |
| **合计** | **19** | **6** | **0.316** | **4 (0.211)** |

- **主判据（v4.0 §三.4）**：翻转率 **0.316 < 1/3**，跨 3 个家族（dense_corridor、nc_tight、nc_mid），方向一致 → **量级仍未达**（`pass_min_meaningful=false`）。仅尾段口径 0.211 更低。
- **口径与直接读数**：6 个「完整口径」翻转中有 **2 个发生在终止前**——2 个 `nc_tight_b2` 回合 `done_reason=timeout`，其**真值几何相交发生在终止前**（尾段净空 7.2/7.5 m），属**回合内**漏报，非终止后尾段事件；已分列。**讨论"终止后物理结局"应以「仅尾段」4/19＝0.211 为直接读数**；6/19＝0.316 仅作**冻结的完整口径**保留，**不得**用来证明尾段偏差。
- **对照 T5**：T5 无共同 hold 时主项 **5/21＝0.238**；本轮完整口径 **6/19＝0.316**，数值**上升**，只有「仅尾段」口径 **4/19＝0.211** 更低。两轮之间更换了接触模型、场景构成与测量口径，**不能**把差异归因于共同 hold；残差集中在窄走廊近障族（线索级，见 §四）。

## 七、限制

1. 平台**无显式种子**，「重复」为独立回合；每格样本小（fam denom 1—8），区间不可给。
2. 基础设施失败率（`nc_mid` 0.385）与右删失（`nc_mid` 0.75）偏高，**削弱量级置信**；失败与删失原始记录保留。

4. 本复核**不宣称**普遍发生率或算法排序影响；只报「修正控制下」可测的口径与量级。
5. 运行中曾泄漏 **1 个 `drone_launch_controller_node`**（会话差集回收未覆盖到），已在核验阶段定位并回收；全程**无头**（未启动 Gazebo GUI）。
