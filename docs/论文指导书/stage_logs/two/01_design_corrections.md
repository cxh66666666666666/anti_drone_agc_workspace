## §B（P2）三个机制反例与公平比较的证据等级更正

> 依据：验收 **F3**（[`one/09_acceptance_review.md`](../one/09_acceptance_review.md) [§3 F3](../one/09_acceptance_review.md)）、[阶段 two 任务书](publication_tasks.md) §2 **P2**。
> 本节只更正**结论的证据等级与表述**，**不改**任何既有脚本/json/csv，也不改 `one/` 原文。

### B.1 CE1 的替代解释

- CE1（`experiments/paper_v3/mechanisms/ce1_speed_sweep.py` → `results/ce1_speed_sweep.json`）是「**实际无障碍**制动轨迹 ＋ **假设**障碍净空」的**离线评分**，**不是**在场景中放置障碍后做的安全通行试验：脚本只读 trace 的 Gazebo 真值，并按**同一假设净空** `c = dth`（`ce1_speed_sweep.py:99-119`）判定；`one/04` §7.3 亦承认「未在场景里真正放置同一净空障碍」。
- `sweep_peak_m` 是**沿给定方向（`direction=(1.0, 0.0)`）的最大投影** `max((p−p0)·u)`（`ce1_speed_sweep.py:58-59`），**不能**称「水平最大位移」（验收 F2/F3 均点此条）。
- **能被引用**：同一**假设**净空下，实际无障碍制动轨迹的**沿向最大外扩**随速度增大（0.2386→0.5091 m，比值 ×2.13，见 `ce1_speed_sweep.json` 的 `sweep_ratio_1p0_over_0p5`）；「只看当前距离」判据在该假设下误判 1.0 m/s 样本。**不得**引用为「已做障碍通行实验」，`sweep_peak_m` **不得**称「水平最大位移」。

### B.2 CE2 的替代解释（两例分开 ＋ 碰撞/裕量区分）

必须把两件事**分开**表述：

- (a) **已知方向的固定误差例子**：`e=(-0.20, 0)`（朝墙）与 `e=(0, +0.20)`（平行），见 `ce2_error_direction.py:42-50` 的 `physics`。
- (b) **给定不确定集合的最坏值例子**：半轴 `(a_long, a_lat)=(0.20, 0.05)` 的椭圆，支持函数 `σ_E(n)=√((0.20·n_x)²+(0.05·n_y)²)` 随方向在 0.05—0.20 变化（`ce2_error_direction.py:23-24,29-36,66-83`）。

**关键更正**：示例 (a) 中的 `e=(0, 0.20)`（横向 0.20）**不属于**集合 (b)（其横向半轴仅 0.05，椭圆内最大的 `(0,·)` 分量为 0.05）。因此**不能**称「同一批误差在同一覆盖集合内的实测优势」；`one/09` F3 明确要求二者分开。

- **物理碰撞 vs 未满足设计裕量**：CE2 中朝墙净空 `C0 − R = 0.30 − 0.20 = 0.10 m`（`ce2_error_direction.py:45`）只是**不满足设计裕量** `margin = 0.15 m`（即 `0.10 < 0.15`），**不得**写成「物理碰撞」。物理碰撞须以**几何包络相交**判定（机体包络接触阈值，见 `gazebo_env.py` 的碰撞判据），CE2 未涉及。
- **能被引用**：误差**方向**改变扫掠净空（几何事实）；**固定标量膨胀** `κ‖e‖` 方向盲（κ=1 对平行误差 4/7 误拒，见 `ce2_error_direction.json` 的 `summary.false_reject_k1`）。**不能**引用为实测碰撞或实测优势。

### B.3 CE3 的替代解释

- CE3（`experiments/paper_v3/mechanisms/ce3_delay_replay.py` → `results/ce3_delay_replay.json`、`results/ce3_delay_curve.csv`）是**合成的一阶速度模型**，**不是**实际位置指令回放。
- 参数为**借用值**：`V_CMD = 1.4`（`ce3_delay_replay.py:26`）借自**位置偏移上限** `max_offset_xy`（单位纪律见契约 §3）；`TAU = 0.85`（`:24`）借自旧 z 轴位置阶跃的冻结时间常数（`one/01` §3.7）。二者**未经本接口辨识**即用于速度环。
- `cruise_brake_replay()`（`:61-79`）生成的是「速度从 0.5 切至 0」的**合成输入**，**未读取任何真实 trace**，也不能复现真实「回退到当前实测位置」产生的**回摆**行为（对比 `one/02_brake_hold.md` §3 的三段剖面）。
- **能被引用**：在给定一阶滞后模型内，「瞬时实现」假设在命令变化处产生 ≥0.8 m 的预测偏差且随延迟近线性增大（**模型级**）。**不能**引用为真实装置的位置指令回放结论。

### B.4 公平比较结论撤回

4. 旧判据**未对齐**「预测发出时刻 k 的实际初态 ＋ 实际执行输入序列 ＋ 未来真实观测 k+j」，故**不能替代未来预测验证**（与 `one/01` §5.2 一致）；其四项指标（`sound`/`false_safe`/`optimistic`/`conservative_exceeded`）都只是**同一时刻**的实现/几何一致性。（协议 v2 §1、§2）
