## 1. 目的与证据级别

- **目的**：在 `B2` 之上实现一个**简单历史一致性分支筛选原型**（不引入 RL），专门检验「`P` 的候选差异＝执行历史细化/分支保留」是否有**独立于标准集合辨识/多模型鲁棒控制**的价值。
- **证据级别**：本文全部结论为 **`model-level`**（离线模型级，合成/借用参数），**非 PX4/SITL/真机实测**，**不得**当作实飞观测证据。
- **判定由测量导出**：`results/summary.json` 的结论（`missed_true_branch`、`no_independent_method_contribution` 等）全部由**逐拍度量**计算，**无硬编码标签**（`all_measured=true`）。
- 允许延迟区间取自 **N1 辨识** `[0.18, 0.30] s`（来源 `experiments/paper_v3/identification/brake_hold_v3/identified_params.json`，`evidence_level=sim-observation`）；若不可用则回退 N0 声明 `[0.15,0.25]`。

## 2. 原型设计与其同等约束

**离散与分支**：把允许延迟区间均匀离散为 `N_b=7` 个分支（均匀取 `L=0.18,0.20,…,0.30 s` → `n_L=9…15` 拍）；`B2` 基线使用区间**端点 2 支**。

**同等约束（与 `B2` 对齐，显式声明）**：

| 约束 | 取值/来源 |
|---|---|
| 同模型族 | `baselines/model.py` 纯延迟 + 一阶滞后位置闭环（`dt=0.02 s`、`n_L=ceil(L/dt)`、`alpha`） |
| 同噪声界 | 声明残差界 `resid_bound`（历史一致性唯一阈值，**不由真值拟合**） |
| 同方向误差表示 | `model.sigma_E`（候选鲁棒判据 `h−σ_E(−∇h)`，`a_long=0.20`/`a_lat=0.05`） |
| 同共同备份 | `baselines/backup.py` 的 `expand_candidate`（候选一拍 → 共同备份 → 保持） |
| 同计算上限 | 满时域分支 rollout 数 ≤ `B2` 分支数 × 时域（`B2` 为 `2×140=280`；保留 `k` 支即 `k×140`） |
| 信息权限 | 控制侧**只用**已发布命令历史 `pub` + 实测位置 `meas`；**不读真实延迟标签** |

**历史一致性筛选**：对每个分支 `L`，在最近 `W=40` 拍窗口上用**已发布命令历史**从窗口起点实测位置前推、与当前实测位置比对，得残差；**残差 > 声明噪声界**的分支被剪掉。两种模式分开报告：
- `sliding`：每拍用最近窗口**重新**计算（**可重新纳入**），最佳努力版本；
- `commit`：本 episode 内已剪不再纳入，自然「确认即锁定」版本。
- **允许时变延迟**下另设 `proto_all`：**保留所有允许后继分支**（sound 处理）。

**激励**：绕基点的**三角波**位置设定点（平滑、有界）→ 提供延迟可辨识的持续斜坡激励（锯齿跳变会与「延迟→位置单调」不符，已弃用）。

## 3. 固定延迟（正例）实测

三项固定延迟场景（`L=0.18/0.24/0.30 s` 恒定）。**有利低噪声档**（声明残差界 `0.002 m`；`disturb/noise` 幅度 ~`8e-4`）：

| 场景 | 评估器 | 保留分支数(均) | horizon 末端包络宽度 max | 覆盖违例 step | 真值分支被排除 step | 在 B2 预算内 |
|---|---|---|---|---|---|---|
| `fixed_Lmin` | **剪枝(sliding)** | **1.52** | **0.0216** | **0** | **0** | 0.89 |
| `fixed_Lmid` | **剪枝(sliding)** | **1.74** | **0.0216** | **0** | **0** | 0.83 |
| `fixed_Lmax` | **剪枝(sliding)** | **1.65** | **0.0257** | **0** | **0** | 0.84 |
| `fixed_*` | 剪枝(commit) | 1.00 | 0.0000 | 0 | 0 | 1.00 |
| `fixed_*` | 不剪枝(proto_all) | 7.00 | 0.0332 | 0 | 0 | 0.00 |
| `fixed_*` | `B2` 基线 | 2.00 | 0.0332 | 0 | 0（见 §6 注） | 1.00 |

- **正例成立**：历史剪枝确实**缩小保留分支数**（7→1.5~1.7）与**包络宽度**（0.0332→0.0216~0.0257，commit 版→0），且**本批未观测到覆盖违例**、真值分支**始终被保留**。
- **限定**：即使有利档，剪枝也**并非每拍都在 `B2` 的 2 支预算内**（`within_b2_budget_ratio` 0.83–0.89）——`B2` 的区间端点 2 支同样 0 覆盖违例且在预算内，剪枝**未显示计算优势**。

## 4. 允许时变延迟（边界负例）实测

**关键构造**（对应 spec「过去观测看似排除、未来仍可能发生」）：真实延迟先在 `[0,160)` 拍取区间一端，令**历史把另一端的分支剪掉**；随后在拍 `160` **跳变**到被剪掉的那一端。两个方向（`0.18→0.30` 与 `0.30→0.18`）都做。

| 场景 | 评估器 | 覆盖违例 step | 真值分支被排除 step | `missed_true_branch` | 安全比例 | 在 B2 预算内 |
|---|---|---|---|---|---|---|
| `tv_jump_low_to_high` | **剪枝(sliding)** | **79** | **35** | **True** | **0.62** | 0.88 |
| `tv_jump_high_to_low` | **剪枝(sliding)** | **83** | **39** | **True** | **0.60** | 0.86 |
| `tv_jump_*` | 剪枝(commit) | 82 / 99 | 35 / 52 | **True** | 0.61 / 0.53 | 1.00 |
| `tv_jump_*` | **保留全部（sound）** | **0** | 0 | False | 1.00 | **0.00** |
| `tv_jump_*` | `B2` 基线（2 支） | **0** | 0 | False | 1.00 | **1.00** |

- **判定：`missed_true_branch = True`（失败）**。跳变后即使滑动窗口最终能**重新纳入**被剪分支，仍有一段 **35–39 拍**真值分支不在保留集内，并产生 **79–83 拍**覆盖违例（真值运动落在预测包络之外）——即**过去观测看似排除的分支，未来仍可能成为真值**，剪枝**在一般时变延迟下不成立**。`commit` 版更差。
- **sound 处理**：**保留所有允许后继分支**可把覆盖违例降到 0（本批未观测到），但**保留 7 支 → 超出 `B2` 的 2 支等价预算**（`within_b2_budget_ratio=0.00`）。
- **`B2` 基线**：区间端点 2 支在时变场景**本批未观测到**覆盖违例且**始终在预算内** → 标准区间鲁棒处理已覆盖同一最坏情形，**比保留全部分支省算**。

## 5. 现实噪声（N1 量级）敏感性

同一原型在 **N1 观测噪声量级**档（声明残差界 `0.02 m`；`disturb/noise` 幅度 ~`5e-3`/`6e-3`）下：

- **固定延迟**：剪枝几乎**不缩小**（保留分支数 5.52 / 6.71 / 5.63），`within_b2_budget_ratio` 仅 0.02 / 0.00 / 0.03 → **无计算收益**；
- **时变延迟**：滑动窗口因保留集偏大（~5.8 支），覆盖违例被「淹没」为 0，但真值分支仍被排除 7–8 拍（`missed_true_branch=True`）；commit 版真值分支排除 27–90 拍、覆盖违例 13–20 拍。

→ 与 N1「延迟**只能给区间、不能给点**」相互印证：**现实噪声下延迟分支无法分辨**，历史一致性筛选退化为「几乎不剪」或「不可靠剪」。

## 6. 等价性判断（回答 spec「是否等价于标准集合辨识/多模型鲁棒控制」）

**结论：等价，`no_independent_method_contribution = true`，无独立方法贡献。** 依据（均由测量导出，见 `results/summary.json` 的 `conclusion`）：

1. **固定延迟**：剪枝＝**在线延迟辨识/自适应观测器**，其输出即「延迟不确定集」；其安全结果与 `B2` 的**区间端点鲁棒处理**一致（同样 0 覆盖违例、且在预算内），**未显示独立收益**。
2. **允许时变延迟**：剪枝**在一般情形无效**（`missed_true_branch=true` + 79–83 拍覆盖违例）；唯一的 sound 处理是**保留所有允许后继分支**（＝多模型/鲁棒集合），与 `B2` 的区间鲁棒**同源**，且保留全部分支**超出 `B2` 预算**。
3. **无剩余可证差异**：没有任何测量显示存在「**既保留全部后继、又低于 `B2` 成本**」的步骤/机制；`B2` 基线的 2 支已覆盖同一最坏情形。→ 该「历史细化」不能与标准集合辨识/多模型鲁棒控制区分。

**具体步骤/性质/待检验代价**（因等价，仅列出以示人，不作为新贡献）：若强行主张差异，其候选步骤为「用控制侧历史残差在线淘汰延迟分支」，可证性质仅限「**固定延迟**下的一致辨识」（需持续激励 + 噪声可分辨），代价是「时变下的 35–39 拍漏检 + 覆盖违例」；该性质与代价均可由**标准集合辨识**给出，故不构成独立方法。

**注**：`summary.json` 中 `B2` 基线的「真值分支被排除 step」在 `fixed_Lmid`（真值 0.24 不在端点 `{0.18,0.30}`）为非零，属**技术性计数**：`B2` **不主张点识别**，其安全指标看**覆盖违例（本批为 0）**。

## 7. 继续 / 否决 / 证据不足 依据

- **给出：否决（请求停止把「执行历史细化」当作独立机制）。**
- **依据**：在本阶段限定的可辨识执行系统与同等约束下，测量一致给出——（1）固定延迟下剪枝＝标准在线延迟辨识，未超越 `B2` 区间处理；（2）允许时变延迟下剪枝**不成立**（`missed_true_branch=true`，覆盖违例 79–83 拍），sound 处理＝保留全部后继（多模型/鲁棒集合）且**超 `B2` 预算**；（3）现实噪声下剪枝退化（无缩小或无收益）。据此 `no_independent_method_contribution=true`。
- **非「证据不足」的理由**：失败判据（`missed_true_branch`）与安全代价（覆盖违例）**直接由测量给出且方向一致**（两个跳变方向、两种剪枝模式、两档噪声均复现），符合 spec「若有可靠否决证据，直接提交否决分析，**不强行造新场景**」。
- **不外推的部分（留待后续，非本轮结论）**：本结论限于 **`model-level`、合成/借用参数、单轴位置闭环**；不排除在**多轴耦合/更强非线性/真机**下出现不同结论，但那需新证据，不作为本轮「继续」的理由。
