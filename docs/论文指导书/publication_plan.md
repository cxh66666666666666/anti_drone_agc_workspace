## 1. 先给出研究决策

**建议大改研究主线，但保留已经积累的平台与实验资产。停止把“DQN＋跟踪误差标量裕量”当作必须做成的论文中心，转向“执行滞后条件下可保留制动退路的预测避障”。**

推荐工作题目：**考虑执行滞后的无人机预测避障方法**。

论文要回答的问题是：

> 当上层给出一个看起来安全的绕障指令，而底层飞控存在滞后、惯性和跟踪偏差时，如何判断该指令执行后仍然来得及安全停下，并在窄通道或转弯中减少不必要的停车和绕行？

这条路线利用现有 PX4 位置设定点接口、响应辨识、净空测量和失败日志，也允许重新设计控制接口、动作空间与算法。核心不再是“用了什么强化学习”，而是**从命令到真实运动的可验证预测，以及它对安全与通行效率的影响**。

**当前建议锁定的是研究问题，具体算法只进入六周竞争性预研。** 本次进一步检索发现，未知延迟的输入输出安全过滤、方向相关可达集和分层跟踪误差补偿都已有研究。没有证据支持现在就把“延迟＋可达管＋制动”视为一年工作的必成创新。六周后依据原文差异与强基线结果决定继续、缩小或转向；这一决策是主计划的必要组成部分。

我的判断是：原计划的实验规范值得保留，但预期贡献偏薄；继续完成它不能自然推导出具备目标期刊竞争力。新路线具有更明确的问题、可分析的方法和更强的比较对象，值得投入一年半。但录用概率无法从仓库或少数已发表论文估计，本文不承诺“大概率录用”。我们能够控制的是：在投稿前，把最容易导致拒稿的创新性、对照公平性、结果可信度和任务价值问题逐一解决。

### 1.1 为什么选这条，而不是直接换一个更大的题目

| 方向 | 潜在价值 | 与现有工作的关系及主要风险 | 决策 |
|---|---|---|---|
| 继续 DQN＋κ 裕量调参 | 能完成现有工程闭环 | 改进容易退化成经验阈值；缺强基线 | 留作旧基线与回归实验 |
| 执行滞后、方向相关预测与制动可恢复性 | 能解释现有失败，可形成控制方法与适用边界 | 必须对标已有预测安全过滤，不能只拼装成熟模块 | **主线** |
| 连续动作安全 RL／高速视觉飞行 | 上限高 | 与已有强工作重合；感知、训练、实机和算力成本明显增加 | 不作为起步方向 |
| 动态障碍或多机协同 | 应用丰富 | 同时引入预测、博弈和感知误差，难定位贡献 | 静态主线成熟后择一小规模扩展 |
| 完整空地协同反无人机拦截 | 与仓库名称相关 | 要重新定义探测、通信、拦截与任务效能，基本是另一项课题 | 本篇不开展 |

这里的“大改”是重构研究问题与控制方法，不是把所有软件重写一遍。一个做透的问题，比同时做安全 RL、动态避障、SLAM 和多机协同更有机会形成完整论文。

### 1.2 投稿质量目标

提交的论文至少应包含三条相互衔接的贡献：

1. **问题与模型**：建立与实际设定点接口一致、显式包含执行滞后和历史命令的局部闭环模型，区分路径偏离、设定点跟踪误差与预测残差。
2. **方法**：提出并验证针对该接口的方向相关不确定性处理及制动可恢复性判定，使安全过滤在相近风险下减少过度保守；相位/速度调节是维持通行效率的执行手段。
3. **证据与规律**：用强基线、机制消融、独立场景和参数扰动，揭示在什么速度、延迟、净空和误差范围内有效，以及何时失效。

以上是**候选贡献**。只有新颖性检索和实验支持后，才能写成“提出了”；搭建 ROS/PX4 平台、多跑随机种子、增加 Dueling/PER 等不能独立占一个方法创新点。

### 2.2 四项基础问题必须先纠正

- **观测权限**：当前过滤器用到经激光距离筛选的场景真实几何。新主实验的控制器只能读取传感观测、估计状态和任务路径；场景真值由独立评分器使用。
- **预测验证**：当前预测最小净空与当前净空的比较属于一致性检查。应验证发出预测之后、在相同实际输入条件下的未来位置与扫掠净空。
- **终止语义**：`shield_infeasible` 是任务/证书失败事件；暂停命令已经下发也不等于机体已经安全停止。后续物理运动必须继续记录。
- **技术门槛**：导师沟通和期刊核验是需要推进的管理事项，不阻止已获授权的建模、文献、代码和可逆预实验。旧的行政 No-Go 不再阻塞技术进展。

## 3. 先证明值得研究：六周新颖性与问题验证

### 3.1 必须承认哪些是已有方法

MPS（模型预测屏蔽）、鲁棒预测安全过滤、可达管、终端安全集、制动备份、参考调节、路径时间缩放、残差 RL 都已有成熟研究。Hsu 等安全过滤综述的 §3.3 已直接介绍其中多项。

因此，“我们把可达管、制动和强化学习结合起来”仍然可能只是工程组合，不能作为立项依据。新颖性必须落在以下候选缺口上：

> 对外部只能访问设定点的闭环系统，能否用有界延迟和命令历史构造可计算的方向相关预测范围，并在可靠覆盖实际运动的前提下，相比固定各向同性误差膨胀显著减少通行损失？

“方向相关”指误差沿不同空间方向的范围不同。例如，沿航向的滞后较大，并不代表侧向也需要同样大的障碍膨胀。这个想法本身同样不是新概念；必须说明针对本问题新增了什么模型、计算方法或可验证性质。

### 3.2 文献检索与交付物

前六周精读最接近的 8—12 篇，不以总篇数作成绩。检索至实际检索日，包含：

- predictive safety filter / model predictive shielding / backup controller；
- reachability-based trajectory design / tracking error bound / FaSTrack；
- reference governor / path parameterization / time scaling；
- input delay / actuator dynamics / black-box tracking controller；
- robust MPC / data-driven uncertainty set / anisotropic uncertainty；
- UAV obstacle avoidance / safety filter / setpoint interface。

每篇记录：原始 DOI 或 arXiv 版本、控制输入、内环假设、延迟处理、误差集合、备份策略、终端条件、感知权限、对照、可复现代码、我们的具体差异。未获取原文的关键结论标“待核验”。

必须产出一张最近邻比较表，能写清楚：

> 相比方法 X 的假设 A，本项目处理限制 B；新步骤 C 带来性质或收益 D，代价 E；实验 F 能单独检验它。

如果填不出来，不进入大规模训练。首先复现一个标准预测安全过滤器，再从它的实际不足提出修改。

### 3.3 三个最小机制场景

1. **同位置、不同速度或命令历史**：当前几何净空相同，但制动需要的距离不同。证明只看当前距离无法区分两种状态。
2. **同误差模长、不同误差方向**：分别沿墙平行和朝墙运动，检验标量误差膨胀是否造成不同程度的误判。
3. **同路径、不同执行滞后**：逐步增加命令延迟，检验瞬时速度映射在哪个范围失效，以及模型显式考虑滞后后是否改善。

这些是用于解释机制的开发场景，不能当作随机泛化主结果。所有基线都应允许制动，避免把“别人没有刹车”制造成新方法优势。

**第六周决策**：若普通延迟模型＋标准预测安全过滤已能解决全部问题，新论文不能只报告实现成功。应研究更有价值的缺口，如误差方向保守性、跨内环配置适用性或受限观测下的可恢复区域；最多再给四周形成可检验差异，避免无期限追逐创新。

## 4. 问题定义与研究边界

### 4.1 主任务

单架四旋翼沿给定巡检路径飞行，在局部未知的静态障碍环境中避碰、通过并重新接近任务路径。允许在安全需要时降低路径进度或暂停；最终以实际通行和任务完成计分。

主研究先做定高平面运动，使用 PX4 与四旋翼动力学仿真构成的闭环；明确称为“定高避障”。稳定后加入有限高度变化验证。论文不以二维场景推出任意三维环境结论。

障碍包括圆柱、箱体、墙面和窄通道，逐步从简单可解释的几何转向组合环境。首阶段速度建议从当前验证范围开始，以 0.5、1.0、1.5 m/s 作候选工况；是否增加至 2.0 m/s 由制动、感知范围和执行稳定性决定，不把高速纪录当目标。

### 4.2 三种误差必须分开

设实际位置为 $p_k$，任务路径为 $\gamma(s)$，真正发给飞控的参考为 $r_k$，模型在时刻 $k$ 的未来预测为 $\hat p_{k+j|k}$。

- **路径偏离**：实际位置到合法路径进度附近的路径距离，反映任务代价；不能简单使用自交路径全局最近点。
- **参考跟踪误差**：$e_k=p_k-r_k$，反映对修改后参考的执行情况；同时记录参考时间戳，解释其滞后含义。
- **预测残差**：$p_{k+j}-\hat p_{k+j|k}$，必须在已知且相同的实际输入序列下计算，反映模型误差。

主动绕障偏离任务路径是允许的。不能把它全部当作执行不确定性，再反过来扩大安全距离。

### 4.3 信息和安全边界

主方案已知任务路径和允许飞行区域，未知局部障碍几何；使用机载 LiDAR/深度信息形成局部自由空间及未知区域。暂不研究完整 SLAM，先以仿真定位作为明确假设，再做定位误差扰动。

静态障碍中的可验证安全结论只能在以下条件下成立：初态可安全制动；状态、模型、延迟和感知误差处于声明范围；备份控制可执行；制动扫掠区域处于已观测自由空间；计算按时完成。动态障碍和超范围扰动不包含在这一保证中。

## 5. 方法设计：从实际接口出发

### 5.1 结构与第一版实现

```text
任务路径 → 候选局部参考/路径进度（确定性生成器，后续可接 DQN）
                         ↓
实际状态＋历史命令＋传感自由空间 → 闭环预测及方向相关误差范围
                         ↓
       检查“候选执行一段时间＋备份制动＋稳定保持”
                         ↓
  可行：选择通行代价最低者      不可行/超时：执行此前已验证的备份
                         ↓
         唯一命令发布器 → 既定外环/PX4 → 状态和日志
```

第一版不训练新网络。用有限个平滑局部参考生成候选，例如左/直/右偏移与若干路径推进比例组合；具体数量由动作可执行性与实时预算确定。制动/保持是独立的执行模式，不用“上升悬停”动作名代替。

先把标准方法和新预测机制做成纯函数/独立模块，再接 Gazebo。所有方法共享同一个命令发布器、限幅器和低层控制配置，避免不同模式暗中改变侧向锁定、速度缩放或控制权限。

### 5.2 执行接口：前六周内只选定一种主接口

默认优先保留现有位置参考接口，修复或重新定义其参考生成方式，通过系统辨识把已有外环与 PX4 视为组合闭环。不能把 `LQR 输出→位置设定点` 简化成直接加速度控制。

若试验发现该接口无法形成可重复的制动/保持行为，则在第六周前切换为明确的速度设定点接口，重新辨识，旧接口仅留作背景对照。不在同一主结果表里让不同方法使用不同接口。切换速度接口也不能假定速度指令瞬时实现。

建议上层初始决策频率 10 Hz、底层发布保持当前合适频率；实际周期、消息年龄与计算延迟必须实测。预测时域以“最大确认制动时间＋通信/计算延迟＋保持验证余量”确定，而不是固定相信 1 秒足够。

### 5.3 可辨识的闭环模型

第一版采用低阶线性/分段线性模型，状态包括位置、速度、必要的执行器状态或命令历史。示意形式：

$$
x_{k+1}=A_\theta x_k+B_\theta u_{k-d_k}+w_k,
\qquad d_k\in\{0,\ldots,d_{\max}\}.
$$

其中 $u$ 是实际接口接收的量，$\theta$ 表示已辨识参数范围，$w$ 表示未建模扰动。位置接口通常需要参考误差与命令历史，不能直接套用速度接口的一阶惯性模型。必要时用多模型覆盖不同速度/方向，但先证明简单模型不足，再增加模型复杂度。

辨识数据应覆盖：纵横向阶跃、短脉冲、不同幅度斜坡、左右反转、减速至停、路径转弯以及组合输入。按整段运行划分训练、校准和验证，不能把同一轨迹相邻时间步随机拆散到三个集合。

比较三种预测：当前恒速动作映射、显式延迟低阶模型、拟议模型/集合。先比较位置和扫掠净空的多步预测，再比较闭环控制结果。

### 5.4 方向相关可达范围：候选方法贡献的落点

对每个候选参考及备份控制，传播包含初始估计误差、参数误差、输入滞后与扰动的可达集合：

$$
\mathcal X_{j+1}=\operatorname{Reach}(\mathcal X_j,u_j,
\Theta,\mathcal W,\mathcal D),\qquad
\mathcal P_j=C_p\mathcal X_j.
$$

实现上优先采用区间盒或 zonotope；选择理由应是能否保留方向信息、覆盖实际运动、控制计算量。不要为了术语引入无法验证的复杂模型。

设标称位置为 $\hat p_j$，位置误差集合为 $\mathcal E_j$。对指向障碍的单位方向 $n$，用支持函数

$$
\sigma_{\mathcal E_j}(n)=\sup_{e\in\mathcal E_j}n^Te
$$

描述该方向最坏偏差，而不是在所有方向统一加 $\kappa\|e_{\mathrm{track}}\|$。无人机包络、感知误差和采样间扫掠误差另外计入，避免重复计算同一误差。

**拟研究的新增部分**是：怎样根据已执行命令与滞后状态构造足够紧、计算可承受的方向相关范围，并解释它与现有固定管、一般状态相关管或 RTD 的差别。支持函数和集合传播公式本身是标准工具，不作为新定理。

主实现采用离线校准后冻结的误差范围。不能依据最近几步误差小就任意缩小范围，否则可能破坏已有安全证书。基于已证实的一致性条件排除不可能模型，与凭经验缩小误差分位数是两回事；前者也必须给出保留真实模型的条件。扩大范围后要重新核对旧备份，不能假设旧证书自动仍然有效。

#### 具体预研对象：按执行历史约束的制动可达范围

前六周只试一项具体方法，避免“研究更好的可达管”过于空泛：

1. 在增广闭环状态中显式保存最近若干命令及其发送时间；将可能的延迟和响应参数表示为有限模型分支或有界参数集合。
2. 用已测得的输入输出和冻结噪声界检查模型分支的一致性；只排除与观测不相容的分支，不访问仿真注入的真实延迟。
3. 对仍可能成立的分支，预测“候选一步＋制动＋保持”的位置范围。尽量保留沿航向/横向及分支之间的结构，避免在很早的阶段压成一个大球。
4. 在预算允许的分支数量内做安全外包合并，保证合并不会丢掉可能真实运动；记录每次合并造成的保守性和运行耗时。
5. 将这套机制与**同样考虑延迟、同样采用方向相关集合，但不做历史一致性细化的鲁棒预测方法**比较；再与通用集合辨识/自适应管方法比较，确定是否只是已有算法的等价实现。

这里可能产生贡献的部分是：**在有限计算预算下，怎样利用可在线获得的执行历史保留必要分支，构造更紧的制动可恢复集合，并保持明确的包含关系与备份有效性。** “保存历史”“排除不一致模型”“集合外包”都是已有工具，只有产生区别于最近邻的具体计算步骤或有价值的结构性质后，才成立为方法贡献。

特别注意时变延迟：过去观测只约束过去，不能自动限制下一步延迟。若只能假设延迟在区间内任意跳变，就必须对所有允许的未来延迟分支预测；若采用有界变化率或驻留时间，必须在问题定义中明确，并用独立数据检查。不能为获得紧集合而凭空加入慢变化假设。

**否决条件**：如果收益只来自各向同性基线太弱、使用了真实延迟、低估噪声、忽略未来延迟跳变，或通用延迟增广鲁棒管已得到相同结果，就否决这一创新主张。此时已有代码仍能作为高质量基线，但不再投入半年完善同一个无差异算法。

### 5.5 可执行备份：保持“还能安全停下”的能力

候选方案由两个部分组成：先执行一个决策周期的任务动作，再接已定义的制动和保持策略。整个预测时域要求：

$$
\operatorname{Sweep}(\mathcal P_j,\mathcal P_{j+1})\oplus\mathcal B
\subseteq\mathcal F_k,
\qquad \mathcal X_N\subseteq\mathcal X_{\mathrm{hold}}.
$$

这里 $\mathcal B$ 为机体包络，$\mathcal F_k$ 是扣除感知/定位不确定性后的已确认自由空间，$\mathcal X_{\mathrm{hold}}$ 是备份控制能够维持的终端集合。只检查若干离散点可能漏掉穿越障碍，必须检查段扫掠或采用有依据的采样间膨胀。

式中的 `Sweep` 必须包含两个采样时刻之间的实际连续运动范围，不能仅连接端点就假定覆盖弯曲轨迹；应由模型传播或速度/加速度界构造采样间外包。局部地图更新时保留仍有效的静态自由空间证据，若定位误差或新观测使该证据失效，应重新检查备份并记录证书变化。

终端条件不能只有“速度接近零”。还应包括足够位置净空、剩余延迟命令影响、允许扰动下的保持能力和执行器约束。初始安全状态也要验证备份可行。

运行时保存上一周期的有效备份。新候选全部不可行或求解超时时，继续该备份的剩余控制；不能重新随意选择一个“看起来最安全”的动作并声称仍有证书。

若传感/状态异常使原备份前提失效，执行预定义应急策略并记录 `certificate_lost`，继续物理观察；这属于保证范围外事件，不计作已证明安全。传感短时丢帧只有在静态自由空间记忆和误差传播仍支持备份时，才允许沿用证书。

### 5.6 安全与通行效率：允许调节路径进度

使用弧长或明确归一化的单调进度 $s$，在可行候选中选择局部偏移与推进率。若 $s$ 为弧长，

$$
s_{k+1}=s_k+\nu_k\Delta t,\qquad 0\le\nu_k\le\nu_{\max}.
$$

评分包括路径推进、横向偏离、偏移变化和停车时间。碰撞/可恢复性作为可行性约束，不用奖励权重抵消。给定任务截止时间，长期悬停必须算失败，避免靠不移动实现零碰撞。

相位调节并非新概念。它的作用是让方法在安全需要时真正减速；必须与“标准预测安全过滤＋相同相位调节”比较，才能区分执行模型贡献和单纯降速收益。

### 5.7 DQN 的位置

先用确定性候选生成器完成方法闭环。若后续发现通道拓扑选择、绕障方向承诺或局部效率仍有瓶颈，再让 DQN 给候选排序；它不能取消制动证书。

第六个月做一次明确决策：

- 若无学习版本已经形成完整贡献，主论文采用无学习方法，DQN 作为对照；
- 若学习在同一安全层下稳定改善通行效率，再纳入主方法，至少 5 个独立训练种子；
- 连续动作成为必要设计时可以选 SAC/PPO，但只选一个成熟实现，不以换算法宣称创新。

这保留了既有 RL 工作的价值，也避免论文成败被一个不一定必要的网络绑住。

## 6. 理论与模型验证：证明什么，不证明什么

### 6.1 至少完成两项可核查分析

1. **条件安全性或递归可行性说明**：在有界误差、最大延迟、正确自由空间、初始备份可行、终端集合可保持和按时执行等假设下，新候选被接受或旧备份继续执行都保持约束。证明需覆盖命令延迟队列、采样间运动、备份移位及终端保持，不能只复制标准 MPS 结论后忽略实现差异。
2. **保守性与适用域分析**：用同一个有效误差集合比较方向投影和其外包球。在同等覆盖前提下说明方向投影不比外包球更保守；这个几何性质是标准事实，真正需要研究的是紧度、执行历史与计算代价。随后分析速度、延迟和可见距离如何限制可恢复区域。

可用一维必要检查帮助发现错误参数：

$$
d_{\mathrm{free}}>v\tau+\frac{v^2}{2a_{\mathrm{stop}}}+d_{\mathrm{uncertainty}}.
$$

该式仅在相应制动模型和减速度下界成立时适用，不替代三维闭环可达性分析。当前 `0.044 m/s²` 的低速拟合统计不能直接作为这里的全工况下界。

### 6.2 有限数据与安全保证的关系

- 有限样本的最大残差、p99 或 p10 都不能自动变成对所有未来运行成立的确定性界。
- 可以在明确的物理/模型有界假设下给条件定理，再用独立数据检验这些假设的经验覆盖；论文同时报告越界率和最大越界。
- 若使用统计校准，报告置信或覆盖定义。单步边际覆盖不等于整条轨迹联合安全概率；相关时间序列也不能直接套用独立样本结论。
- 如果无法建立可信误差集合或终端保持条件，就采用“经验鲁棒预测避障”的较弱主张。若连相对强基线的机制收益也不成立，则不能仅靠改标题进入投稿。

### 6.3 预测验证的正确做法

在时刻 $k$ 保存预测模型版本、实际初态、候选/备份输入序列及整条预测范围。对实际执行序列，检查未来 $k+j$ 的位置是否被覆盖，以及真实最小扫掠净空是否符合预测下界。

如果后来改了动作，原先“继续执行旧动作”的反事实预测不能直接拿来和新轨迹比较。采取两种独立验证：固定输入开环短段/制动实验；根据真实输入序列进行多步回放预测。另设分叉仿真评估未执行候选，但明确区分仿真反事实和实际观测。

预测精度、范围覆盖、范围体积/方向宽度、危险误放行、安全误拒绝分别统计。不能用“过滤器自己认为危险”作为独立危险真值。

## 7. 实验：必须战胜谁，怎样证明收益来自方法

### 7.1 比较对象

所有主比较方法共享任务、感知信息、实际执行接口、速度上限、允许飞行区域和任务期限。给每种方法合理且记录在案的验证集调参预算。

| 编号 | 方法 | 要回答的问题 | 优先级 |
|---|---|---|---|
| B0 | 现有规则避障，补齐统一执行与制动接口 | 相比现有工程方案有何变化 | 诊断对照 |
| B1 | 标准标称预测安全过滤：点预测、备份制动、相位调节 | 仅加入标准预测/制动机制能解决多少问题 | 主对照 |
| B2 | **延迟增广、方向相关的鲁棒预测安全过滤**，相同备份与相位调节 | 执行历史相关的范围细化是否超过成熟鲁棒方案 | **最近邻主对照** |
| B3 | **鲁棒局部 MPC/参考调节器**，采用可用的同等级模型与观测 | 独立安全过滤架构是否真有必要 | **强控制基线** |
| P | 拟议方法：执行历史/滞后相关预测范围、方向相关约束、可恢复性与相位调节 | 核心研究假设是否成立 | 主方法 |
| L0/L1 | 兼容版本的旧 DQN / DQN＋旧过滤器 | 交代研究起点和历史改善 | 补充，不能替代 B2/B3 |
| P-L | 学习候选生成器＋与 P 完全相同的安全层 | 学习是否带来额外任务效率 | 第六个月后按证据决定 |

B2 和 P 的核心机制比较应尽量使用同一中心预测、参数范围、输入权限和校准数据，仅改变误差集合表示或明确的拟议步骤。B3 不能故意使用更差的模型或过小的优化预算。若 B3 是重新实现而非原作者代码，要给出复现说明与基础工况验证。

各向同性版本作为弱化消融保留，不能充当唯一最近邻。R0 还需比较输入输出 DDSF、通用集合辨识/自适应管等候选最近邻；若最终研究差异直接针对其中一种，正式对照必须纳入它，可替换非关键 B1 或增加一个方法，不允许因为不好复现就完全回避。

旧 DQN 若使用不同状态维度、特殊规则或真值几何，应单独标注“历史系统比较”；不能混入同条件消融。不必复现所有跨平台视觉飞行方法：采用原论文对照只在输入与任务可比时成立。

### 7.2 必须做的机制消融

| 消融 | 保持不变 | 检验的机制 |
|---|---|---|
| 去掉显式延迟/命令历史 | 同样的其他模型、约束、候选和执行接口 | 处理执行滞后的必要性 |
| 保留延迟状态但去掉历史一致性细化 | 同样的有效模型集、方向表示、噪声界与备份 | 拟议细化步骤是否有独立收益 |
| 方向相关集合替换为有效外包球 | 相同覆盖对象、校准数据与中心预测 | 各向异性是否减少保守性 |
| 移除终端制动可恢复性，仅短视预测 | 相同传感、预测和计算预算；限仿真 | 只看短期无碰撞是否漏掉不可恢复状态 |
| 固定路径推进率 | 相同安全层，危险时仍允许应急停止 | 主动调整进度是否改善安全—效率折中 |
| 确定性候选与学习候选互换 | 同一个安全层与动作权限 | 学习是否有独立价值，仅在纳入 RL 时执行 |

消融先在机制场景验证，再在验证集检查。正式确认性消融只保留与论文核心主张直接相关的 2—3 项，其他进入补充材料，避免无目的地乘大实验规模。

### 7.3 场景设计

分开研究难度、泛化和极限，不能混成一个平均成功率。

- **基础**：开阔空间、单障碍、左右镜像、绕障后回归路径。
- **受限空间**：不同通道宽度、贴墙飞行、连续交错障碍、L 形转弯。
- **执行压力**：多速度、命令延迟、响应参数变化、扰动与制动初态变化。
- **观测压力**：测距噪声、延迟、短时丢帧、遮挡及局部未知空间；未观测区域不能默认为自由。
- **泛化**：未见布局家族/组合、不同障碍尺寸、不同参考曲率或另一个内环参数配置。
- **能力边界**：来不及制动的初态、不可通过通道、超出模型边界的扰动。单列压力测试，不与正常可行任务混算。

静态几何 A* 可行不等于动力学可行。用独立、较慢的离线规划/轨迹验证器检查主任务是否存在满足共同动作限制的可行轨迹；其未找到解只说明“可行性未确认”，不能直接宣布场景不可行。不要依据 P 是否成功筛选主测试场景。

### 7.4 数据划分与新测试集

新建 `paper_v3` 协议。旧实验目录和清单不修改，旧 test 中参与诊断的样本归入新研究开发历史。

新数据建议分为：

1. **模型辨识集**：无障碍及安全控制激励，拟合闭环模型。
2. **误差校准集**：独立运行，用于固定误差范围和模型适用域。
3. **开发/训练集**：调试方法，若使用 RL 则在此训练。
4. **验证集**：选超参数、模型和停止规则；建议先准备 20 个独立布局。
5. **确认性测试集**：协议冻结后使用，初始预算为 60 个布局×3 个扰动种子。
6. **分布外测试集**：初始预算为 20 个新布局/参数组合×3 个扰动种子，与主测试分表。

60/20 是工作量起算点，不是期刊要求或统计充分性的保证。镜像、旋转和只轻微平移的同一原型归为一个布局家族，在划分时整体分配。记录生成规则、地图家族、场景种子、扰动种子和学习种子；保留未使用测试清单的访问记录。

正式测试前冻结：代码内容哈希、环境镜像、方法配置、参数来源、场景清单、主要指标、比较对象、统计方案与缺失处理。时间戳明确早于正式数据生成；包含结果的后生成报告不能单独充当预注册证据。

### 7.5 样本量与算力预算

没有学习模块时，B1/B2/B3/P 共 4 个主方法，每个先预算 240 次，共 **960 次闭环试验**。B0、历史 DQN 和非核心消融先在开发集评估，正式补充实验另列预算。

若一次试验模拟时间 120 s、实际实时率为 0.5，960 次净仿真约 64 小时；复位、启动、失败重试和日志可能再增加 50%—100%。这只是示例，须先用 20 次试验测量本机实际耗时。硬件、并发数和磁盘消耗按实测制定，不能默认有大规模 GPU 集群。

若加入 P-L，至少 5 个独立训练种子，每种学习方法对应 5×240 次评估；其训练成本另计。已有一个策略重复 5 次不是 5 个训练种子。确定性方法不复制成“5 个种子样本”增加统计量。

低保真模型用于调试、参数初筛和反事实诊断，PX4 闭环用于主结果。不能只用拟合模型生成数据，再用同一个模型证明自身准确；必须在未参与辨识的 PX4 配置或独立运动数据上验证。

### 7.6 指标与公平比较

**主要指标采用安全与任务完成的联合视角：**

- 几何碰撞率及原始计数，另列物理接触事件；
- 在共同任务期限内无碰撞完成的比例；
- 所有已启动试验的受限完成时间：成功者记实际完成时间，碰撞、停滞、超时等失败者记统一期限，同时报告失败类型。

另外报告：最小扫掠净空、路径偏离、恢复时间、停止次数/时长、路径长度、预测范围覆盖与越界、备份触发、证书丢失、CPU 求解耗时分位数和超时比例。

注意以下区别：

- 同时报告修改后参考跟踪误差和名义路径偏离；不能用很大的主动绕行掩盖跟踪性能。
- 成功轨迹完成时间单独报告，但不能只在各方法自己的成功样本上比较后宣称整体更快。
- 过滤干预率是解释性指标，不是越高越好；最终看是否安全且完成任务。
- 降速会减少碰撞，必须报告达到的实际速度，并画安全—完成时间/成功率折中曲线。
- 以两种视角比较：共同速度上限/期限下的系统结果；由验证集预先选定配置在相近风险目标下的效率结果。不得在测试集上挑“最好的一点”。

### 7.7 物理终止、基础设施故障与统计分母

一次已起飞的任务即使被安全层宣告失败，仍要执行备份并继续观察，直至速度/漂移在规定窗口内满足稳定条件，或发生碰撞，或达到统一尾段上限。尾段碰撞归属原试验。记录任务结束时刻和物理观察结束时刻，不能在复位传送后宣称安全停车。

起飞前 reset 失败记为启动失败，不与已启动飞行的碰撞率混合；主结果同时列计划次数、成功启动次数、碰撞/任务结果及基础设施异常。碰撞后的仿真崩溃不能当作基础设施原因删除。真正缺失结果保留，并给必要的最坏情况敏感性分析。

### 7.8 统计分析与预先决策

先在验证集确定最小有意义差异和所需样本量。候选目标是：相对 B2，在碰撞风险不增加超过预定容忍量时，提高任务完成率或减少受限完成时间。可用“时间改善 10%”和“碰撞率非劣界 2 个百分点”作为讨论起点；它们是研究决策参数，**不是期刊门槛，也不能先看测试结果再选**。

使用配对场景/扰动比较。布局家族是重要聚类单位；学习方法还需要计入训练种子这一交叉变化来源，可采用场景与种子的双向重采样。不能把所有时间步或同场景重复运行视为独立样本。

报告原始计数、比例、效应量与 95% 区间；聚类 bootstrap/适当分层模型用于方法差异。Wilson 区间仅在相应独立二项假设合适时使用，不以简单池化的 Wilson 区间替代聚类分析。

稀有碰撞下的非劣结论可能需要远多于 240 次；应在冻结前做功效/精度规划，并相应增加样本或缩小主张。即使理想独立条件下 240 次零碰撞，按近似“三除以样本量”法则，上界仍约 1.25%；实际有场景相关性时不能直接套用。零碰撞不是零风险。

B2 是预指定的主要比较对象，B3 是强外部对照；其他多重比较调整或标为探索性。测试不足以支持非劣时写“证据不足”，不能用差异不显著当作同等安全。

## 8. 仿真可信度与成果上限

### 8.1 三层验证

1. **离线模型与算法验证**：时间对齐、命令延迟队列、几何扫掠、可达集合包含性、备份移位、终端保持、唯一发布权限。
2. **PX4 闭环验证**：真实点云输入、执行滞后、接触与几何净空交叉核对、实际制动、实时运行及故障尾段观察。
3. **跨配置验证**：改变未用于辨识的 PX4 响应/控制参数、质量/阻力或延迟，在明确参数范围内测试；超范围的结果单列压力试验。

闭环仿真应采用记录和控制相互独立的架构。评分器可读取 Gazebo 真值，但不回传给主控制器；“真值感知”只作为额外上限实验，标明信息优势。

### 8.2 硬件在环和实机如何安排

用户目前暂无实物平台，因此首次投稿主线按**纯仿真且不依赖购置硬件**设计。不把实机作为未经核实的期刊硬性条件。同刊已存在仿真型研究，但这不意味着本项目一定不需要额外证据。

第六个月评估资源，优先级为：

1. 完整的强基线和有解释力的跨配置仿真；
2. 若有飞控板与条件，加入硬件在环，验证计算/通信时序和部署接口；
3. 若实验室具备成熟平台与场地，再做低速、简单静态障碍的少量实飞，验证预测与制动误差。

硬件在环主要验证真实计算/通信链路，不能替代空气动力学真实性；实飞少量成功也不能证明普遍安全。若资源不足，保留明确的仿真论文定位，不以压缩主要对照来换演示视频。

### 9.2 R0 的三种结论与真正的备份路线

- **继续主线**：执行历史相关机制在相同误差覆盖、相同计算上限下，比合理的方向相关延迟鲁棒方法有可复现收益，而且原文差异成立。接下来投入模型与理论完善。
- **问题有价值，但候选方法无新增内容**：优先转为“固定计算预算下的安全过滤计算调度/约束筛选”，研究保守筛选是否保留全问题可行性、何时复用上次证书、如何处理求解超时；必须与已有事件触发和约束压缩方法重新比较。这是一个备选研究问题，不是已经成立的第二创新点。
- **问题与两个候选机制均缺乏差异或现实效应**：停止算法主线，与导师在第 8—10 周做一次正式改题讨论。另一可保留资产的方向是“闭环控制失效边界的仿真测试方法”，研究同等仿真预算下的边界搜索/反例发现与统计估计；必须有测试方法创新、随机/分层采样基线，并使用独立确认样本或正确重要性权重，不能把定向找到的失败比例写作真实碰撞概率。该方向也需重新检索，不能当作自动可投的降级出口。

不同时开展三条路线。备选的意义是限定最大试错成本，避免一年后才发现没有可发表贡献。对用户目标的承诺是认真追求目标档次，不能将“没做成就随便投低一级”预设为成功。

## 10. 论文怎么组织才有说服力

### 10.1 建议正文

1. **引言**：设定点执行与预测不一致导致的安全/保守性问题；已有方法及具体未解决点。
2. **系统与问题**：实际接口、延迟、状态/输入、观测权限、路径任务和安全假设。
3. **方法**：拟议闭环预测范围、方向约束、备份可恢复性与参考选择；标准部分引用原文。
4. **性质与实现**：条件保证或适用域分析、算法复杂度、超时和证书失效处理。
5. **仿真设置**：模型验证、任务、B1/B2/B3、数据隔离、指标和统计。
6. **结果与讨论**：主要对照、机制消融、跨配置泛化、安全—效率折中、失败边界。
7. **结论**：只总结已支持贡献，交代仿真/感知/扰动限制。

不要先写出“显著提升、保证安全、高泛化”的摘要，再寻找能填进去的数字。

### 10.2 必须支撑核心论点的图表

| 图表 | 需要说明的事实 |
|---|---|
| 执行链路图 | 论文模型与实际接口一致，无隐藏规则或真值通道 |
| 机制反例图 | 相同净空下，不同速度/历史需要不同判断 |
| 多步预测与实际运动图 | 方向相关范围是否覆盖真实运动，是否明显更紧 |
| 制动全过程图 | 拒绝危险指令后确实停下，尾段没有被复位截断 |
| 主对照表 | 同任务、同信息、同速度/期限下的成功、安全、效率和计算量 |
| 安全—效率折中曲线 | 收益不是仅靠极端降速或悬停换取 |
| 延迟×速度/通道宽度能力图 | 方法适用域及失效边界，而非只展示挑选的成功轨迹 |
| 核心消融表 | 新增步骤的独立效应；哪些改动没有贡献 |

本地旧细则建议中文标题一般不超过 20 字、摘要约 260 字、关键词 5—8 个且盲审去作者/基金信息；这些仅作为已有文件中的格式提示，投稿时按官网最新版本核验。

### 10.3 投稿前的五个模拟审稿问题

- **这是不是标准 MPS/鲁棒 MPC 换了一个平台？** 能具体指出新的预测/误差处理及其相对最近邻的必要性；否则创新不足。
- **为什么不直接用鲁棒 MPC？** 有 B3 数据，说明性能、计算成本或接入限制上的实际取舍。
- **安全保证是否把模型误差和感知问题藏进假设？** 展示假设适用范围、独立覆盖验证和越界失败。
- **收益是否来自隐藏的刹车、规则或真值几何？** 有统一执行层、信息权限审计和消融。
- **是否只是很慢所以不碰撞？** 有共同任务期限、实际速度、完成率和折中曲线。

这五个问题若有一个核心问题无法回答，应先补研究，而不是润色措辞。

## 11. 风险、止损与不自动降档

| 风险 | 识别信号 | 决策 |
|---|---|---|
| 新颖性被现有工作覆盖 | 最近邻已处理相同接口/滞后/集合且证据更充分 | 第六周前调整具体问题；不以“首次用于本平台”替代贡献 |
| 标准强基线已经足够 | B2/B3 与 P 效果相同或更好 | 检查是否存在有价值的计算/保守性取舍；无则停止该方法主张 |
| 误差范围过宽 | 几乎所有通道都不可行 | 找到主要误差来源、改进模型或缩小真实适用域；不任意缩裕量 |
| 模型覆盖不成立 | 测试残差频繁越界 | 停止安全保证主张，修正辨识/集合；不能仅删异常 |
| 安全靠提前结束获得 | shield 失败多、尾段碰撞未统计 | 固定尾段观察与任务失败规则，再重评全部方法 |
| 感知改造吞噬时间 | 长期在建图/定位而非方法上工作 | 定高、局部已观测自由空间、冻结感知模块；降低感知贡献主张 |
| RL 没有独立收益 | 干预层承担全部决策，学习跨种子不稳定 | 第六个月移出主方法，保留对照 |
| 仿真数据规模过大 | 耗时和存储超出实测预算 | 删非核心扩展，优先 B2/B3、主要指标与统计精度 |
| 硬件资源不可得 | 第六个月仍没有稳定平台 | 完成仿真与跨配置证据，不无限等待实机 |
| 结果不足以支持目标投稿 | 仅胜过弱基线、消融无效、缺创新 | 在剩余时间里改研究，不自动改投低档期刊，也不把负结果包装成成功 |

本篇暂不同时做多机协同、完整 SLAM、视觉端到端高速飞行、在线学习安全证书与动态障碍预测。若主线提前成熟，优先补强跨配置验证或实机证据；动态障碍作为下一篇或明确缩小范围的补充，不把静态停车保证直接套到移动障碍上。

## 12. 最终验收：何时值得投《系统仿真学报》

投稿前逐项勾选；这是一份内部质量清单，不是期刊官方录用标准。

- [ ] 最近邻方法差异有原文依据，拟议贡献不只是标准模块组合或换平台。
- [ ] 至少一项新的方法步骤或有实质价值的建模处理，经机制实验与消融支持。
- [ ] 有 B2 延迟感知鲁棒预测过滤、B3 强控制基线；公平性与实现正确性可解释。
- [ ] 预测检查对齐未来实际输入与运动；不把当前净空的一致性当作未来安全验证。
- [ ] 有实际制动/保持证据，任务终止后继续观察；碰撞率没有被提前复位截断。
- [ ] 控制观测与评分真值隔离；几何代理和接触指标分别报告。
- [ ] 数据划分、确认集、代码内容、种子和统计协议可追溯，无旧 test 调参冒充盲测。
- [ ] 安全—效率收益超过预定最小有意义差异，或有其他明确、诚实且重要的性能取舍。
- [ ] 不确定性、有限数据、保证条件、分布外失败和计算超时均有报告。
- [ ] 当前投稿要求与学校认定已核实，稿件经过针对创新与对照的实质审阅。

这份计划的目标是把已经完成的工程工作转化为可解释、可比较、可复核的研究成果。未来一年半最值得投入的部分，是把“为什么这个动作执行后仍然可恢复、为什么比成熟方案更少保守”真正研究清楚。
