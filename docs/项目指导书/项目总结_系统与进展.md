## 二、这是一个什么样的系统

### 2.1 问题背景

多旋翼无人机保有量快速增长（中美登记数已超 200 万台），"黑飞""滥飞"对公共安全、关键基础设施、航班秩序等构成现实威胁。现有反无人机装备以**固定式定点被动拦截**为主，存在机动性差、灵活性低、作业效率低、智能化程度低等问题，无法对移动式、大范围目标进行主动拦截。

### 2.2 项目定位

> 研发**空地协同移动式无人机拦截系统**：以移动式反无人机平台（无人车）为拦截载体，协同无人机提供空中全局视野，实现移动式主动拦截，解决传统设备"动不了、看不远、不够智能"的痛点。

系统核心是"**空地协同**"：无人机负责大范围环境感知与全局信息获取，地面移动平台负责抵近与拦截，二者通过高速通信链路实现"感知—决策—执行—反馈"闭环。

### 2.3 三大研究内容

1. **协同感知与多源信息融合**
   无人机携带多传感器收集目标区域环境信息，实时传回地面平台；平台端做数据校正与关键特征提取，按多源信息互补原理动态权重融合，生成环境综合态势图。

2. **协同路径规划及实时动态优化**
   无人机利用高空视野获取小车周边障碍物分布与动态变化并回传；地面平台据此构建地图，结合 GPS 与目标点，用全局规划算法生成最优路径，并用局部优化策略实时规避突发障碍。

3. **协同控制策略（分层分布式架构）**
   - 信息感知层：无人机获取大范围环境信息，地面平台传感器获取近距离障碍信息；
   - 决策与执行层：无人机自主调整飞行姿态与监测范围，地面平台结合全局信息与局部感知规划路径并实时调整。

### 2.4 创新点

- **思想创新**：突破固定式定点被动拦截，提出移动式主动防御拦截方法，提升机动性与覆盖范围。
- **技术创新**：提出"无人机协同移动式反无人机平台进行路径规划"的新方法，将多源环境信息融合、路径规划、空地协同控制有机结合，构建无人车全局规划模型 + 局部路径优化与避障策略。

### 2.5 技术路线

```text
无人机（携带传感器）──环境信息──▶ 移动式反无人机平台
      │                                    │
      │ 高空宏观信息                        │ 数据预处理 / 特征提取 / 多源融合
      ▼                                    ▼
  协同感知 ◀───────────────▶ 环境综合态势图
                                           │
                                           ▼
                          全局路径规划 + 局部动态避障优化
                                           │
                                           ▼
                    分层分布式协同控制（感知-决策-执行-反馈闭环）
                                           │
                                           ▼
                              仿真与实物实验验证与优化
```

## 四、当前完成情况

工作区 `anti_drone_agc_workspace` 已建成基于 **Ubuntu 20.04 + ROS Noetic + PX4 SITL + Gazebo** 的实验平台，技术栈与模块如下。

### 4.1 系统平台与仿真环境（已完成）

- 完整的 PX4 SITL + Gazebo 仿真环境，机型 `iris_3d_lidar`（兼容 XTDrone 模型库），集成 MAVROS；
- 统一启动脚本 `scripts/start_sim.sh`，支持 `sim / takeoff / lqr / perception` 四种模式，以及 `--trajectory`、`--with-perception`、`--obstacle`、`--training`、`--experiment-logger` 等选项；
- 仿真默认无头（headless）运行；
- 地面小车仿真环境与启动脚本 `scripts/start_ground_sim.sh`。

### 4.2 无人机与小车发射/控制（已完成）

- `drone_launch_controller`：连接监控、自检、解锁、起飞/降落、模式切换；
- `car_launch_controller`：小车节点含状态发布、健康检查、运动控制；
- `air_ground_core`：空地协同地面平台控制节点。协同层已按《M0 接口契约》`agc-m0-v1.2` 落地，空地闭环 M2 → M3 → M5 → M6 已验收；`/agc/ground/cmd_vel` 是地面唯一执行口，旧 `car_commander` 的写速度循环在协同 run 中停用（见 `src/air_ground_core/launch/agc_collab.launch`）。

### 4.3 轨迹追踪（已完成）

`lqr_trajectory_tracker` 基于 LQR 的轨迹跟踪控制器，支持轨迹类型：

- `linear`（直线）、`circular`（圆周）、`helical`（螺旋）
- `fixed_horizontal`（固定水平 8 字形）
- `step`（悬停：定点、零速度/零加速度）

参数化配置见 `config/default_params.yaml`，可输出跟踪误差等评估数据。

### 4.4 感知与局部避障（已完成）

- **感知层**：`rl_obstacle_avoidance` 基于 Velodyne 激光雷达（VLP-16/HDL-32/HDL-64）的扇区特征感知，输出 `/obstacle_features`；
- **规则避障**：基于扇区距离的绕行策略，支持单障碍绕行与多障碍连续绕行；
- **强化学习避障**：DQN 局部避障训练闭环（Dueling + Double DQN + 优先经验回放，PyTorch），含经验回放、贪心评估与模型管理；
- **地面车避障**：`rl_ground_avoidance` 镜像无人机侧实现（运动学模型 + 虚拟激光）；
- **安全过滤**：`safety_filter.py` / `safety_policy.py`，含紧急/碰撞/安全三级距离阈值与不可行率统计；
- **场景生成**：`scenario_generator_v2~v4`，支持障碍物布局、起降净空约束与垂直逃逸通道；
- **协同侧接口**：感知与多源融合的协同接口已按《M0 接口契约》`agc-m0-v1.2` 落地并验收，见 `docs/项目任务日志/M4/M4_目标识别与多源融合验收_v1.md`。

### 4.5 控制链路（已完成）

```text
/iris/velodyne_points ──▶ perception_node ──▶ /obstacle_features
                                                   │
                                                   ▼
                     rl_planner_node ──▶ /rl_planner/action（离散动作）
                          │              /rl_planner/local_goal（局部目标点）
                          │              /rl_planner/local_offset（LQR 位置参考偏移）
                          ▼
            lqr_tracker_node ──▶ /mavros/setpoint_position/local
```

### 4.6 实验记录与评估（已完成）

- `experiment_logger_node` 记录飞行数据至 `experiment_data/`；
- `scripts/evaluate_experiment.py` 计算六项指标：避障成功率、最小障碍距离、跟踪误差、路径长度、避障耗时、偏移抖动；
- 评估报告另含 `shield_infeasible_rate`（安全过滤不可行率）与 `reset_failure_rate`（复位失败率）。

### 4.7 已验证场景（Gazebo 仿真）

| 场景 | 障碍物配置 | 结果 |
|------|-----------|------|
| 无障碍 | 无 | 沿 8 字形轨迹正常飞行，无异常偏移 |
| 单障碍 | (5, 0, 2) 柱体 | 稳定绕开，避障后恢复原轨迹 |
| 三障碍 | (5,0,2) (10,2,2) (15,-2,2) | 成功连续绕行三个障碍物 |

### 4.8 训练与研究成果积累

- 多轮 DQN 训练运行记录（`training_runs/`），含 v3 试跑与 v4 正式多随机种子（s101–s505）批次；
- 算法侧安全过滤、场景生成、跨场景校验等实验脚本与阶段记录（`experiments/`、`docs/论文指导书/`）；
- 相关工作已形成论文写作素材，处于选题与论证推进阶段。
