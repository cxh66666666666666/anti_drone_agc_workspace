## 三、M6 不可达场景审计（按任务状态判断）

- **现象**：不可达场景 `ground_planner` 无可行路径，`/agc/ground/path` 依契约（≥1 Hz 且非空）**不发布**，现场接口审计报 `频率 /agc/ground/path 0.00 Hz` 与 `样本 /agc/ground/path`（窗口内无消息）两项 FAIL。
- **口径（定义）**：不再对 fault 类别**整体**豁免，改为**按任务状态**条件豁免——仅当（1）非 path 项无 FAIL、（2）path 频率/样本项缺失、（3）该场景**全部回合**按预期正确失败（`final_state=5`、`reason=PLAN_UNREACHABLE`，即无可行路径且正确失败）三条同时成立时，path 项才豁免通过。任一条件不满足即判 FAIL：名义场景缺 path（异常无路径）、或失败原因非 `PLAN_UNREACHABLE`，都不得据此放行。
- **实现**：[verify_m6_scenarios.py](file:///home/ubuntu/anti_drone_agc_workspace/src/air_ground_core/scripts/verify_m6_scenarios.py) 的 `audit_path_failures()` 从各批次目录 `audit_interfaces_cycle*.json` 拆分 path/非 path FAIL，`E2` 项按上述三条据任务状态结算。
- **结果**：重跑 `verify_m6_scenarios.py` 得 **PASS=81 FAIL=0**；不可达 `E2` 条件豁免、其余场景全项通过；名义 path 仍强制满足频率（实测 1.99 Hz）。反向护栏已核验：名义异常无路径（终态 `TRACKING_SUCCESS`）不豁免、不可达现场 infra 失败不豁免。
- **文档**：[M6 验收 §一/§5.1/§5.3/§七/§八.3](../阶段1/M6/M6_空地协同任务场景验收_v1.md) 已同步。
