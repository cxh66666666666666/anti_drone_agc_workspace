## 一、任务口径与诚实说明

- 本任务实现的是**真值派生的感知仿真**：由 Gazebo 真值（目标/无人机/障碍位姿）加噪声、延迟、丢包、遮挡、偏置与虚警生成观测；
  **不是真实视觉/雷达识别的标定**，A0 字段取值均为工程取值，不代表任何真实传感器性能。
- 在线链路语义不变：观测仍发布 `SensorObservation` / `AirObservationArray`，目标仍单 `target_id`；
  **真值关联 ID（`truth_id`）、虚警位置（`fa_pos`）、真值面子段仅写入离线 `perception_log.jsonl`，绝不进入在线消息**。
- 虚警为**仅评估日志**记录，**不进入在线发布**；多目标关联与在线虚警接线延后到 A2（涉及 `target_id` 规则，需走契约检查点）。
- 阶段 A 终态只称 `TRACKING_SUCCESS`；本项目无拦截机构，**不得出现 `INTERCEPT_CONFIRMED`**。

## 三、观测模型定义

- **通道内相关**：`corr_xy` 构造 x/y 白噪声相关 `u_y = ρ·u_x + √(1-ρ²)·u_y`。
- **通道间公共模态**：同 `corr_group` 且 `corr_rho>0` 的通道共享按 `(组, bucket)` 派生的公共模态 `g`，
  以 `u = ρ_c·g + √(1-ρ_c²)·u` 叠加；两通道同组实现通道间误差相关。
- **时间相关**：`noise_tau_s>0` 时按 bucket 栅格递推 AR(1) `a_b = ρ_t·a_{b-1} + √(1-ρ_t²)·u_b`，`ρ_t=exp(-(1/obs_hz)/τ)`。
- **确定性偏置**：`bias_m`（world 系）逐观测相加。
- **成簇丢失**：每通道两态机（正常/突发），`drop_burst_prob` 缩放进入率，`drop_burst_mean_gap_s`/`drop_burst_mean_s` 为平均间隔/持续；
  同 `drop_group` 组共享状态机（每拍每组只更新一次）。
- **遮挡**：`perception_model.occlusion.enabled` 时对无人机→目标/障碍视线做 OBB（按 `pad_m` 外扩）相交测试，
  命中则 `gate_reason="occluded"`、`occluder=<障碍名>`、不产生观测。
- **虚警**：每拍概率 `false_alarm_rate_hz/obs_hz`，命中产生 `is_false_alarm=true` 与 `fa_pos`（仅评估日志）。
- **机动**：`sinusoid`（`heading_deg`/`amplitude_m`/`period_s`）与 `circle`（`radius_m`），合速度受车上限约束（<0.9 m/s）。
- **RNG 命名空间**：各通道独立流（噪声/成簇/虚警按 `base_seed + 偏移 + 101·idx` 派生）；公共模态组按组出现次序派生；
  `deterministic_reseed=true` 时以 `bucket=round(t_sim·obs_hz)` 为格子，白噪声/公共模态/AR(1) 均为 `(seed, 通道/角色, bucket)` 的纯函数。

## 七、未决边界

1. **跨 run 逐条一致不可得（已量化）**：Gazebo 非锁步 → 两次 run 的 `t_sim` 相位/拍数不同；且 `intruder_uav` 为动态模型，
   真值 z 在 0.05s bucket 窗口内有 ~1e-3 物理微抖。故采用 **bucket 栅格 + 残差判据**：
   在配对 bucket 上 `|Δobs-Δtruth| ≤ 1e-9`（实测 max 4.4e-16，n=2907）证明观测=真值+可复现噪声偏移；
   truth 相等 bucket 上 obs 严格一致 655/655。真值的物理微抖不计入观测模型不确定性（`replay_check.json`，status=inconsistent 按逐点严格定义）。
   注意 `replay_check.json` 中 `status` 与 `verdict` 的口径区别：`status` 为逐点严格相等定义（`inconsistent`），
   `verdict` 为观测模型确定性判据（bucket 栅格 + 残差 `|Δobs-Δtruth|≤1e-9`，`consistent`，`n_residual_gt_1e-9=0`、`max_residual=4.4e-16`）。
2. **`d0_freeze.py --check` 现状 FAIL**：因 A0 **有意**改动 `perception_sensors.yaml`/`agc_params.yaml`/`air_perception.cpp`/`intruder_driver.cpp`/`d1_scenario_gen.py`
   （配置字段级扩展，参照任务清单第二节第 6 条与 N1 先例，**不构成契约变更**）。但 `eval_protocol_v1.yaml`/`eval_manifest.schema.json`
   语义与冻结 **D 测试集数据（198/198 哈希）** 未变，已由 `verify_a0_perception.py` 第 9 项与 `experiments/d` 树哈希佐证。
