## T1 最近邻与命题（`three/01_最近邻与命题.md`）

- [x] `01_最近邻与命题.md` 存在，含 ≥3 个**真正接近**的算法（覆盖事件触发安全过滤、约束筛选/压缩、可达集快速外包或证书复用），以**原文**核查算法与假设，非摘要/名称替代
- [x] 新增来源保留**版本、页码/公式及访问日期**；归档 PDF 记录 SHA-256；沿用 `two/08` 已核实来源
- [x] 差异表覆盖六列维度：允许延迟转移规律、状态/历史信息、覆盖或递归可行性前提、备份及超时语义、主要计算步骤、哪些已解决拟议问题
- [x] **恰好一个**可证伪候选步骤，含输入、输出、保守性条件、**一个能失败的例子**、相对最近邻的新内容
- [x] 通过判据自检留痕：能指出具体算法步骤及最近邻未覆盖的条件/性质；未以「代码更快」「比旧 DQN 好」充当方法差异
- [x] 独立审查发现当前差异/性质未成立，已**转 Task 6 改题准备**；否决理由见 `three/04_研究决定.md`，`01` 顶部附复核提示，未强行进入 T3

## T2 对照协议（`three/02_对照协议.md`）

- [x] `02_对照协议.md` 含固定的**场景/参数/指标清单**
- [x] 选定一个**主转移规律**并写清物理依据；逐拍任意延迟用 `two/15` 的**逐拍可达集传播**作标准安全基线
- [x] 固定延迟与单次跳变**另列**，未把其零违例外推为任意切换下的可靠基线
- [x] 统一口径齐全：模型、命令限制、方向误差、可见信息、候选集、共同备份、计算机/运行环境、时限；控制侧**不读真值**；各方法跑**同一组预先登记**场景
- [x] 指标清单含全部预登记项：逐时域覆盖、物理碰撞、裕量违例、假安全证书、通行/停滞、证书不可用、备份接管、每拍工作量与 p50/p95/最大耗时、超时次数
- [x] 记录**独立运行身份、失败与缺失**；在相同安全要求下比较成本与通行；**未**用端点 2 支制造效率优势
- [x] 预登记主判据 =「**p95 每拍耗时至少降低 20%**」并**固定重复计时次数**（≥30 次/场景/方法，p95 同批样本计算）；写明不达标不得事后更换主指标
- [x] 备份与候选执行按 `two/14` 逐拍协议；对「**证书只核对首个命令**」已另作限定，未写成完整未来轨迹或一般安全保证
- [x] 旧位置模型结果标 `model-level`；本轮**未声明**统计安全边界
- [x] 至少含一个**安全应通过**、一个**必须拒绝**、一个**时变延迟切换**、一个**求解超时/备份接管**样例
- [x] 协议可由另一人按清单独立复算（无隐含前置）

## 确认门

- [ ] T1 命题与 T2 协议已交用户确认后，才进入 T3

## T3 最小探针（`three/03_最小探针.md` + `experiments/paper_v3/feasibility_probe/`）

- [ ] 仅实现 T1 选出的那一步及必要适配；保留**可靠全量方法**与**最接近已发表简化法**为对照
- [ ] 原型、对照及评分**分开保存**；验证样例的真实延迟**未**被读取用于筛选分支
- [ ] **首先**跑反例与超时样例；缩小范围/跳过约束/复用证书均有**可检查的包含/有效性条件**
- [ ] 一旦漏覆盖或给出假安全证书，已**直接记失败**；**未**靠事后调大裕量遮盖
- [ ] 同一实现路径下记录**确定性工作量计数**并**重复墙钟计时**；记录精度、机器负载与尾部耗时
- [ ] 收益已拆分为**算法步骤变化**与**实现差异**；无收益时**保留负结果**
- [ ] `03_最小探针.md`、版本化代码与逐 trial 数据（`results_v3/`）存在；结果可复算
- [ ] 判据清楚给出候选的覆盖、计算与通行相对强基线的关系；**未**以单合成场景零违例宣称一般安全

## T4 研究决定（`three/04_研究决定.md` + 导师材料）

- [ ] 三选一结论明确（继续新候选 / 停止算法主线并改题 / 证据不足需一个最小补充实验），**逐条链接原始数据**
- [ ] 未以目录齐全、退出码 0 或布尔汇总自动通过
- [ ] 「继续新候选」仅在**同时**满足三条件（可复述最近邻差异＋可检查性质；全部预定反例无漏覆盖/虚报安全；同约束同预算下达 T2 阈值且重复方向一致）时成立
- [ ] 满足时已列下一轮模型误差校准、强基线与针对性 SITL，且**未自动启用**原 R1
- [ ] 未满足时已**止损**：停止安全过滤算法主线并给出 §4 选题检索与导师讨论
- [ ] 单项证据缺失时的补充实验已说明能**翻转哪项判断**、上限 **≤1 周**，且**未重做**已完成的备份修正
- [ ] 附**一页导师讨论材料**；导师真实回复、日期、要点**单独记录**；未回复未阻塞可逆技术分析，也未假记为同意

## §4 改题准备（仅否决时，`three/05_改题可行性检查.md`）

- [ ] 只做选题可行性检查，未当作自动投稿路线
- [ ] 已检索失效边界搜索、反例生成、主动测试、重要性采样最近邻
- [ ] 提出与随机/分层采样的公平基线、独立确认样本与预算口径
- [ ] 明确**定向搜索失败样本比例不得当作自然碰撞概率**
- [ ] 与导师讨论题目/资源/目标期刊后**另发**后续执行任务

- [ ] 重复运行确定性（除时间戳字段外一致）
- [ ] 全程无头运行，无 ROS/Gazebo GUI 残留进程
- [ ] 措辞合规：零违例只写「本批未观测到」；未虚报安全；负结果如实保留
- [ ] 主动投入 ≤**35 h / 5 个工作日**；阶段验收以**研究命题是否成立**为准，未以完成任务表或训练时长为准
