# 优化PPT布局与美观度 Spec

## 问题

当前PPT存在两个主要问题：
1. **内容溢出**：第8页（训练过程分析）的条形图每10个episode一组，共24组，超出页面底部边界（延伸到8.6"，页面高度仅7.5"）。
2. **美观度不足**：纯色块+文字排版，缺乏专业PPT的视觉层次感、间距控制和现代设计元素。

## 变更内容

### 1. 修复内容溢出
- 第8页条形图改为每20个episode聚合一组（12组），确保全部在页面内
- 或改为用进度条/表格代替条形图，节省垂直空间
- 第8页分析摘要文本压缩为单行，放置到图例区域
- 检查所有页面确保无元素超出页面底部边界

### 2. 安装并应用专业PPT模板库（skill）
- 安装 `powerpoint_template_system`：提供现代化模板系统，包含渐变背景、卡片、徽章、专业配色
- 或安装 `EasyPPTX`：提供百分比定位、模板TOML文件、现代配色方案
- 使用库提供的主题系统替换现有硬编码颜色

### 3. 视觉设计优化（基于专业设计规范）
- **配色方案**：采用"Midnight Executive"专业调色板（海军蓝#1E2761、冰蓝#CADCFC、白#FFFFFF）
- **排版**：统一字体层级，标题/副标题/正文/标注使用一致字号
- **间距**：遵循最小0.5"边距规则，每页5-7个元素限制
- **视觉层级**：大小表示重要性，颜色对比强调，Z字形内容流
- **卡片设计**：圆角卡片、阴影效果替代纯色块

### 4. 内容精简
- 第6页（实验数据总览）表格压缩为关键指标摘要
- 第7页（DQN训练结果）统计卡片从5个减为4个，保存关键数据
- 第8页条形图改为每20episode一组，减少到12组
- 所有页面文本精简30%，去除冗余描述

## 影响范围

- 修改文件：`scripts/generate_pptx.py`（重写视觉样式和布局逻辑）
- 新增依赖：`powerpoint_template_system` 或 `EasyPPTX`
- 输出文件：`docs/指导书/项目答辩PPT.pptx`（重新生成）
- 无其他模块影响

## 新增需求

### 需求：内容不溢出
系统SHALL确保所有幻灯片元素在页面边界内（T+ H ≤ 7.5"）。

#### 场景：检查第8页
- 执行python脚本验证所有元素位置
- 确保无元素超出7.5"高度

### 需求：专业模板系统
系统SHALL使用 `powerpoint_template_system` 或 `EasyPPTX` 库提供的主题/模板功能。

#### 场景：应用主题
- 加载库提供的内置主题
- 应用到所有幻灯片

## 修改需求

### 需求：美观度提升
- 原方案：纯色块+简单文字
- 新方案：渐变背景、圆角卡片、阴影、专业配色

## 移除需求

无
