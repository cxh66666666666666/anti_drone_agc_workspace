# Checklist

- [ ] A* 规划器能对给定障碍物场景输出无碰撞路径
- [ ] RRT 规划器能对给定障碍物场景输出无碰撞路径
- [ ] A* 和 RRT 输出的航点经 LQR 跟踪后无人机能安全到达目标
- [ ] 场景生成脚本能正确生成包含障碍物的 Gazebo world 文件
- [ ] 稀疏场景配置文件（3-5 障碍物）可用
- [ ] 密集场景配置文件（8-20 障碍物）可用
- [ ] 评估脚本能分别运行 DQN、A*、RRT、规则基线评估
- [ ] 评估脚本输出指标汇总表包含成功率、碰撞率、路径长度、规划时间、平滑度
- [ ] 评估结果通过固定随机种子可复现
- [ ] DQN 在稀疏障碍物场景下成功率 > 70%
- [ ] A* 与 DQN 的对比结果有记录（指标表格）
